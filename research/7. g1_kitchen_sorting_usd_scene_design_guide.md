# G1 주방용품 분류 정리 USD 씬 설계 및 구현 가이드

> 작성일: 2026-02-20
> 기반 문서: `g1_tabletop_manipulation_isaac_sim_assets_research.md`
> 목적: Unitree G1 + INSPIRE 5지 핸드로 주방 테이블 위 물체를 분류 정리하는 Isaac Lab 환경의 USD 씬 설계 및 구현

---

## 1. 설계 개요

### 1.1 목표 시나리오

G1 로봇이 주방 테이블 앞에 고정 자세로 서서, **INSPIRE 5지 핸드 양팔**을 사용하여 테이블 위에 흩어진 주방용품들을 카테고리별 정리함(분류함)에 분류하여 넣는 태스크.

### 1.2 핵심 구성 요소

| 구성 요소 | 설명 | 에셋 소스 |
|-----------|------|----------|
| 로봇 | G1 INSPIRE FTP (고정 베이스) | `G1_INSPIRE_FTP_CFG` |
| 테이블 | 주방 테이블 (0.75m 높이) | Isaac Lab Mimic table 또는 커스텀 |
| 정리함 3개 | 카테고리별 분류 목적지 | `sorting_bin_blue.usd` + 프리미티브 |
| 주방용품 5~8종 | 파지 대상 물체 | Isaac Lab 기본 + YCB + 프리미티브 |
| 카메라 | 물체 인식용 RGB-D | `CameraCfg` |
| 조명 | 주방 환경 조명 | `DomeLightCfg` |

### 1.3 시나리오 레이아웃

```
              [정면 뷰 - 위에서 내려다봄]

     ┌──────────────────────────────────────────┐
     │                                          │
     │  [BinA:주방]  [BinB:식품]  [BinC:기타]   │  ← Y=0.85m (뒤쪽)
     │                                          │
     │   (머그) (접시)  (캔)   (스폰지)         │  ← Y=0.55m (중앙)
     │      (그릇)   (병)  (사과)               │     물체 랜덤 배치
     │                                          │
     └──────────────────────────────────────────┘
                                                    ← Y=0.30m (테이블 앞 가장자리)
              ┌──────────────┐
              │   G1 로봇    │                      ← Y=0.0m, Z=1.0m
              │  (고정 베이스)│
              └──────────────┘

     X축: 좌(-0.4) ─────── 중앙(0.0) ─────── 우(+0.4)
```

## 2. 로봇 구성 (G1_INSPIRE_FTP_CFG)

### 2.1 기본 설정

```python
from isaaclab_assets.robots.unitree import G1_INSPIRE_FTP_CFG

robot: ArticulationCfg = G1_INSPIRE_FTP_CFG.replace(
    prim_path="{ENV_REGEX_NS}/Robot",
    init_state=ArticulationCfg.InitialStateCfg(
        pos=(0.0, 0.0, 1.0),           # 테이블 높이 맞춤 (pelvis 높이)
        rot=(1.0, 0.0, 0.0, 0.0),      # 정면(+Y) 방향
        joint_pos={".*": 0.0},          # 모든 관절 0 초기화
    ),
)
```

### 2.2 G1_INSPIRE_FTP_CFG 핵심 스펙

| 항목 | 값 | 비고 |
|------|-----|------|
| USD 모델 | `g1_29dof_inspire_hand.usd` | 29DOF + 24 손가락 |
| 기본 링크 | `pelvis` | IK 베이스 |
| 고정 베이스 | `fix_root_link = True` | 테이블탑 시나리오 |
| 중력 비활성 | `disable_gravity = True` | 상체 안정성 |
| 팔 강성 | stiffness=3000, damping=100 | 높은 위치 정밀도 |
| 손 강성 | stiffness=10, damping=0.2 | 유연한 파지 |
| 팔 관절 | shoulder_pitch/roll/yaw, elbow, wrist_yaw/roll/pitch | 7DOF × 2 |
| 손 관절 | index/middle/ring/pinky/thumb (proximal/intermediate/distal) | 12DOF × 2 = 24 |

### 2.3 액션 구성 (Pink IK + Inspire Hand)

기존 `pickplace_unitree_g1_inspire_hand_env_cfg.py` 기반:

```python
from isaaclab.controllers.pink_ik import PinkInverseKinematicsActionCfg

actions: ActionsCfg = ActionsCfg(
    arm_ik=PinkInverseKinematicsActionCfg(
        # IK로 제어할 팔 관절 (14 joints: 7 × 2)
        pink_controlled_joint_names=[
            ".*_shoulder_pitch_joint",
            ".*_shoulder_roll_joint",
            ".*_shoulder_yaw_joint",
            ".*_elbow_joint",
            ".*_wrist_yaw_joint",
            ".*_wrist_roll_joint",
            ".*_wrist_pitch_joint",
        ],
        # 직접 위치 제어할 손 관절 (24 joints)
        hand_joint_names=[
            # Left proximal (5)
            "L_index_proximal_joint", "L_middle_proximal_joint",
            "L_pinky_proximal_joint", "L_ring_proximal_joint",
            "L_thumb_proximal_yaw_joint",
            # Right proximal (5)
            "R_index_proximal_joint", "R_middle_proximal_joint",
            "R_pinky_proximal_joint", "R_ring_proximal_joint",
            "R_thumb_proximal_yaw_joint",
            # Left intermediate (5)
            "L_index_intermediate_joint", "L_middle_intermediate_joint",
            "L_pinky_intermediate_joint", "L_ring_intermediate_joint",
            "L_thumb_proximal_pitch_joint",
            # Right intermediate (5)
            "R_index_intermediate_joint", "R_middle_intermediate_joint",
            "R_pinky_intermediate_joint", "R_ring_intermediate_joint",
            "R_thumb_proximal_pitch_joint",
            # Thumb distal (4)
            "L_thumb_intermediate_joint", "R_thumb_intermediate_joint",
            "L_thumb_distal_joint", "R_thumb_distal_joint",
        ],
        # EEF 타겟 링크
        target_eef_link_names={
            "left_wrist": "left_wrist_yaw_link",
            "right_wrist": "right_wrist_yaw_link",
        },
    ),
)
```

### 2.4 액션 차원 (38D 총합)

```
[0:7]   Left EEF  = pos(3) + quat(4)
[7:14]  Right EEF = pos(3) + quat(4)
[14:38] Hand joints = 24 DOF
```

### 2.5 Pink IK 컨트롤러 파라미터

```python
PinkIKControllerCfg(
    articulation_name="robot",
    base_link_name="pelvis",
    num_hand_joints=24,              # Inspire hand
    # 왼쪽 손목 태스크
    left_wrist_task=LocalFrameTask(
        position_cost=8.0,           # [cost]/[m]
        orientation_cost=2.0,        # [cost]/[rad]
        lm_damping=10,
        gain=0.5,
    ),
    # 오른쪽 손목 태스크 (동일)
    right_wrist_task=LocalFrameTask(...),
    # 널스페이스 자세 태스크
    null_space_task=PostureTask(
        cost=0.5, lm_damping=1, gain=0.3,
        # 허리+어깨 관절의 기본 자세 유지
    ),
)
```


## 17. 핵심 주의사항

### 17.1 물리 안정성

1. **solver_position_iteration_count=16**: 파지 안정성을 위해 높은 반복 횟수
2. **max_depenetration_velocity=5.0**: 물체 겹침 시 급격한 튕김 방지
3. **kinematic_enabled=True**: 테이블, 정리함 등 고정 에셋에 필수
4. **disable_gravity=True**: G1 상체는 중력 비활성으로 안정적 조작

### 17.2 카메라 사용

1. `--enable_cameras` CLI 플래그 없이 카메라 사용 시 RuntimeError
2. `semantic_segmentation` 사용 시 모든 물체에 `semantic_tags` 필수
3. 카메라 업데이트 주기(`update_period`)가 짧으면 성능 저하

### 17.3 Nucleus 에셋 경로

1. `ISAACLAB_NUCLEUS_DIR`는 Nucleus 서버 연결이 필요
2. 오프라인 환경에서는 에셋을 로컬에 다운로드 후 절대 경로 사용
3. 프리미티브(CuboidCfg, CylinderCfg, SphereCfg)는 Nucleus 없이 즉시 사용 가능

### 17.4 성능 최적화

1. `make_instanceable=True`: 다수 환경 클론 시 GPU 메모리 절약
2. `lazy_sensor_update=True`: 접근할 때만 센서 업데이트
3. `replicate_physics=True`: 물리 에셋 공유로 메모리 절약
