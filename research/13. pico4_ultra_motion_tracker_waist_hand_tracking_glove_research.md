## 1. 허리 모션 트래커 장착: Full-Body Tracking 허리 인식

### 1.1 PICO Motion Tracker Waist Version 개요

PICO는 2025년에 **Motion Tracker Waist Version**을 공식 출시했다. 기존 발목 트래커(2개)만으로는 하반신 포즈 추정 시 허리 방향(orientation)이 부정확했는데, 허리 전용 트래커를 추가하면 **실제 허리 회전/기울임을 직접 측정**할 수 있다.

### 1.2 기술 사양

| 항목 | 사양 |
|------|------|
| **센서** | 9축 IMU (가속도계 + 자이로스코프 + 지자기 센서) + 12개 적외선 센서 |
| **자유도** | 6DoF |
| **전송 주파수** | 200Hz |
| **위치 편차** | 평균 5cm |
| **각도 편차** | 평균 6° |
| **걸음 인식 정확도** | 98% 이상 |
| **지연시간** | 20ms |
| **무게** | 27g |
| **배터리** | 25시간 이상 연속 사용 |
| **연결 방식** | 2.4GHz 전용 프로토콜 |
| **호환 기기** | PICO 4 Ultra, PICO 4 Pro, PICO 4, PICO Neo3 |

### 1.3 허리 트래커가 제공하는 개선점

#### 발목 트래커만 사용 시 (기존)
- AI 알고리즘이 발 위치로부터 허리 방향을 **추정** (간접 추론)
- 빠른 몸통 회전 시 지연 발생
- 앉기/눕기 자세에서 정확도 급감
- 24개 스켈레톤 포인트 중 상체 관련 포인트 오차 큼

#### 허리 트래커 추가 시 (개선)
- **실제 허리 회전(yaw/pitch/roll)을 직접 측정** → 몸통 방향 정확도 대폭 향상
- 앉기(sitting) 및 눕기(lying) 자세에서 **트래킹 성능 크게 향상**
- 몸통 기준 썸스틱 이동(torso-relative thumbstick movement) 가능
- VRChat 등 소셜 VR에서의 표현력 향상

### 1.4 트래커 구성 옵션

PICO 4 Ultra는 **최대 5개 Motion Tracker** 동시 사용을 지원한다:

| 구성 | 트래커 수 | 장착 위치 | 용도 |
|------|----------|----------|------|
| **Basic** | 3개 | 발목 2 + 허리 1 | 기본 Full-Body Tracking |
| **Enhanced Thigh** | 5개 | 발목 2 + 허리 1 + 허벅지 2 | 다리 추적 정밀화 |
| **Enhanced Forearm** | 5개 | 발목 2 + 허리 1 + 팔뚝 2 | 팔 추적 정밀화 + 핸드 트래킹 지연 감소 |

### 1.5 NVIDIA SONIC/GR00T WBC 통합

현재 GR00T-WholeBodyControl의 VR Teleop 설정은:
- **헤드셋**: PICO 4 / PICO 4 Pro (PICO 4 Ultra Enterprise도 호환)
- **컨트롤러**: PICO Controllers 2개 (손 위치/방향 입력)
- **트래커**: PICO Motion Tracker 2개 (발목)
- **데이터 전송**: XRoboToolkit (PC 서비스 + 헤드셋 앱, WiFi 스트리밍)

> **참고**: 현재 GR00T WBC 공식 문서에는 허리 트래커가 포함되어 있지 않지만, PICO의 Body Tracking API가 허리 트래커 데이터를 24개 스켈레톤 포인트에 반영하므로 XRoboToolkit을 통해 자동으로 개선된 Body Tracking 데이터가 전달될 것으로 예상됨.

### 1.6 개발자 API 지원

PICO Body Tracking API 지원 플랫폼:
- **Unity**: PICO Unity Integration SDK
- **Unreal Engine**: PICO UE SDK
- **OpenXR**: PICO OpenXR SDK (크로스 플랫폼 개발에 추천)
- **Avatar SDK**: 전신 움직임을 반영하는 아바타 생성

24개 스켈레톤 포인트에 대한 6DoF 데이터를 실시간으로 출력하며, Enhanced Forearm/Thigh Tracking 모드도 동일 API를 통해 접근 가능하다.

### 1.7 결론: 허리 트래커

**가능하다.** PICO Motion Tracker Waist Version은 공식 액세서리로, 발목 트래커 2개와 조합하면 허리 회전/기울임을 직접 측정하여 Full-Body Tracking 정확도가 크게 향상된다. 특히:
- 허리 방향(orientation) 직접 측정으로 상체-하체 분리 동작 정확도 향상
- 앉기/눕기 자세 지원 → 고령자 돌봄 시나리오(Phase 3) 직접 적용 가능
- 가격 합리적: 허리 트래커 ~€50 (~$55), 발목 2팩 ~€90 (~$100)

## 2. 손목/팔뚝 트래커 장착: 핸드 트래킹 정밀도

### 2.1 Enhanced Forearm Tracking 모드

PICO 4 Ultra의 5-트래커 Enhanced Tracking에서 **Enhanced Forearm Tracking** 구성을 선택하면:

```
발목 2개 + 허리 1개 + 팔뚝(forearm) 2개 = 5개 트래커
```

이 모드의 공식 효과:
- **팔 포즈(arm pose) 정확도 향상**: 팔꿈치, 손목 위치가 더 정확해짐
- **카메라 기반 핸드 트래킹의 위치 지연(positional latency) 감소**: 손이 카메라 시야 밖에 있을 때에도 팔뚝 IMU로 위치 보정
- **컨트롤러 없이(controller-free) 핸드 트래킹 사용 시 특히 효과적**

### 2.2 핸드 트래킹의 두 가지 레이어

PICO 4 Ultra의 핸드 트래킹은 두 레이어로 구성됨:

| 레이어 | 방식 | 추적 대상 | 정밀도 |
|--------|------|----------|--------|
| **카메라 기반 핸드 트래킹** | IR 카메라 + AI | 손바닥 위치 + 개별 손가락 관절 | 일반 인터랙션에 충분, 정밀 조작에는 부족 |
| **Motion Tracker (팔뚝)** | IMU + IR 센서 | 팔뚝 방향/위치 (6DoF) | 5cm 위치 편차, 6° 각도 편차 |

**핵심 이해**: 팔뚝 트래커는 **손가락 개별 추적이 아니라 팔/손목의 전체 위치를 보정**하는 역할이다.

### 2.3 한계점

| 측면 | 설명 |
|------|------|
| **손가락 추적 불가** | 모션 트래커는 IMU 기반으로 손가락 관절을 추적하지 않음 |
| **카메라 한계** | 손이 카메라 FOV 밖에 있으면 손가락 추적 불가 (팔뚝 위치만 보정) |
| **위치 정밀도** | 5cm 편차 → 로봇 텔레오퍼레이션의 그리핑 정밀도에는 부족 |
| **Dexterous Manipulation 불가** | INSPIRE 5-finger hand 제어에 필요한 개별 손가락 DOF 데이터 제공 불가 |

### 2.4 GR00T WBC 현재 핸드 트래킹 방식

GR00T WBC의 VR Teleop은 현재:
- **컨트롤러 기반**: PICO Controllers를 손에 들고 손 위치/방향 입력
- **손가락 제어 없음**: 컨트롤러 버튼으로 그리퍼 open/close만 지원
- **Dexterous manipulation**: MANUS 글러브 추가 시 개별 손가락 제어 가능 (NVIDIA SONIC 문서 참조)

### 2.5 결론: 손목 트래커로 핸드 트래킹 향상

**부분적으로 가능하지만, 기대와 다를 수 있다.**

| 항목 | 향상 여부 |
|------|----------|
| 팔/손목 전체 위치 정확도 | **향상됨** (팔뚝 IMU 보정) |
| 카메라 FOV 밖 손 위치 추적 | **향상됨** (위치 추정 가능) |
| 핸드 트래킹 위치 지연(latency) | **감소됨** |
| 개별 손가락 관절 추적 정밀도 | **변화 없음** (카메라 기반 동일) |
| Dexterous manipulation (5-finger) | **불가** → 글러브 필요 |

**UST 프로젝트 관점**:
- **G1 + INSPIRE 5-finger hand** 텔레오퍼레이션에는 개별 손가락 데이터가 필수
- 팔뚝 트래커만으로는 **그리퍼 open/close 이상의 정밀 제어 불가**
- **모션 글러브 추가가 필요**하며, 팔뚝 트래커는 글러브와 병행 시 팔 위치 보정으로 부가 가치 제공

## 6. 글러브 통합 기술 고려사항

### 6.1 UDCAP + PICO 통합 시나리오

UDCAP VR Gloves는 **SteamVR 기반**으로 동작하므로:

```
PICO 4 Ultra Enterprise
    │
    ├── PICO Connect (PC 스트리밍)
    │       │
    │       ▼
    │   SteamVR Runtime (PC)
    │       │
    │       ├── PICO Body Tracking → SteamVR 입력
    │       └── UDCAP Gloves → SteamVR 입력 (2.4GHz USB 동글)
    │               │
    │               ▼
    │           통합 데이터 → Isaac Lab
    │
    └── 또는: CloudXR Streaming (Isaac Lab 직접)
            + UDCAP SDK 병렬 데이터 수집
```

**핵심 고려사항**:
- PICO Connect로 PCVR 연결 시 SteamVR에서 Body Tracking + UDCAP 데이터 통합 가능
- CloudXR 사용 시: UDCAP SDK를 PC 측에서 별도로 실행하여 Isaac Lab에 핑거 데이터 전달
- **데이터 동기화**: Body Tracking(200Hz)과 UDCAP(120Hz) 간 타임스탬프 동기화 필요

### 6.2 Isaac Lab 통합 구현 방향

```python
# 예시: 통합 텔레오퍼레이션 데이터 파이프라인
class FullBodyTeleopDevice:
    """PICO Body Tracking + UDCAP Gloves 통합 디바이스"""

    def __init__(self):
        self.body_tracker = PICOBodyTracker()     # 24 skeleton points
        self.left_glove = UDCAPGlove("left")       # 21 joint angles
        self.right_glove = UDCAPGlove("right")     # 21 joint angles

    def get_teleop_command(self) -> dict:
        body = self.body_tracker.get_skeleton()    # 전신 포즈
        left_hand = self.left_glove.get_joints()   # 왼손 관절각
        right_hand = self.right_glove.get_joints()  # 오른손 관절각

        return {
            "head_pose": body.head,           # 6DoF
            "torso_pose": body.torso,         # 6DoF (허리 트래커)
            "left_arm_pose": body.left_arm,   # 6DoF (팔뚝 트래커)
            "right_arm_pose": body.right_arm, # 6DoF (팔뚝 트래커)
            "left_leg_pose": body.left_leg,   # 6DoF (발목 트래커)
            "right_leg_pose": body.right_leg, # 6DoF (발목 트래커)
            "left_finger_joints": left_hand,  # 21 angles (UDCAP)
            "right_finger_joints": right_hand, # 21 angles (UDCAP)
        }
```

## 7. 리스크 및 주의사항

### 7.1 UDCAP VR Gloves 리스크

| 리스크 | 수준 | 대응 방안 |
|--------|------|----------|
| 신제품 (2025) → 로보틱스 생태계 검증 부족 | 중 | UDCAP Data Glove (로보틱스 전용 버전) 출시 모니터링 |
| ROS2 직접 지원 없음 | 중 | SDK를 통한 커스텀 브릿지 개발 (Python SDK → ROS2 topic) |
| SteamVR 경유 필요 | 저 | PICO Connect 안정성 높음, CloudXR 병렬 사용 가능 |
| PICO 네이티브 BT 연동 불가 | 저 | USB 동글 방식이라 BT 제한과 무관 |

### 7.2 일반 주의사항

1. **PICO PUI 버전**: PUI 4.8.19에서 일부 BT 디바이스 연결 차단됨 → PUI 5.0+ 업데이트 권장
2. **SenseGlove Nova 2**: PUI 4.8.19에서 BT 목록에 나타나지 않는 호환 문제 있음 → PUI 5.0+ 필요
3. **MANUS 글러브**: PICO 네이티브 BT 미지원 → Vive Tracker 또는 별도 트래커 부착 필요
4. **Enhanced Forearm Tracking + 글러브 동시 사용**: 팔뚝 트래커 위에 글러브 착용 시 물리적 간섭 가능성 → 글러브 선택 시 슬림한 디자인 우선
