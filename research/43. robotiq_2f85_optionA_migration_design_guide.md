## 1. 왜 옵션 B 가 부적절했는가 (스크린샷 분석)

사용자 스크린샷에서 보이는 그리퍼는 `build_gripper_usd.py` 가 만든:

- 손목에 직사각형 박스 base
- 그 base 에서 직각으로 늘어진 두 prismatic finger (cube primitive, 사이즈 0.01×0.04×0.06)
- finger 가 base 의 +Z 방향으로 0.06 m 길이로 뻗음 → 손목 아래로 길게 매달린 듯한 형상

이 형상이 부적절한 이유:

1. **시각적 misleading** — 사용자 텔레오퍼레이션 시 "어디서 잡히는가" 가 직관적이지 않다. 산업 그리퍼는 fingertip pad 가 좁고 두 finger 가 평행 grasp 하는 형태로 즉시 식별 가능해야 demo 데이터 품질이 올라간다.
2. **충돌/마찰 모델 검증 없음** — finger box 의 모서리가 sharp 해서 contact normal 이 불연속. PhysX 의 frictional dynamics 가 jitter 를 유발하는 케이스가 잦다.
3. **하드웨어 가속 sim-to-real 경로 차단** — 추후 실제 robot 에 적용할 때 자작 그리퍼는 hardware 대응이 없다. Robotiq 2F-85 는 산업 표준이라 sim-to-real, mocap, RL 학습 모든 단계가 매끄럽다.
4. **mesh 가 cube primitive 라 mass/inertia 가 비현실적** — finger mass 0.02 kg, base mass 0.05 kg 으로 임의 설정. 실제 robot mass distribution 과 다르다.

옵션 A 는 위 네 가지를 한 번에 해결한다.

### 2.4 Mechanism 모델 결정

Robotiq 2F-85 는 **순수 prismatic 아님** — 4-bar linkage 로 fingertip 이 parallel 또는 encompassing grasp 한다. PhysX articulation 은 tree 구조라 closed loop 를 표현 못 한다. 세 가지 모델링 옵션:

| 모델 | 설명 | 추천 |
|---|---|---|
| **A** (1순위) | stock USD 의 PhysX MimicJointAPI 활용. lead `finger_joint` 만 actuate, 5 followers 는 constraint 로 자동 추종 | ★★★★★ |
| **B** (백업) | MimicJointAPI 제거, 6 revolute joints 모두 actuated. `BinaryJointPositionAction` 의 close_command 에 각 joint 의 target 명시 (sign 주의) | ★★★ |
| **C** (단순화) | 6 revolute 를 단일 prismatic 으로 대체 + visual-only fingers | ★ (sim-to-real 가치 손실) |

→ **A** 채택. 만약 Isaac Sim 5.1 의 알려진 "follower 정지" issue 가 발생하면 **B** 로 fallback.

```python
"""Materialise GR1T2_with_robotiq.usd from stock assets.

Replaces ust_hm_grip 9.45 의 build_gripper_usd.py (자작 box gripper).
"""
from pxr import Usd, UsdGeom, UsdPhysics, Sdf, Gf

GRIPPER_TCP_OFFSET_Z = 0.150   # 2F-85 mount face → TCP centerline, meters
                                # closed-pose body height 162.8 mm 에서 fingertip
                                # pad 두께 ~12 mm 제외값. 캘리브레이션 권장.

GRIPPER_ATTACH_OFFSET_Z = 0.00  # wrist 와 mount face 직접 접촉 (별도 spacer 없음)


def _strip_fourier_hand(stage, side):
    """L_* / R_* finger prims 제거 (build_gripper_usd 9.45 와 동일)."""
    # ... 기존 _remove_fourier_hand 그대로 ...


def _attach_robotiq(stage, side, robotiq_layer):
    """Robotiq 2F-85 subtree 를 humanoid USD 의 {side}_hand_pitch_link 하위에
    Sdf.CopySpec 으로 import + ArticulationRoot 제거 + FixedJoint 로 anchor +
    TCP frame 추가."""

    root = stage.GetDefaultPrim().GetPath()
    wrist_path = root.AppendChild(f"{side}_hand_pitch_link")
    dest_path = root.AppendChild(f"{side}_robotiq")

    # 1) Sdf.CopySpec — Robotiq stock USD subtree 를 새 prim 으로 복사
    Sdf.CopySpec(
        robotiq_layer,
        Sdf.Path("/Robotiq_2F_85"),       # stock USD 의 default prim
        stage.GetRootLayer(),
        dest_path,
    )

    # 2) 그리퍼의 ArticulationRoot 제거 — humanoid 의 articulation 에 흡수
    gripper_root_prim = stage.GetPrimAtPath(dest_path)
    if gripper_root_prim.HasAPI(UsdPhysics.ArticulationRootAPI):
        gripper_root_prim.RemoveAPI(UsdPhysics.ArticulationRootAPI)

    # 3) FixedJoint — humanoid wrist body ↔ robotiq base_link
    base_link_path = dest_path.AppendChild("robotiq_arg2f_base_link")
    fj = UsdPhysics.FixedJoint.Define(
        stage, root.AppendChild(f"{side}_robotiq_attach_fixed_joint"),
    )
    fj.CreateBody0Rel().SetTargets([wrist_path])
    fj.CreateBody1Rel().SetTargets([base_link_path])
    fj.CreateLocalPos0Attr(Gf.Vec3f(0.0, 0.0, GRIPPER_ATTACH_OFFSET_Z))
    fj.CreateLocalPos1Attr(Gf.Vec3f(0.0, 0.0, 0.0))
    # GR1T2 wrist 좌표계가 robotiq mount face 와 어떻게 align 되는지
    # inspect_usd 로 사전 확인 필수. 필요시 90° rotation 추가.
    fj.CreateLocalRot0Attr(Gf.Quatf(1.0, 0.0, 0.0, 0.0))
    fj.CreateLocalRot1Attr(Gf.Quatf(1.0, 0.0, 0.0, 0.0))

    # 4) TCP frame 추가 — Pink IK target 으로 사용
    tcp_path = dest_path.AppendChild(f"{side}_gripper_tcp_link")
    tcp_prim = UsdGeom.Xform.Define(stage, tcp_path).GetPrim()

    # base_link 의 world rest pose 계산 (build_gripper_usd 9.48 패턴)
    xform_cache = UsdGeom.XformCache(Usd.TimeCode.Default())
    base_world = xform_cache.GetLocalToWorldTransform(
        stage.GetPrimAtPath(base_link_path)
    )
    tcp_world = (
        Gf.Matrix4d().SetTranslate(Gf.Vec3d(0.0, 0.0, GRIPPER_TCP_OFFSET_Z))
        * base_world
    )
    UsdGeom.Xformable(tcp_prim).ClearXformOpOrder()
    UsdGeom.Xformable(tcp_prim).AddTransformOp().Set(tcp_world)
    UsdPhysics.RigidBodyAPI.Apply(tcp_prim)
    # TCP 는 collision 없음 — 순수 frame
    UsdPhysics.MassAPI.Apply(tcp_prim)
    tcp_prim.GetAttribute("physics:mass").Set(1e-6)

    tcp_fj = UsdPhysics.FixedJoint.Define(
        stage, root.AppendChild(f"{side}_gripper_tcp_fixed_joint"),
    )
    tcp_fj.CreateBody0Rel().SetTargets([base_link_path])
    tcp_fj.CreateBody1Rel().SetTargets([tcp_path])
    tcp_fj.CreateLocalPos0Attr(Gf.Vec3f(0.0, 0.0, GRIPPER_TCP_OFFSET_Z))
    tcp_fj.CreateLocalPos1Attr(Gf.Vec3f(0.0, 0.0, 0.0))
    tcp_fj.CreateLocalRot0Attr(Gf.Quatf(1.0, 0.0, 0.0, 0.0))
    tcp_fj.CreateLocalRot1Attr(Gf.Quatf(1.0, 0.0, 0.0, 0.0))


def main():
    sim_app = _boot_isaac_sim()             # 기존 helper 그대로
    try:
        from pxr import Usd, Sdf
        src_gr1t2  = _resolve_stock_usd_path()    # 기존 helper
        src_robotiq = _resolve_robotiq_usd_path() # 신규 — local cache 우선
        out = os.path.abspath(args.output)

        # GR1T2 flatten + open
        src_stage = Usd.Stage.Open(src_gr1t2)
        flat_layer = src_stage.Flatten()
        out_stage = Usd.Stage.Open(flat_layer)
        out_stage.GetRootLayer().Export(out)
        stage = Usd.Stage.Open(out)
        _setup_default_prim(stage)
        _strip_fourier_hand(stage)

        # Robotiq layer 를 열고 양쪽 wrist 에 attach
        robotiq_layer = Sdf.Layer.FindOrOpen(src_robotiq)
        for side in ("left", "right"):
            _attach_robotiq(stage, side, robotiq_layer)

        stage.GetRootLayer().Save()
    finally:
        sim_app.close()
```

### 4.3 검증 — `scripts/inspect_usd_robotiq.py`

1. `{side}_robotiq_arg2f_base_link` prim 존재
2. `{side}_robotiq_finger_joint` (lead) 와 `{side}_robotiq_*_joint` × 5 (followers) 존재
3. **각 follower joint 에 `PhysxMimicJointAPI` 적용 + `referenceJoint=finger_joint` + `gearing=±1` + `offset=0` 확인** (이게 옵션 A 의 핵심)

5. articulation root 는 GR1T2 root 하나뿐 (gripper 쪽 ArticulationRootAPI 제거 확인)

**Fallback** (PhysxMimicJointAPI 미동작 시): `joint_names_expr` 를 `ROBOTIQ_ALL_JOINTS_LEFT/RIGHT` 로 확장하고 actuator 6개 모두 등록. close 명령은 §5.4 참조.

### 5.3 BinaryJointPositionAction

```python
class GripperActionsCfg:

    left_gripper_action = BinaryJointPositionActionCfg(
        asset_name="robot",
        joint_names=[ROBOTIQ_LEAD_JOINT_LEFT],
        open_command_expr  = {ROBOTIQ_LEAD_JOINT_LEFT: 0.0},
        close_command_expr = {ROBOTIQ_LEAD_JOINT_LEFT: ROBOTIQ_CLOSE_RAD},
    )
    right_gripper_action = BinaryJointPositionActionCfg(
        asset_name="robot",
        joint_names=[ROBOTIQ_LEAD_JOINT_RIGHT],
        open_command_expr  = {ROBOTIQ_LEAD_JOINT_RIGHT: 0.0},
        close_command_expr = {ROBOTIQ_LEAD_JOINT_RIGHT: ROBOTIQ_CLOSE_RAD},
```

**Fallback** (mimic 안 됨 → 6 joints 명시): `joint_names` 에 `ROBOTIQ_ALL_JOINTS_LEFT` 전체. `close_command_expr` 에 **inner_finger 두 joint 는 -ROBOTIQ_CLOSE_RAD**, 나머지는 +ROBOTIQ_CLOSE_RAD. 부호 실수가 가장 흔한 함정 (community Disc #2626).

## 7. 위험 요소 & 완화책

### 7.1 PhysxMimicJointAPI 동작 불안정 (5.1 known issue)

| 위험 | 완화 |
|---|---|
| 일부 follower link 가 lead 와 안 움직임 | §6.6 의 6 joints 명시 fallback. `_pink_hand_dim_zero_patch.py` 처럼 import-time monkey-patch 작성 가능 |
| stock USD 에 MimicJointAPI 자체가 missing | URDF 재import (`Issue #305` 의 finite-limit workaround 적용) — PickNik xacro 사용 |

### 7.2 GR1T2 wrist frame 과 Robotiq mount face 의 축 misalignment

스크린샷 inspection 시 즉시 발견된다. `FixedJoint.localRot0` 에 quaternion 으로 90°/180° 회전 보정. 단계 1 의 `_attach_robotiq` 에 try-and-test orientation 옵션 파라미터화 권장.

### 7.3 PD gain 으로 인한 손목 회전 artifact

Issue #3347 (community) — stiffness ≥ 2000 + damping ≥ 100 조합에서 그리퍼 contact force 가 비대칭 → wrist rotation. 우리 cfg 는 stiffness=1.0 / damping=80 으로 안전 영역 내부.

### 7.4 TCP frame 위치 calibration

`GRIPPER_TCP_OFFSET_Z = 0.150` 은 데이터시트 기반 추정. 실제 grasping 정확도 검증 시 사용자가 컨트롤러로 target 을 가리키게 하고 그리퍼 fingertip 이 실제 그 위치에 닫히는지 확인 → 어긋나면 `build_robotiq_usd.py` 에서 offset 재조정 후 USD 재빌드 (~2 분).

### 7.5 mesh 라이선스

NVIDIA stock USD 는 Asset EULA — 우리 내부 빌드 산출물 `GR1T2_with_robotiq.usd` 는 외부 배포 금지. 외부 공개 (예: open-source release) 시 PickNik BSD-3 mesh 로 교체 후 URDF 재import 필요.

### 7.6 demo 데이터 호환성

기존 옵션 B 그리퍼로 수집한 demo HDF5 가 있다면 action layout 은 동일 (16-D = 7+7+1+1) 이라 그대로 replay 가능. 단 collision geometry 가 달라져서 grasp success rate 가 다를 수 있다 — 새 demo 수집 권장.
