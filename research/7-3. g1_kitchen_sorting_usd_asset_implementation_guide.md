## 1. 개요 및 사전 준비

### 1.1 목적

이 가이드는 Isaac Sim을 독립 실행하고, GUI 조작만으로 주방 분류 씬(`kitchen_sorting_scene.usd`)을 구축하는 전체 워크플로우를 설명한다. 코드 한 줄 없이 마우스와 키보드만으로 다음을 완성한다:

- 테이블, 정리함, 물체 등 13개 에셋 배치
- 물리 속성(Rigid Body, Collider, Mass) 설정
- 재질/색상 적용
- 시맨틱 태깅
- Play 버튼으로 물리 검증
- USD 파일 저장

### 1.2 코드 기반 vs GUI 기반 비교

| 항목 | 코드 기반 (env_cfg.py) | GUI 기반 (이 가이드) |
|------|----------------------|---------------------|
| 씬 생성 | `Usd.Stage.CreateNew()` | File > New |
| 에셋 추가 | `UsdFileCfg(usd_path=...)` | Content Browser 드래그앤드롭 |
| 프리미티브 | `sim_utils.CylinderCfg(...)` | Create > Mesh > Cylinder + Property 패널 |
| 위치 설정 | `InitialStateCfg(pos=(...))` | Property > Transform > Translate 직접 입력 |
| 물리 설정 | `RigidBodyPropertiesCfg(...)` | + Add > Physics > Rigid Body |
| 재질 색상 | `PreviewSurfaceCfg(diffuse_color=...)` | Material > OmniPBR > Base Color |
| 시맨틱 태그 | `semantic_tags=[("class", "mug")]` | + Add > Semantics > Semantics Schema |
| 검증 | `./isaaclab.sh -p ...` | Play 버튼 (▶) |
| 저장 | `stage.Save()` | File > Save As |

### 1.3 사전 요구사항

- **Isaac Sim 5.1.0** 이상 설치 (Isaac Lab 2.3.0 포함)
- **GPU**: NVIDIA RTX 계열 (RTX PRO 6000 권장)
- **Nucleus 서버**: 에셋 브라우징에 필요 (로컬 또는 클라우드)
- **디스플레이**: GUI 모드 실행 필수 (`--headless` 불가)

### 1.4 최종 결과물

`ust_ws/ust_260220/assets/kitchen_sorting_scene.usd` — Isaac Lab 환경에서 로드 가능한 완전한 주방 분류 씬.

## 2. Isaac Sim 독립 실행

### 2.1 방법 A: Isaac Lab 래퍼 사용 (권장)

Isaac Lab 확장 경로가 자동으로 포함된다.

```bash
./isaaclab.sh -s
```

Isaac Sim이 GUI 모드로 열리며, 좌측 하단에 "Ready" 상태가 표시될 때까지 기다린다 (첫 실행 시 1~3분 소요).

### 2.2 방법 B: Isaac Sim 직접 실행

```bash
# Isaac Sim 설치 경로에서 직접 실행
~/.local/share/ov/pkg/isaac-sim-*/isaac-sim.sh
```

### 2.3 초기 화면 확인

실행 후 다음 패널이 보이면 정상:
- **Viewport** (중앙): 3D 뷰
- **Stage** (우측): USD 프림 계층 트리
- **Property** (우측 하단): 선택한 프림의 속성
- **Content Browser** (하단): 파일/에셋 탐색

> **주의**: `--headless` 모드에서는 GUI가 없으므로 이 가이드를 따라할 수 없다. 반드시 디스플레이가 연결된 상태에서 실행한다.

## 3. GUI 핵심 패널 안내

### 3.1 Viewport (뷰포트)

3D 씬을 렌더링하여 보여주는 패널.

| 조작 | 입력 | 설명 |
|------|------|------|
| 회전 | `Alt + LMB 드래그` | 궤도 회전 (Orbit) |
| 이동 | `Alt + MMB 드래그` | 평행 이동 (Pan) |
| 줌 | `스크롤 휠` | 줌 인/아웃 |
| 포커스 | `F` (프림 선택 후) | 선택 프림에 카메라 포커스 |
| 시점 변경 | Viewport 좌상단 큐브 클릭 | Top/Front/Right 등 정사영 뷰 |
| 기즈모 | `W` / `E` / `R` | Move / Rotate / Scale 기즈모 전환 |

### 3.2 Stage (스테이지)

USD 프림 계층 구조를 트리로 보여준다.

- **프림 선택**: 클릭으로 선택, Property 패널에 속성 표시
- **이름 변경**: 프림 선택 후 `F2` 또는 더블클릭
- **숨기기/보기**: 프림 왼쪽 눈 아이콘 토글
- **삭제**: 프림 선택 후 `Delete` 키
- **계층 이동**: 드래그앤드롭으로 부모-자식 관계 변경

### 3.3 Property (속성)

선택된 프림의 모든 속성을 표시/편집하는 패널.

- **Transform**: Translate(위치), Orient(회전), Scale(크기) — 직접 숫자 입력 가능
- **Physics**: Rigid Body, Collider, Mass 등 물리 속성
- **Material**: 바인딩된 재질 확인/변경
- **Raw USD Properties**: 모든 USD 어트리뷰트 직접 편집

### 3.4 Content Browser (콘텐츠 브라우저)

Nucleus 서버의 에셋을 탐색하고 씬에 추가하는 패널.

- **좌측 트리**: Nucleus 서버, 로컬 디렉토리 탐색
- **우측 그리드**: 파일/폴더를 썸네일로 표시
- **검색**: 상단 검색창에서 파일명 검색
- **에셋 추가**: USD 파일을 Viewport 또는 Stage에 드래그앤드롭

### 3.5 기타 유용한 패널

| 패널 | 여는 방법 | 용도 |
|------|----------|------|
| Console | Window > Console | 로그/에러 메시지 확인 |
| Physics Inspector | Window > Physics > Physics Inspector | 충돌체/강체 시각화 |
| Script Editor | Window > Script Editor | Python 스크립트 직접 실행 |
| Property (Raw USD) | Property 패널 하단 "Raw USD Properties" | USD 어트리뷰트 직접 편집 |

## 4. 새 Stage 생성 및 기본 설정

### 4.1 새 Stage 생성

1. **File > New** (또는 `Ctrl+N`)
2. 기존 작업 저장 여부 묻는 다이얼로그 → "Don't Save" (새로 시작)
3. 빈 Stage가 열림

### 4.2 Stage 기본 설정

1. **Edit > Preferences > Stage** (또는 Stage 탭 좌측 하단 톱니 아이콘)
   - **Up Axis**: `Z` (Isaac Sim 기본값, 확인)
   - **Meters Per Unit**: `1.0` (미터 단위)

### 4.3 /World Xform 생성

Stage 루트에 모든 에셋을 담을 컨테이너를 만든다.

1. **Stage 패널** 빈 공간 우클릭 > **Create > Xform**
2. 생성된 `Xform`을 선택, `F2`로 이름 변경 → `World`
3. Stage에서 `/World`를 우클릭 > **Set as Default Prim**
   - 이렇게 하면 다른 USD에서 이 파일을 Reference로 추가할 때 `/World`가 기본 진입점이 됨

### 4.4 Physics Scene 추가

1. Stage에서 `/World`를 선택
2. 메뉴 **Create > Physics > Physics Scene**
3. Property 패널에서 확인:
   - **Gravity Direction**: (0, 0, -1)
   - **Gravity Magnitude**: 9.81
   - 기본값이 정확함, 변경 불필요

### 4.5 Ground Plane 추가

1. 메뉴 **Create > Physics > Ground Plane**
2. Stage에 `/World/GroundPlane`이 생성됨
3. 기본 위치 (0, 0, 0)에 바닥면이 배치됨 — 변경 불필요

### 4.6 조명 추가

#### Dome Light (주방 환경 조명)

1. 메뉴 **Create > Light > Dome Light**
2. Stage에서 생성된 DomeLight를 `/World` 아래로 드래그 → `/World/DomeLight`
3. Property 패널에서 설정:
   - **Intensity**: `3000`
   - **Color**: `(0.95, 0.90, 0.80)` — 따뜻한 주방 톤
     - Color 옆 색상 칩 클릭 → RGB 값 직접 입력: R=`0.95`, G=`0.90`, B=`0.80`

#### Distant Light (보조 조명)

1. 메뉴 **Create > Light > Distant Light**
2. `/World` 아래로 드래그 → `/World/SpotLight`
3. Property 패널:
   - **Intensity**: `1500`
   - **Color**: `(1.0, 1.0, 1.0)` — 백색

### 5.2 필요 에셋 경로 목록

|------|-------------------------------|

### 5.3 USD 에셋을 씬에 추가하는 방법 (선택 사항)

USD 에셋을 사용하고 싶은 경우:

1. Content Browser에서 원하는 `.usd` 파일을 찾기
2. 해당 파일을 **Viewport** 또는 **Stage 패널**로 **드래그앤드롭**
3. 다이얼로그가 나타남 → **"Add as Reference"** 선택
   - "Add as Reference"를 선택해야 원본 USD를 참조하면서 로컬에서 Transform/속성을 오버라이드할 수 있음
   - "Open"을 선택하면 현재 Stage를 교체하므로 주의
4. Stage에 새 프림이 생성됨 → `F2`로 이름 변경 (예: `BinKitchen`)
5. `/World` 아래로 드래그하여 계층 정리

**USD 에셋 추가 step-by-step 예시 (BinKitchen)**:

1. Content Browser에서 `Mimic/nut_pour_task/nut_pour_assets/sorting_bin_blue.usd` 찾기
2. Viewport로 드래그앤드롭 → "Add as Reference" 선택
3. Stage에서 생성된 프림 이름을 `BinKitchen`으로 변경
4. `/World` 아래로 이동
5. Property > Transform > Translate에 `(-0.28, 0.82, 0.80)` 입력
6. 같은 방식으로 `BinFood`(0.0, 0.82, 0.80), `BinMisc`(0.28, 0.82, 0.80) 추가

> **주의**: USD 에셋의 원점(Pivot) 위치가 바닥 중심이 아닐 수 있다. 추가 후 Viewport에서 시각적으로 테이블 위에 올바르게 위치하는지 확인하고, Z값을 미세 조정한다.

## 6. 프리미티브 도형 생성

env_cfg.py에 정의된 사양 그대로 프리미티브 도형을 생성한다.

### 6.1 Table (테이블)

1. 메뉴 **Create > Mesh > Cube**
2. Stage에서 `Cube`를 `/World` 아래로 이동, 이름을 `Table`로 변경
3. Property > Transform:
   - **Translate**: `(0.0, 0.55, 0.375)` — 테이블 중심 높이
   - **Scale**: `(0.45, 0.30, 0.375)` — Cube 기본 크기가 2×2×2이므로 half-size로 Scale 설정
     - 최종 크기: 0.9 × 0.6 × 0.75m

> **Scale vs Size 설명**: Isaac Sim의 Cube Mesh는 기본 크기가 한 변 2.0 단위(= -1~+1 범위)이다. 따라서 원하는 크기의 **절반**을 Scale에 입력한다.
> - 0.9m 폭 → Scale X = `0.45`
> - 0.6m 깊이 → Scale Y = `0.30`
> - 0.75m 높이 → Scale Z = `0.375`

### 6.2 Bins (정리함 3개)

> 프리미티브로 만드는 경우. Nucleus USD 에셋을 사용하려면 5.3절 참조.

정리함은 크기가 동일하므로 하나를 만들어 복사한다.

1. **Create > Mesh > Cube**
2. `/World` 아래로 이동, 이름 `BinKitchen`
3. Property > Transform:
   - **Translate**: `(-0.28, 0.82, 0.80)` — TABLE_HEIGHT(0.75) + bin 반높이(0.05)
   - **Scale**: `(0.125, 0.09, 0.05)` — 0.25 × 0.18 × 0.10m
4. Stage에서 `BinKitchen` 우클릭 > **Duplicate** (또는 `Ctrl+D`) → `BinFood`
   - Translate를 `(0.0, 0.82, 0.80)`으로 변경
5. 다시 Duplicate → `BinMisc`
   - Translate를 `(0.28, 0.82, 0.80)`으로 변경

### 6.3 Mug (머그컵) — 원통

1. **Create > Mesh > Cylinder**
2. `/World` 아래로 이동, 이름 `Mug`
3. Property:
   - **Translate**: `(0.15, 0.55, 0.79)` — TABLE_HEIGHT + 반높이(0.04)
   - **Radius**: `0.04` (Property > Geometry에서 설정, 또는 Scale로 조정)
   - **Height**: `0.08`

> **Cylinder 크기 설정**: Isaac Sim Cylinder는 기본 radius=0.5, height=1.0이다. Property의 Geometry 섹션에서 직접 radius와 height를 편집하거나, Scale로 비율을 조정한다. Geometry 직접 편집을 권장한다.

## 7. 에셋 배치 및 트랜스폼

### 7.1 기즈모 조작

Viewport에서 프림을 선택하면 기즈모(축 화살표)가 표시된다.

| 키 | 기즈모 | 용도 |
|----|--------|------|
| `W` | Move (이동) | 화살표 드래그로 위치 이동 |
| `E` | Rotate (회전) | 링 드래그로 회전 |
| `R` | Scale (크기) | 축 드래그로 크기 변경 |

> **정밀 배치 시**: 기즈모 드래그보다 **Property > Transform > Translate에 숫자 직접 입력**을 권장한다.

### 7.2 전체 배치 좌표표 (env_cfg.py 기준)

| 에셋 | Translate (X, Y, Z) | 비고 |
|------|---------------------|------|
| Table | `(0.0, 0.55, 0.375)` | 중심 높이, kinematic |
| BinKitchen | `(-0.28, 0.82, 0.80)` | 파란색, kinematic |
| BinFood | `(0.0, 0.82, 0.80)` | 파란색, kinematic |
| BinMisc | `(0.28, 0.82, 0.80)` | 검정색, kinematic |
| Mug | `(0.15, 0.55, 0.79)` | 원통, 질량 0.25kg |
| Plate | `(-0.10, 0.50, 0.77)` | 납작 원통, 0.35kg |
| Bowl | `(0.05, 0.60, 0.775)` | 원통, 0.20kg |
| Can | `(-0.18, 0.52, 0.81)` | 원통, 0.30kg |
| Bottle | `(0.20, 0.48, 0.84)` | 원통, 0.40kg |

> - 이렇게 하면 물체 바닥면이 정확히 테이블 상판(0.75m)에 접한다

### 7.4 USD 에셋 원점(Pivot) 확인

Nucleus USD 에셋(정리함, 머그컵 등)은 원점이 물체 바닥 중심이 아닐 수 있다.

**확인 방법**:
1. 에셋을 씬에 추가
2. Property > Transform > Translate를 `(0, 0, 0)`으로 설정
3. Viewport에서 물체의 원점(기즈모 중심) 위치 확인
4. 원점이 바닥이 아닌 경우 → Z값에 오프셋 추가

**Z값 미세 조정**:
1. Viewport 좌상단 큐브에서 **Front** 뷰 선택 (정면 뷰)
2. 물체 바닥이 테이블 상판(Z=0.75)에 정확히 닿는지 확인
3. Property > Transform > Translate Z 값을 0.01 단위로 조정

## 8. 물리 속성 설정

모든 물체에 물리 속성을 추가해야 시뮬레이션에서 중력, 충돌, 파지가 작동한다.

### 8.1 Rigid Body 추가

물체를 물리 시뮬레이션 대상으로 만든다.

1. Stage에서 대상 프림 선택 (예: `Mug`)
2. Property 패널 상단 **+ Add** 버튼 클릭
3. **Physics > Rigid Body** 선택
4. Property > Physics > Rigid Body에서:
   - **Solver Position Iteration Count**: `16` (파지 안정성 향상)
   - **Max Angular Velocity**: `1000.0`

**적용 대상**: Mug, Plate, Bowl, Can, Bottle, Apple, Sponge, TeddyBear (8개 동적 물체)

### 8.2 Kinematic 설정 (고정 물체)

테이블과 정리함은 움직이지 않아야 하므로 Kinematic으로 설정한다.

1. Stage에서 대상 프림 선택 (예: `Table`)
2. **+ Add > Physics > Rigid Body**
3. Property > Physics > Rigid Body:
   - **Kinematic Enabled**: 체크 (✓)
   - kinematic 체크 시 중력과 충돌 힘의 영향을 받지 않으면서 충돌면은 유지됨

**적용 대상**: Table, BinKitchen, BinFood, BinMisc (4개 고정 물체)

### 8.3 Collider 추가

물리 충돌을 감지하려면 Collider가 필요하다.

1. 대상 프림 선택
2. **+ Add > Physics > Collision**
3. 기본 설정(메시 기반 충돌) 유지 — 프리미티브 도형은 자동으로 적절한 충돌체가 생성됨

**적용 대상**: 모든 12개 에셋 (Table, Bin ×3, 물체 ×8)

### 8.4 Mass (질량) 설정

Rigid Body가 추가된 프림에 질량을 설정한다.

1. 대상 프림 선택
2. Property > Physics > Mass 섹션 (Rigid Body 추가 후 나타남):
   - **Mass**: 각 물체별 질량값 입력

**물체별 질량 (env_cfg.py 기준)**:

| 물체 | 질량 (kg) |
|------|-----------|
| Mug | 0.25 |
| Plate | 0.35 |
| Bowl | 0.20 |
| Can | 0.30 |
| Bottle | 0.40 |
| Apple | 0.18 |
| Sponge | 0.03 |
| TeddyBear | 0.15 |

> Table, Bin은 kinematic이므로 질량 설정 불필요.

### 8.5 Physics Material (물리 재질)

마찰과 반발을 전역으로 설정한다.

1. Stage에서 `/World` 선택
2. **Create > Physics > Physics Material**
3. `/World/PhysicsMaterial` 생성됨
4. Property > Physics Material:
   - **Static Friction**: `0.7`
   - **Dynamic Friction**: `0.5`
   - **Restitution**: `0.1`
5. 이 재질을 물체에 바인딩:
   - 대상 프림 선택 > Property > Physics > Collision 섹션
   - **Physics Material** 필드에 `/World/PhysicsMaterial` 드래그앤드롭 (또는 경로 입력)

> **팁**: 모든 물체에 동일 물리 재질을 적용해도 무방하다. env_cfg.py에서도 전역 `physics_material`을 사용한다 (static=0.7, dynamic=0.5, restitution=0.1).

## 12. USD 저장

### 12.1 저장

1. 메뉴 **File > Save As** (또는 `Ctrl+Shift+S`)
2. 저장 경로: `ust_ws/ust_260220/assets/kitchen_sorting_scene.usd`
   - 디렉토리가 없으면 미리 생성: `mkdir -p ust_ws/ust_260220/assets/`
3. **파일 형식 선택**:
   - `.usd` (기본, 바이너리 크레이트 포맷) — 파일 크기 작음, 로드 빠름, **권장**
   - `.usda` (ASCII 텍스트) — 사람이 읽을 수 있음, 디버깅/학습용
   - `.usdc` (바이너리 명시) — `.usd`와 동일하나 명시적

### 12.2 저장 후 확인

저장 후 Stage 탭 상단에 파일 경로가 표시되고, 제목 바에 `*` (수정 표시)가 사라지면 성공.

### 12.3 Nucleus Reference 경로 주의

Content Browser에서 Nucleus 에셋을 Reference로 추가한 경우, 저장된 USD 파일 내부에 Nucleus 경로가 남아있다. 예:
```
references = @omniverse://localhost/NVIDIA/Assets/Isaac/4.2/Isaac/IsaacLab/Objects/Mug/mug.usd@
```

**주의사항**:
- 이 USD를 다른 머신에서 열 때 해당 Nucleus 서버에 접속 가능해야 함
- 오프라인 환경에서는 Reference가 해석되지 않아 에셋이 표시되지 않음
- 프리미티브만 사용한 경우 이 문제가 없음 (자체 완결적)

## 13. Isaac Lab 연동

### 13.1 전체 씬 USD 로드 방법

GUI에서 만든 USD 파일을 Isaac Lab 환경에서 로드하는 코드 패턴:

```python
from isaaclab.sim.spawners.from_files import UsdFileCfg

# 배경 씬 전체를 하나의 USD로 로드
scene_usd = AssetBaseCfg(
    prim_path="/World/KitchenScene",
    spawn=UsdFileCfg(
        usd_path="ust_ws/ust_260220/assets/kitchen_sorting_scene.usd",
    ),
)
```

### 13.2 하이브리드 접근 (권장)

실제 Isaac Lab 환경에서는 **배경(테이블, 빈, 조명)은 USD**로, **동적 물체는 개별 RigidObjectCfg**로 구성하는 것이 일반적이다. 이렇게 하면:
- 동적 물체에 대한 물리 제어(reset, 랜덤화)가 가능
- `scene["mug"]`로 개별 물체에 접근 가능
- 배경 레이아웃만 변경하려면 USD만 교체하면 됨

```python
@configclass
class KitchenSortingSceneCfg(InteractiveSceneCfg):
    # 배경 (USD 파일에서 테이블+빈+조명 로드)
    kitchen_bg = AssetBaseCfg(
        prim_path="/World/KitchenBg",
        spawn=UsdFileCfg(
            usd_path="ust_ws/ust_260220/assets/kitchen_background.usd",
        ),
    )

    # 동적 물체 (코드에서 개별 정의)
    mug = RigidObjectCfg(
        prim_path="{ENV_REGEX_NS}/Mug",
        init_state=RigidObjectCfg.InitialStateCfg(
            pos=(0.15, 0.55, 0.79),
        ),
        spawn=sim_utils.CylinderCfg(
            radius=0.04, height=0.08,
            ...
        ),
    )
    # ... 나머지 동적 물체
```

### 13.3 GUI에서 확인한 좌표를 코드에 반영하는 패턴

1. Isaac Sim GUI에서 물체를 배치하고 시각적으로 적절한 위치를 확인
2. Property > Transform > Translate의 (X, Y, Z) 값을 메모
3. env_cfg.py의 `InitialStateCfg(pos=(...))` 에 해당 값을 입력
4. `pos` 좌표는 env_cfg.py에서 **프림의 중심(centroid)** 기준이므로, GUI에서도 동일한 기준인지 확인

## 14. 검증

### 14.1 Play 버튼 물리 테스트

1. Viewport 좌측 상단 **▶ (Play)** 버튼 클릭 (또는 `Space` 키)
2. 물리 시뮬레이션 시작 — 다음을 확인:

| 확인 항목 | 정상 동작 | 문제 시 |
|----------|----------|--------|
| 물체가 테이블 위에 안착 | 물체가 테이블에 살짝 떨어져 안착 | Z값 조정, Collider 확인 |
| 물체가 바닥으로 떨어지지 않음 | 테이블 위에 유지됨 | Table에 Collider 추가 확인 |
| 물체끼리 겹치지 않음 | 각자 독립적으로 안착 | 배치 좌표 간격 확인 |
| 테이블/빈이 움직이지 않음 | 완전 고정 | Kinematic Enabled 체크 확인 |
| 정리함에 물체 안 빠짐 | 빈이 테이블 위에 안정 | Z값, 물리 속성 확인 |

3. **■ (Stop)** 버튼으로 시뮬레이션 중지

### 14.2 Viewport 다각도 확인

1. **Top View**: Viewport 좌상단 큐브에서 상단 면 클릭
   - 물체들이 테이블 범위 안에 있는지, 겹치지 않는지 확인
2. **Front View**: 전면 확인
   - 물체들이 테이블 높이(Z=0.75) 위에 올바르게 놓여있는지 확인
3. **Perspective View**: 큐브 모서리 클릭
   - 전체 씬의 시각적 느낌 확인

### 14.3 Physics Inspector

1. **Window > Physics > Physics Inspector** 열기
2. 각 물체의 충돌체(Collider) 형태가 시각화됨 (초록색 와이어프레임)
3. 충돌체가 시각 메시와 크기가 맞는지 확인
4. Rigid Body 상태(dynamic/kinematic) 확인

### 14.4 Isaac Lab 텔레오퍼레이션 통합 테스트

USD 저장 후, 실제 Isaac Lab 환경에서 로드하여 검증:

./isaaclab.sh -p ust_ws/ust_260220/scripts/run_teleop.py --teleop_device handtracking

# 확인 사항:
# 1. 로봇 팔이 모든 물체에 도달 가능한지
# 2. 물체를 잡을 수 있는지 (파지 안정성)

# 4. 프레임레이트가 충분한지 (VR 시 60 FPS 이상)

## 부록 B: FAQ / 문제 해결

### Q1: Content Browser에서 Nucleus 에셋이 안 보인다

**원인**: Nucleus 서버에 연결되지 않았거나 에셋이 다운로드되지 않음.
**해결**:
1. Omniverse Launcher에서 Nucleus 서버 상태 확인 (로컬: `localhost`)
2. Content Browser 좌측 트리에서 `omniverse://localhost` 클릭하여 연결 시도
3. 에셋 경로가 Isaac Sim 버전에 따라 다를 수 있음 (`Isaac/4.2/` vs `Isaac/4.5/` 등)
4. 프리미티브로 대체하면 Nucleus 없이도 작업 가능

### Q2: Play 시 물체가 테이블을 뚫고 떨어진다

**원인**: Table에 Collision(충돌체)이 없다.
**해결**:
1. Table 프림 선택 > **+ Add > Physics > Collision**
2. Table에 Rigid Body가 없으면 **+ Add > Physics > Rigid Body** 후 **Kinematic Enabled** 체크

### Q3: 물체 크기가 너무 크거나 작다

**원인**: Cube/Cylinder/Sphere 기본 크기와 Scale 계산 오류.
**해결**:
- Cube: 기본 크기 2×2×2 → Scale = 원하는 크기 / 2
- Cylinder: Property > Geometry에서 Radius와 Height를 직접 편집 (Scale보다 정확)
- Sphere: Property > Geometry에서 Radius 직접 편집

### Q4: 물체가 초기에 서로 겹친다

**원인**: 물체간 이격 거리가 부족하거나, 같은 좌표에 여러 물체가 배치됨.
**해결**:
1. Top View에서 물체 배치 확인
2. 겹치는 물체의 X, Y 좌표를 최소 8cm 이상 이격
3. Play 버튼으로 물리 시뮬레이션을 실행하면 겹침이 자동으로 해소될 수 있으나, 초기 배치가 정확한 것이 바람직

### Q5: USD 에셋의 Scale이 이상하다

**원인**: Nucleus USD 에셋의 단위(Meters Per Unit)가 1.0이 아닐 수 있음.
**해결**:
1. 에셋을 추가한 후 Viewport에서 크기 확인
2. 너무 크거나 작으면 Property > Transform > Scale 조정
3. 원본 에셋의 metersPerUnit 확인: Property > Raw USD Properties > `metersPerUnit`

### Q6: 재질/색상이 적용되지 않는다

**원인**: 재질이 바인딩되지 않았거나, Viewport 렌더 모드가 와이어프레임.
**해결**:
1. Viewport 좌상단 렌더 모드 확인: **RTX - Interactive** 또는 **RTX - Real-Time** 선택
2. 재질 바인딩 확인: 대상 프림 Property > Material Binding 섹션
3. 재질을 대상 프림 위로 드래그앤드롭하여 바인딩
