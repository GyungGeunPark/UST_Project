# Unitree G1 테이블탑 매니퓰레이션을 위한 Isaac Sim 에셋 및 환경 구축 리서치

> 작성일: 2026-02-20
> 목적: Unitree G1 로봇의 실내 가정환경 테이블 위 물체 정리 태스크 구현을 위한 에셋, 환경, 시나리오 조사

## 1. 개요

본 리서치는 Unitree G1 휴머노이드 로봇이 가정환경(실내)에서 테이블 위 물체들을 양팔로 정리하는 태스크를 Isaac Sim/Isaac Lab에서 구현하기 위해, 활용 가능한 에셋(물체, 가구, 환경)과 기존 환경 설정을 체계적으로 조사한 결과이다.

## 6. 테이블 정리 태스크 시나리오 설계

### 6.1 기본 시나리오: "테이블 위 물체 분류 정리"

**시나리오 설명**: G1 로봇이 테이블 앞에 서서, 양팔을 사용하여 테이블 위에 흩어진 물체들을 카테고리별로 정리함

```
[테이블 레이아웃]

     ┌─────────────────────────────┐
     │ [정리함A] [정리함B] [정리함C] │  ← 뒤쪽: 카테고리별 분류함
     │                             │
     │  (물체1) (물체3)  (물체5)   │  ← 중앙: 정리할 물체들
     │     (물체2)  (물체4)        │     (랜덤 배치)
     │                             │
     └─────────────────────────────┘
              │ G1 로봇 │              ← 앞쪽: 로봇 위치 (고정)
```

**활용 에셋**:
- 테이블: `Mimic/.../table.usd` 또는 `SeattleLabTable`
- 정리함: `sorting_bin_blue.usd`, `black_sorting_bin.usd`, `box.usd`
- 물체: `mug.usd`, `teddy_bear.usd`, `toy_truck.usd`, 블록들, `factory_m16_nut_green.usd`

### 6.2 확장 시나리오: "주방 테이블 정리"

**시나리오 설명**: 식사 후 주방 테이블 위의 식기와 음식 용기를 정리

**활용 에셋 (YCB + SimReady)**:
- 식기: 접시(plate), 그릇(bowl), 머그(mug), 컵(cups)
- 식품 용기: 캔, 병, 박스
- 정리 위치: 싱크대 영역, 냉장고 영역, 수납장

### 6.3 확장 시나리오: "양팔 협조 정리"

**시나리오 설명**: 큰 물체(양팔 필요)와 작은 물체(한팔)를 구분하여 정리

**태스크 분류**:
| 동작 타입 | 물체 예시 | 팔 사용 |
|----------|----------|---------|
| 한손 파지+이동 | 머그, 볼, 블록, 캔 | 왼팔 또는 오른팔 |
| 양손 파지+이동 | 스티어링 휠, 배기관, 큰 박스 | 양팔 협조 |
| 정밀 파지 | 너트, 작은 블록, 볼펜 | 한팔 (Inspire 손가락) |
| 붓기 동작 | 비커 → 그릇 | 한팔 (기울이기) |

### 6.4 난이도별 시나리오 구성

#### Level 1: 기본 (블록 분류)
- 물체: 컬러 블록 4종 (빨강, 파랑, 초록, 노랑)
- 목표: 색상별로 해당 정리함에 넣기
- 에셋: `blue_block.usd`, `red_block.usd`, `green_block.usd`, `yellow_block.usd`, `sorting_bin_blue.usd`

#### Level 2: 중급 (다양한 물체)
- 물체: 머그, 테디베어, 장난감 트럭, 블록
- 목표: 물체 종류별 분류 (장난감/주방용품/기타)
- 에셋: `mug.usd`, `teddy_bear.usd`, `toy_truck.usd`, `box.usd`

#### Level 3: 고급 (주방 정리)
- 물체: YCB 물체 세트 (접시, 그릇, 머그, 캔, 병)
- 목표: 용도별 분류 + 양팔 협조 (큰 그릇)
- 추가 어려움: 물체 인식, 깨지기 쉬운 물체 주의

#### Level 4: 전문가 (미지 물체 + AI 도움 요청)
- 물체: 학습되지 않은 새로운 물체 포함
- 목표: AI가 모르는 물체를 사람에게 질문 → 답변 반영
- **교정 티칭 AI 시스템과 연동**

## 10. 결론 및 추천

### 10.1 즉시 구현 가능한 것

1. **G1 Fixed Base + Inspire Hand** 환경에서 **기본 제공 물체 4종** (머그, 테디베어, 장난감 트럭, 박스)을 사용한 테이블 분류 태스크
2. **컬러 블록 4종**을 사용한 스태킹/분류 기본 태스크
3. **Mimic 에셋** (분류 그릇, 비커, 정리함)을 활용한 nut-pour 스타일 정리 태스크
4. **Pink IK + VR 텔레오퍼레이션**을 통한 시연 데이터 수집

### 10.2 단기간 구축 가능한 것 (1-2주)

1. **YCB 물체 세트 USD 변환** → 77종 일상 물체 활용
2. **프리미티브 기반** 커스텀 물체 (컵, 접시, 책 등) 생성
3. **RoboCasa 주방 환경** 통합
4. **도메인 랜덤화** 설정 (물체 배치, 질량, 조명)

### 10.3 중기 구축 가능한 것 (2-4주)

1. **Google Scanned Objects** 통합 (1,030종 고품질 가정용품)
2. **PartNet-Mobility** 관절형 가구 (서랍장, 냉장고)
3. **InteriorAgent** 실내 씬으로 현실감 있는 가정환경 구축
4. **교정 티칭 AI 시스템**과 연동된 Level 4 시나리오

### 10.4 추천 구현 순서

```
Phase 1: G1 + 기본 물체 + 블록 분류 태스크
   → Fixed Base IK 환경 검증, VR 텔레오퍼레이션 연동 확인

Phase 2: YCB 물체 추가 + 주방 정리 시나리오
   → 다양한 물체 파지 + 양팔 협조 태스크

Phase 3: 카메라 기반 물체 인식 + 분류 AI 통합
   → RGB/Semantic Segmentation → VLM 물체 인식

Phase 4: 교정 티칭 시스템 통합
   → AI 불확실성 감지 → 사람 도움 요청 → 교정 학습
```
