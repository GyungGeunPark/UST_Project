## 1. 문제 정의 — 무엇을 검증하는가

### 1.1 정밀제어의 정의 (이 프로젝트 맥락)

| 항목 | 설명 | 검증 메트릭 |
|---|---|---|
| **Fidelity (충실도)** | 사용자 손가락 굽힘이 robot 손가락 굽힘에 비례하는가 | 5 finger × 좌·우 = 10 finger 의 사용자 input vs robot output Pearson 상관계수 ≥ 0.90 |
| **Latency (지연)** | 사용자 input → robot output 까지의 시간 지연 | 시간 cross-correlation peak 위치, 목표 < 100ms |
| **Range coverage (범위)** | URDF 의 joint limit 을 얼마나 활용하는가 | 사용자 전체 ROM 동안 robot 측 Δrange / joint limit ratio ≥ 0.7 |
| **Symmetry (대칭)** | 좌·우 손이 동일한 입력에 동일하게 반응하는가 | left vs right Δrange 차이 < 0.3 rad |
| **Articulation (다관절성)** | MCP / PIP / DIP 가 단일 동작이 아닌 분리된 동작을 보이는가 | Proximal vs Intermediate slot 간 cross-correlation < 0.95 (mimic 외에 독립적 변동 있는지) |
| **Per-finger isolation (분리성)** | 한 손가락만 움직였을 때 그 손가락만 robot 측에서 반응하는가 | 비-타겟 finger 의 Δrange < 0.05 rad 중 자극 finger 의 Δrange > 0.5 rad 일 때 |
| **Determinism (재현성)** | 동일 input 을 두 번 주면 동일 output 인가 | 동일 VMC replay 두 번 시 robot joint_pos 차이 < 1e-4 rad |

### 1.2 무엇이 정밀제어 검증의 입력 / 출력인가

```
입력 측:
  ① UDCAP 글러브 raw sensor data (UI 가 보여주는 것)         ← 검증 reference (ground truth)
  ② UDCAP VMC OSC bone quaternion (UDP 39539)               ← 우리가 받는 것
  ③ FourierHandMapper 의 11-vector per side                 ← 우리 처리 단계
  ④ pack_22d 의 22-vector (sign 적용)                       ← Pink IK action 입력
  ⑤ env.step() 후 robot.data.joint_pos 의 22 finger 값     ← 실제 robot 상태

출력 측:
  ⑥ Isaac Sim 뷰포트의 robot 손 시각                        ← 사용자 시각 검증
  ⑦ 시간계열 그래프 (Δ 메트릭 over time)                   ← 정량 검증
```

테스트는 **각 단계 ② ↔ ③ ↔ ④ ↔ ⑤** 사이의 충실도를 분리해서 측정.

### 1.3 §34 의 7 root cause 와 본 시스템의 매핑

| Cause | 어느 layer 에서 검출되는가 |
|---|---|
| C1 (UDCAP Skeletal 미작동) | Layer 4 — diagnose_udcap_dataflow 통합 |
| C2 (UDCAP Index curl 미작동) | Layer 4 — 동일 |
| C3 (UDCAP UI Space Plan 미스매치) | Layer 4 — controller pose Z stuck 검출 |
| C4 (Controller_Priority 잘못) | Layer 4 — finger source 가 idle 로 빠지는지 검출 |
| C5 (VMC bone REST POSE 비단위) | **Layer 1 — replay 로 즉결**. canned packet 입력 → mapper output 의 idle 시 nonzero 검사 |
| C6 (thumb yaw midpoint 버그) | **Layer 1 — yaw=0 input 일 때 output=0** 단위 검사 |
| C7 (mimic 임계값 너무 엄격) | **Layer 1 — intermediate slot 이 prox × 0.85 로 채워지는지** 단위 검사 |

→ **Layer 1 (offline replay) 만으로 7개 cause 중 3개를 1초 iteration 으로 검출**. 나머지는 Layer 4 의 live 환경에서.

```python
    "open_hand": {  # 모든 bone identity
```

→ 이 합성 데이터를 mapper 에 직접 던져서 **C5/C6/C7 즉시 검출**:

```python
def test_open_hand_outputs_zero():
    bones = synth_vmc.POSES["open_hand"]
    mapper = FourierHandMapper(vmc_subtract_rest=False)  # 합성이라 cal 불필요
    out = mapper.map_hand_vmc(bones, is_right=False)
    assert np.all(np.abs(out) < 0.05), f"open hand 가 nonzero output: {out}"

def test_full_fist_outputs_curl():
    bones = synth_vmc.POSES["full_fist"]
    mapper = FourierHandMapper(vmc_subtract_rest=False)
    out = mapper.map_hand_vmc(bones, is_right=False)
    # 4 finger proximal 모두 > 0.5 rad
    for i in range(4):
        assert out[i] > 0.5, f"finger {i} 가 fist 에 굽혀지지 않음: {out[i]}"
    # mimic 채워짐 — intermediate 도 prox × 0.85 ≈
    for prox_idx, int_idx in [(0,5), (1,6), (2,7), (3,8)]:
        assert abs(out[int_idx] - out[prox_idx] * 0.85) < 0.05, \
            f"mimic 안 채워짐 — prox={out[prox_idx]} int={out[int_idx]}"

def test_thumb_yaw_zero_at_rest():  # C6 검증
    bones = synth_vmc.POSES["open_hand"]
    mapper = FourierHandMapper()
    out = mapper.map_hand_vmc(bones, is_right=False)
    assert abs(out[4]) < 0.01, f"thumb yaw stuck at midpoint: {out[4]}"
```

### 3.1 목적

### 3.2 구성

```
ust_260502_win/
└── scripts/
    └── run_replay_headless.py   # Isaac Lab 부팅 + replay 입력 + headless 결과 dump
```

```python
"""Run Isaac Lab in headless mode, inject replayed VMC packets,
measure robot joint_pos response.

Usage:
    python -m ust_ws.ust_260502_win.scripts.run_replay_headless \
        --headless --replay tests/golden/full_fist.vmc.jsonl \
        --output results/headless_full_fist.hdf5

Output HDF5 schema:
    /timestamps         (T,)         frame timestamps
    /vmc_input          (T, N, 4)    raw VMC quat per bone (N bones)
    /mapper_output      (T, 22)      pack_22d output (signed)
    /action_taken       (T, 36)      36D Pink IK action sent to env
    /joint_pos_target   (T, 22)      finger joint target after Pink IK
    /joint_pos_actual   (T, 22)      actual finger joint pos after physics
    /joint_pos_limits   (22, 2)      URDF [lo, hi] per joint
"""
```

### 3.3 검증 메트릭 (HDF5 분석 스크립트)

```python
# tools/analyze_replay_hdf5.py
import h5py, numpy as np

with h5py.File("results/headless_full_fist.hdf5", "r") as f:
    target = f["/joint_pos_target"][:]    # (T, 22)
    actual = f["/joint_pos_actual"][:]    # (T, 22)
    limits = f["/joint_pos_limits"][:]    # (22, 2)

# 1. Tracking error (target vs actual)
err = np.abs(target - actual)
print(f"max tracking error: {err.max():.3f} rad")
print(f"per-joint mean error: {err.mean(axis=0)}")

# 2. Range coverage
ranges_actual = actual.max(axis=0) - actual.min(axis=0)   # (22,)
ranges_limit  = limits[:, 1] - limits[:, 0]               # (22,)
coverage = ranges_actual / np.abs(ranges_limit)
print(f"range coverage per joint: {coverage}")
print(f"[FAIL] joints with <30% coverage: {np.where(coverage < 0.3)[0]}")

# 3. Cross-correlation target vs actual (latency 추정)
from scipy.signal import correlate
for j in range(22):
    xc = correlate(target[:, j] - target[:, j].mean(),
                   actual[:, j] - actual[:, j].mean(), mode="full")
    lag = np.argmax(xc) - len(target) + 1
    print(f"joint {j} lag = {lag} frames ({lag * 1000 / 20:.0f} ms @ 20Hz)")
```

→ **Headless 자동화 가능 → CI 에서 실행, 회귀 검증**.

| range coverage (4 finger proximal) | > 0.5 |
| range coverage (thumb yaw) | > 0.4 |

```python
import isaaclab.sim as sim_utils

USER_HAND_MARKER_CFG = VisualizationMarkersCfg(
    prim_path="/Visuals/UserHandOverlay",
    markers={
        "fingertip": sim_utils.SphereCfg(
            radius=0.008,
            visual_material=sim_utils.PreviewSurfaceCfg(diffuse_color=(0, 1, 1)),  # cyan
        ),
        "joint": sim_utils.SphereCfg(
            radius=0.005,
            visual_material=sim_utils.PreviewSurfaceCfg(diffuse_color=(0.5, 0.5, 1.0)),
        ),
    },
)


class UserHandOverlay:
    def __init__(self):
        self._markers = VisualizationMarkers(USER_HAND_MARKER_CFG)

    def update_from_vmc_bones(self, bones_left, bones_right, base_link_pos_w):
        """Forward-kinematic compute 32 sphere positions from VMC quats,
        place them ~30cm next to robot's base for side-by-side comparison."""
        positions = []
        marker_indices = []
        for side in ("left", "right"):
            offset = np.array([0, 0.4 if side=="left" else -0.4, 1.2])
            kinematic_chain_positions = self._fk_from_vmc(
                bones_left if side=="left" else bones_right
            )  # (32, 3)
            positions.append(base_link_pos_w + offset + kinematic_chain_positions)
            marker_indices.extend([0]*5 + [1]*27)  # 5 fingertips + 27 joints
        positions = np.concatenate(positions)
        self._markers.visualize(translations=positions, marker_indices=marker_indices)
```

→ Isaac Sim 뷰포트에 robot 옆에 **사용자 손 spheres skeleton** 이 보이고, robot 손이 그것과 일치하게 움직이는지 시각적으로 즉시 확인.

```python
class FingerDashboard:

        rr.set_time_sequence("frame", t)
        for j, name in enumerate(FOURIER_HAND_JOINT_NAMES):
            rr.log(f"finger/target/{name}", rr.Scalar(float(target_22[j])))
            rr.log(f"finger/actual/{name}", rr.Scalar(float(actual_22[j])))

                rr.log(f"vmc/{bone_name}/bend_rad", rr.Scalar(float(qmag)))

    def push_3d_hand(self, hand_3d_points, side="left"):

               rr.Points3D(hand_3d_points, radii=0.005))
```

### 5.3 사용자 5-pose 검증 프로토콜

각 pose 30초 hold + 5초 transition:

| Pose | 자세 | 검증 포인트 |
|---|---|---|
| 1) **Rest / Open hand** | 5 손가락 자연스럽게 펴짐 | mapper output 모두 < 0.05 (rest cal 정상) |
| 2) **Full fist** | 모든 손가락 90° 굽힘 | 4 finger proximal > 0.5, intermediate ≈ prox × 0.85 |
| 3) **Point index** | 검지 펴고 나머지 fist | index_prox < 0.1, mid/ring/pinky > 0.5 |
| 4) **Pinch (thumb + index)** | 엄지 + 검지 끝이 닿음 | thumb_yaw > 0, thumb_pitch > 0, index_prox > 0.4 |
| 5) **OK sign** | 엄지+검지 원, 나머지 펴짐 | thumb opposition + index curl + 나머지 ≈ 0 |
| 6) **Thumb opposition (yaw)** | 엄지만 좌우로 흔들기 | thumb_yaw 좌·우 평행 변동, pitch ≈ 0 |

각 pose 의 stable region (마지막 5초) 의 평균 22D 출력을 capture → 다음 회귀 실행 시 비교 baseline.

## 6. 지속적 디버깅 — Hot Reload + Iteration

### 6.1 Iteration 시간 단축 — 4단계 사다리

| 사다리 | 도구 | iteration 시간 | 적용 시점 |
|---|---|---|---|
| 1 | unit pytest (Layer 1) | < 5초 | 코드 줄 변경 마다 |
| 2 | smoke test | ~10초 | 모듈 단위 변경 |
| 3 | headless replay (Layer 2) | ~60초 (Isaac Sim 부팅) | 매핑/액션/USD 변경 |
| 4 | live + dashboard (Layer 3/4) | ~5분 (사용자 자세) | 통합 검증 |

→ 전체 작업 시간의 80% 는 사다리 1 (5초 iter) 에서 잡힘. 90% 는 사다리 2 까지.

### 6.2 Hot reload 워크플로 (Isaac Sim 부팅 한 번 + 코드 reload)

Isaac Sim 의 Extension 시스템이 **hot-reload** 지원.  scripted run_teleop 도 다음 패턴으로 가능:

```python
# scripts/run_live_validation.py 의 main loop 안:
import importlib
from ust_ws.ust_fourier_260421.teleop import fourier_hand_mapper

while sim_app.is_running():
    if check_hot_reload_signal():    # e.g. 파일 mtime watcher
        importlib.reload(fourier_hand_mapper)
        device._mapper = fourier_hand_mapper.FourierHandMapper(...)
        print("[hot-reload] mapper 재초기화")

    action = device.advance()
    env.step(action)
```

→ Isaac Sim 부팅 한 번 (~30초) 후 mapper 코드 변경 시 부팅 없이 즉시 적용.

### 6.3 라이브 진단 단축 (관찰 → 가설 → 주입 → 검증)

```
[관찰]   rerun dashboard 에서 R_thb_pitch 가 0 stuck
   │
[가설]   thumb_pitch 의 _quat_to_bend 결과가 0?
   │
[주입]   rerun 에 한 줄 추가: rr.log("debug/thumb_pitch_raw", float(_quat_to_bend(thumb_mcp)))
   │     코드 저장 → hot reload → 다음 frame 부터 dashboard 에 보임
   │
[검증]   값이 0.7 인데 매핑 후 0 → mapper 후처리에서 잘림
   │
[수정]   _amplify(thumb_pitch, scale=2.5) 의 clamp 확인 → fix
```

이 4 step 을 < 1분 안에 완료할 수 있는 환경이 본 시스템의 목표.

### 6.4 에러 발생 시 자동 데이터 캡처

```python
# scripts/run_live_validation.py 의 except 블록:
except Exception as exc:
    crash_dir = Path(f"crashes/{datetime.now():%Y-%m-%d_%H%M%S}")
    crash_dir.mkdir(parents=True, exist_ok=True)
    # 직전 100 프레임의 모든 데이터 dump
    np.save(crash_dir / "last_100_frames.npy", logger.last_n(100))
    # rerun 세션 저장
    rr.save(str(crash_dir / "crash.rrd"))
    # VMC 마지막 5초 dump
    vmc_recorder.flush(crash_dir / "last_5s.vmc.jsonl")
    raise
```

→ 어떤 에러든 직전 5초의 모든 입력/출력이 디스크에 보존 → 디버깅 ↑

## 10. 검증 기준 — 무엇이 "정밀제어 매칭" 인가

### 10.1 정량 통과 기준 (모두 만족 시 "매칭됨" 선언)

| 메트릭 | 기준 | 측정 layer |
|---|---|---|
| 5-pose 시퀀스의 mapper output 라벨 일치 | 6/6 pose 가 fixture 와 ±0.1 rad 안 | Layer 1 |
| Headless replay 의 max tracking error | < 0.1 rad | Layer 2 |
| Range coverage (4 finger proximal 좌·우) | > 0.5 (8/8) | Layer 2 |
| Range coverage (thumb yaw + pitch 좌·우) | > 0.4 (4/4) | Layer 2 |
| Latency (target → actual) | < 5 frame (250ms) | Layer 2 |
| Per-finger isolation (point index pose) | non-target finger Δ < 0.1 rad | Layer 1 |
| Symmetry (left vs right at full fist) | \|left - right\| < 0.3 rad average | Layer 1 |
| Determinism (same VMC twice) | joint_pos 차이 < 1e-3 rad | Layer 2 |

### 10.2 정성 통과 기준

| 메트릭 | 기준 |
|---|---|

| In-sim user hand overlay | robot 손과 user hand spheres 가 정렬되어 보임 |
| rerun dashboard | 22 joint 모두 변동 보임, frozen pattern 없음 |

### 10.3 통과 시점에 적어두는 것
