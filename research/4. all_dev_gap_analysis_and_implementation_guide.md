현재 구현은 **TurtleBot3 Waffle Pi (2륜 차동 구동)** 기반으로 잘 동작하도록 작성되었으나, all_dev.md는 **커스텀 4륜 Skid-Steer 모바일 베이스**를 기반으로 설계되어 있습니다. 이 차이로 인해 여러 파라미터와 구조가 불일치합니다.

**판단**: 현재 TurtleBot3 기반이 실제 하드웨어에 맞으므로, all_dev.md의 설계 중 **TurtleBot3와 호환되는 항목만 반영**하고, 4륜 Skid-Steer 관련 항목은 향후 커스텀 베이스 제작 시 반영하는 것을 권장합니다.

## 3. 카테고리별 상세 분석

### 3.1 로봇 구성 (ArticulationCfg)

#### all_dev.md 스펙 (MOBILE_MANIPULATOR_CFG)
```python
# 스펙에서 지정한 값
actuators = {
    "wheels": ImplicitActuatorCfg(
        joint_names_expr=["wheel_.*"],
        stiffness=0.0, damping=1e4,
        effort_limit_sim=20.0, velocity_limit_sim=10.0,
    ),
    "arm": ImplicitActuatorCfg(
        joint_names_expr=["joint[1-4]"],
        stiffness=80.0, damping=4.0,           # ← 핵심 차이
        effort_limit_sim=10.0, velocity_limit_sim=2.0,
    ),
    "gripper": ImplicitActuatorCfg(
        joint_names_expr=["gripper.*"],
        stiffness=200.0, damping=10.0,
        effort_limit_sim=5.0, velocity_limit_sim=0.5,
    ),
}
```

#### 현재 구현 (UST_MOBILE_MANIPULATOR_CFG)
```python
# 현재 구현 값
actuators = {
    "wheels": ImplicitActuatorCfg(
        joint_names_expr=["wheel_.*_joint"],
        stiffness=0.0, damping=1e4,             # ✅ 일치
        effort_limit=20.0, velocity_limit=30.0,  # ⚠️ velocity_limit 차이: 10→30
    ),
    "arm": ImplicitActuatorCfg(
        joint_names_expr=["joint[1-4]"],
        stiffness=100.0, damping=10.0,           # ❌ 차이: 80→100, 4→10
        effort_limit=10.0, velocity_limit=4.8,   # ⚠️ velocity_limit 차이: 2→4.8
    ),
    "gripper": ImplicitActuatorCfg(
        joint_names_expr=["gripper_.*_joint"],
        stiffness=200.0, damping=10.0,           # ✅ 일치
        effort_limit=5.0, velocity_limit=0.5,    # ✅ 일치
    ),
}
```

**수정 필요 여부 분석**:
- `arm stiffness/damping`: 스펙(80/4) vs 현재(100/10). 스펙의 값은 일반적 로봇 값이고, 현재 값은 TurtleBot3+OpenMANIPULATOR-X에 맞게 튜닝된 것으로 보임. **시뮬레이션 테스트 후 결정** 권장
- `velocity_limit`: 스펙의 값이 더 보수적. 현재 값이 실제 모터 스펙에 가까울 가능성 높음
- `joint_names_expr`: 패턴 차이는 USD 모델의 조인트명에 따라 달라야 하므로 현재 구현이 올바름

### 3.2 Lula IK 솔버

#### all_dev.md 스펙
```python
# Lula IK 사용
from isaacsim.robot_motion.motion_generation import (
    LulaKinematicsSolver,
    ArticulationKinematicsSolver
)

class OpenManipulatorIK:
    def __init__(self, robot_articulation):
        self.kinematics_solver = LulaKinematicsSolver(
            robot_description_path="./config/openmanipulator_descriptor.yaml",
            urdf_path="./assets/open_manipulator_x.urdf"
        )
        self.articulation_kinematics = ArticulationKinematicsSolver(
            robot_articulation, self.kinematics_solver, "end_effector_link"
        )
```

#### 현재 구현

**260207_ust/config/ust_actions_cfg.py에서는 Differential IK (DLS) 사용:**
```python
arm_action = mdp.DifferentialInverseKinematicsActionCfg(
    controller=mdp.DifferentialIKControllerCfg(
        command_type="pose",
        ik_method="dls",
        ik_params={"lambda_val": 0.05},
    ),
)
```

**ust_project1/scripts/ik_controller.py에서는 Lula IK 이미 구현됨:**
```python
from omni.isaac.motion_generation import LulaKinematicsSolver
# open_x1_des.yaml + open_manipulator_x.urdf 사용
```

**분석**:
- Lula IK는 `ust_project1`에 이미 구현되어 있으나 `260207_ust`에 통합되지 않음
- `open_x1_des.yaml`도 존재 (cspace: joint1-4, gripper fixed)
- DLS Differential IK는 Isaac Lab의 ManagerBasedEnv에서 기본 지원하는 방식
- **Lula는 RMPflow 기반 모션 플래닝에 유리하고, DLS는 실시간 텔레오퍼레이션에 적합**
- 현재 텔레오퍼레이션 + 모방학습 파이프라인에서는 DLS가 더 적합할 수 있음

**권장**: 두 가지 IK 모드를 모두 지원하도록 설정 파일에 옵션 추가

### 3.4 텔레오퍼레이션 장치 설정

#### all_dev.md 스펙
```python
# Se3AbsRetargeter (절대 좌표 기반)
position_retargeter = Se3AbsRetargeter(
    Se3AbsRetargeterCfg(
        bound_hand=DeviceBase.TrackingTarget.HAND_RIGHT,
        zero_out_xy_rotation=True,
        use_wrist_position=False,    # ← 핀치 포지션 사용
        use_wrist_rotation=True,
        enable_visualization=True,
    )
)
```

#### 현재 구현
```python
# Se3RelRetargeter (상대 좌표/델타 기반)
arm_retargeter = Se3RelRetargeter(
    Se3RelRetargeterCfg(
        bound_hand=DeviceBase.TrackingTarget.HAND_RIGHT,
        zero_out_xy_rotation=True,   # ✅ 일치
        use_wrist_position=True,      # ❌ 차이 (스펙: False)
        use_wrist_rotation=True,      # ✅ 일치
        delta_pos_scale_factor=10.0,  # ❌ 스펙에 없는 파라미터
        delta_rot_scale_factor=10.0,  # ❌ 스펙에 없는 파라미터
    )
)
```

**핵심 차이점**:

| 파라미터 | all_dev.md | 현재 구현 | 영향 |
|----------|-----------|-----------|------|
| Retargeter 타입 | **Se3AbsRetargeter** | **Se3RelRetargeter** | 제어 방식이 근본적으로 다름 |
| use_wrist_position | False (핀치 위치) | True (손목 위치) | 정밀도 차이 |
| scale factor | 미명시 | 10.0 (pos/rot) | 민감도에 영향 |

**Se3Abs vs Se3Rel 차이**:
- **Se3AbsRetargeter**: 손의 절대 위치 → 로봇 EE 절대 위치 (직접 매핑)
- **Se3RelRetargeter**: 손의 변화량(delta) → EE 위치 변화 (상대 이동)
- 텔레오퍼레이션에서 Se3Rel이 더 직관적이고 안정적 (workspace 불일치 방지)
- all_dev.md는 IK 컨트롤러가 `use_relative_mode=False`인 경우를 전제

**권장**:
- 현재 `Se3RelRetargeter` + `use_relative_mode=True` 조합이 텔레오퍼레이션에 적합
- 다만 `use_wrist_position=False`로 변경하면 핀치 위치 기반 제어가 되어 정밀 조작에 유리
- all_dev.md 스펙 반영 시 **Se3AbsRetargeter** + `use_relative_mode=False` 조합으로 전환 가능 (옵션)

### 3.5 액션 공간

#### all_dev.md 스펙: 11D
```
[arm_pose(6)] + [gripper(1)] + [base_vel(4)]
= 6 + 1 + 4 = 11D
```

#### 현재 구현: 9D
```
[arm_delta_pose(6)] + [gripper(1)] + [base_vel(2)]
= 6 + 1 + 2 = 9D
```

**분석**: 차이는 오직 베이스 차원(4D vs 2D)에서 발생. 이는 4륜(FL,FR,RL,RR) vs 2륜(L,R) 차이에서 기인. TurtleBot3 기반이므로 2D가 올바름.

### 3.6 관측 공간

joint_pos_rel + joint_vel_rel + ee_pos + ee_quat + gripper_pos

## 6. Phase 2: Lula IK 통합

### 6.1 새 파일 생성: `config/lula_ik_cfg.py`

`ust_project1/scripts/ik_controller.py`를 기반으로 Isaac Lab ManagerBasedEnv에 통합 가능한 형태로 래핑합니다.

```python
# config/lula_ik_cfg.py
"""Lula IK 솔버 설정 및 래퍼.

all_dev.md 스펙에 따른 Lula IK 통합.
ust_project1/scripts/ik_controller.py 기반.

사용법:
    from config.lula_ik_cfg import LulaIKWrapper

    ik = LulaIKWrapper(robot_articulation)
    action, success = ik.compute_ik(target_pos, target_rot)
"""

from __future__ import annotations

import os
import numpy as np
from dataclasses import dataclass
from typing import Optional, Tuple

# 설정 파일 경로
CONFIG_DIR = os.path.join(os.path.dirname(os.path.abspath(__file__)))
DEFAULT_ROBOT_DESC = os.path.join(CONFIG_DIR, "open_x1_des.yaml")
DEFAULT_URDF = os.path.join(CONFIG_DIR, "open_manipulator_x.urdf")


@dataclass
class LulaIKConfig:
    """Lula IK 설정."""
    robot_description_path: str = DEFAULT_ROBOT_DESC
    urdf_path: str = DEFAULT_URDF
    end_effector_frame: str = "end_effector_link"
    max_iterations: int = 200
    # 작업 공간 제한 (미터)
    workspace_min_radius: float = 0.08
    workspace_max_radius: float = 0.38
    workspace_min_height: float = -0.05
    workspace_max_height: float = 0.40


class LulaIKWrapper:
    """OpenMANIPULATOR-X Lula IK 래퍼 클래스.

    all_dev.md 스펙의 OpenManipulatorIK 클래스 구현.
    Isaac Sim의 LulaKinematicsSolver를 래핑하여
    ManagerBasedEnv에서 사용 가능한 인터페이스를 제공합니다.

    참고: 이 클래스는 Isaac Sim 런타임에서만 사용 가능합니다.
    (isaacsim.robot_motion.motion_generation 모듈 필요)
    """

    def __init__(self, robot_articulation, cfg: LulaIKConfig = None):
        """초기화.

        Args:
            robot_articulation: Isaac Sim Articulation 또는 Isaac Lab ArticulationData
            cfg: Lula IK 설정
        """
        self.cfg = cfg or LulaIKConfig()

        # Isaac Sim 5.1.0 API 경로 (all_dev.md 스펙)
        try:
            from isaacsim.robot_motion.motion_generation import (
                LulaKinematicsSolver,
                ArticulationKinematicsSolver,
            )
        except ImportError:
            # 구버전 fallback
            from omni.isaac.motion_generation import (
                LulaKinematicsSolver,
                ArticulationKinematicsSolver,
            )

        # Lula 솔버 초기화
        self.kinematics_solver = LulaKinematicsSolver(
            robot_description_path=self.cfg.robot_description_path,
            urdf_path=self.cfg.urdf_path,
        )

        # 프레임 확인
        self.available_frames = self.kinematics_solver.get_all_frame_names()
        print(f"[LulaIK] Available frames: {self.available_frames}")

        # EE 프레임 검증
        ee_frame = self.cfg.end_effector_frame
        if ee_frame not in self.available_frames:
            ee_frame = self.available_frames[-1]
            print(f"[LulaIK] Fallback EE frame: {ee_frame}")

        # ArticulationKinematicsSolver 래핑
        self.articulation_kinematics = ArticulationKinematicsSolver(
            robot_articulation, self.kinematics_solver, ee_frame
        )

    def compute_ik(
        self,
        target_position: np.ndarray,
        target_orientation: Optional[np.ndarray] = None,
        robot_articulation=None,
    ) -> Tuple[object, bool]:
        """IK 계산 및 적용.

        Args:
            target_position: [x, y, z] 미터 단위
            target_orientation: [w, x, y, z] 쿼터니언 (None이면 위치만)
            robot_articulation: 모바일 베이스 포즈 업데이트용

        Returns:
            (action, success) 튜플
        """
        # 모바일 베이스 포즈 업데이트
        if robot_articulation is not None:
            base_pos, base_rot = robot_articulation.get_world_pose()
            self.kinematics_solver.set_robot_base_pose(base_pos, base_rot)

        # IK 계산 (4축: orientation=None이면 위치만)
        action, success = self.articulation_kinematics.compute_inverse_kinematics(
            target_position=target_position,
            target_orientation=target_orientation,
        )

        if success and action is not None and robot_articulation is not None:
            robot_articulation.apply_action(action)

        return action, success

    def compute_fk(self, joint_positions: np.ndarray) -> Tuple[np.ndarray, np.ndarray]:
        """순기구학 계산."""
        position, rotation_matrix = self.kinematics_solver.compute_forward_kinematics(
            frame_name=self.cfg.end_effector_frame,
            joint_positions=joint_positions,
        )
        return position, rotation_matrix
```

def create_ust_teleop_device(
    cfg: USTTeleopDeviceCfg,
    sim_device: str = "cuda:0",
    retargeter_type: str = "rel",  # "rel" 또는 "abs" (all_dev.md 스펙)

    """UST VR 텔레오퍼레이션 장치 생성.

    Args:
        cfg: 장치 설정
        sim_device: CUDA 디바이스
        retargeter_type: "rel" (Se3RelRetargeter, 기본) 또는
                        "abs" (Se3AbsRetargeter, all_dev.md 스펙)
    """
    try:
        from isaaclab.devices import OpenXRDevice, OpenXRDeviceCfg
        from isaaclab.devices.openxr import XrCfg
        from isaaclab.devices.openxr.retargeters import (
            Se3RelRetargeter, Se3RelRetargeterCfg,
            GripperRetargeter, GripperRetargeterCfg,
        )
        from isaaclab.devices import DeviceBase

        xr_cfg = XrCfg(
            anchor_pos=list(cfg.xr_anchor_pos),
            anchor_rot=list(cfg.xr_anchor_rot),
        )

        # 리타게터 타입에 따라 분기
        if retargeter_type == "abs":
            # all_dev.md 스펙: Se3AbsRetargeter
            from isaaclab.devices.openxr.retargeters import (
                Se3AbsRetargeter, Se3AbsRetargeterCfg,
            )
            arm_retargeter = Se3AbsRetargeter(
                Se3AbsRetargeterCfg(
                    bound_hand=DeviceBase.TrackingTarget.HAND_RIGHT,
                    zero_out_xy_rotation=cfg.zero_out_xy_rotation,
                    use_wrist_position=cfg.use_wrist_position,
                    use_wrist_rotation=cfg.use_wrist_rotation,
                    enable_visualization=cfg.enable_visualization,
                )
            )
        else:
            # 현재 기본: Se3RelRetargeter
            arm_retargeter = Se3RelRetargeter(
                Se3RelRetargeterCfg(
                    bound_hand=DeviceBase.TrackingTarget.HAND_RIGHT,
                    zero_out_xy_rotation=cfg.zero_out_xy_rotation,
                    use_wrist_position=cfg.use_wrist_position,
                    use_wrist_rotation=cfg.use_wrist_rotation,
                    delta_pos_scale_factor=cfg.delta_pos_scale,
                    delta_rot_scale_factor=cfg.delta_rot_scale,
                    alpha_pos=cfg.alpha_smoothing,
                    alpha_rot=cfg.alpha_smoothing,
                    enable_visualization=cfg.enable_visualization,
                    sim_device=sim_device,
                )
            )

        gripper_retargeter = GripperRetargeter(
            GripperRetargeterCfg(
                bound_hand=DeviceBase.TrackingTarget.HAND_RIGHT,
                sim_device=sim_device,
            )
        )

        device = OpenXRDevice(
            OpenXRDeviceCfg(xr_cfg=xr_cfg),
            retargeters=[arm_retargeter, gripper_retargeter],
        )
        print(f"[INFO] OpenXR device created (retargeter: {retargeter_type}).")
        return device

    except ImportError as e:
        print(f"[WARNING] OpenXR not available: {e}")
        return create_fallback_keyboard_device()

                       help="태스크 이름")
    parser.add_argument("--output_dir", type=str, default="./trained_models",

            print(f"      --dataset {args.dataset}")

    except Exception as e:
        print(f"[ERROR] Training failed: {e}")
        print("\nManual training command:")
        print(f"  python -m robomimic.scripts.train --config {output_dir}/config_{args.algo}_{args.task}.json")
        sys.exit(1)


if __name__ == "__main__":
    main()

## 9. Phase 5: 물리 속성 튜닝

### 9.1 새 파일 생성: `utils/physics_setup.py` (선택적)

all_dev.md에서 정의한 물리 속성 설정 유틸리티. USD 파일을 직접 수정하는 대신 런타임에 적용합니다.

```python
# utils/physics_setup.py
"""물리 속성 설정 유틸리티.

all_dev.md 스펙의 create_wheel_material(), set_mass() 등 구현.
USD 파일에 이미 설정된 경우 이 모듈은 불필요합니다.

사용법 (Isaac Sim Script Editor 또는 standalone script):
    from utils.physics_setup import apply_physics_properties
    apply_physics_properties(stage)
"""

from __future__ import annotations


def create_wheel_material(stage, friction: float = 0.8):
    """바퀴용 물리 재질 생성 (all_dev.md 스펙)."""
    from pxr import UsdShade, UsdPhysics

    material_path = "/World/Materials/WheelMaterial"
    UsdShade.Material.Define(stage, material_path)
    material = UsdPhysics.MaterialAPI.Apply(stage.GetPrimAtPath(material_path))
    material.CreateStaticFrictionAttr().Set(friction)
    material.CreateDynamicFrictionAttr().Set(friction)
    material.CreateRestitutionAttr().Set(0.1)
    return material_path


def set_mass(stage, prim_path: str, mass: float, com: tuple = None):
    """질량 및 무게중심 설정 (all_dev.md 스펙)."""
    from pxr import UsdPhysics, Gf

    mass_api = UsdPhysics.MassAPI.Apply(stage.GetPrimAtPath(prim_path))
    mass_api.CreateMassAttr().Set(mass)
    if com:
        mass_api.CreateCenterOfMassAttr().Set(Gf.Vec3f(*com))


def setup_velocity_drive(stage, joint_path: str, damping: float = 1e4,
                         max_force: float = 1e6):
    """속도 제어용 Angular Drive 설정 (all_dev.md 스펙)."""
    from pxr import UsdPhysics

    joint_prim = stage.GetPrimAtPath(joint_path)
    drive = UsdPhysics.DriveAPI.Apply(joint_prim, "angular")
    drive.CreateTypeAttr().Set("force")
    drive.CreateDampingAttr().Set(damping)
    drive.CreateStiffnessAttr().Set(0)
    drive.CreateMaxForceAttr().Set(max_force)
    drive.CreateTargetVelocityAttr().Set(0)
    return drive


def apply_physics_properties(stage, robot_path: str = "/World/Robot"):
    """로봇에 물리 속성 일괄 적용.

    Args:
        stage: USD Stage
        robot_path: 로봇 루트 경로
    """
    # 바퀴 재질
    wheel_material = create_wheel_material(stage, friction=0.8)

    # 질량 설정 (TurtleBot3 기준)
    set_mass(stage, f"{robot_path}/base_link", mass=1.5, com=(0, 0, -0.02))

    # 바퀴 질량
    for wheel in ["wheel_left_link", "wheel_right_link"]:
        set_mass(stage, f"{robot_path}/{wheel}", mass=0.1)

    print("[PhysicsSetup] Properties applied.")
```
