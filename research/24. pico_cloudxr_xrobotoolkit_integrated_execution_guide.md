> **날짜**: 2026-04-05
> **기반 문서**: `19. corrective_teaching_pico_udcap_migration_guide.md`, `23. pico_isaac_lab_connection_architecture_analysis.md`, `Step 1 CloudXR Runtime.txt`

### Step 1: CloudXR Runtime Docker 시작 (호스트 터미널 1)

```bash
# ─── 호스트에서 실행 (터미널 1) ───

cd ~/ust_ws

# openxr 공유 디렉토리 생성 (처음만)
mkdir -p /home/jyp/ust_ws/openxr

# 기존 컨테이너 정리
docker stop ust-cloudxr-runtime 2>/dev/null
docker rm ust-cloudxr-runtime 2>/dev/null

# CloudXR Runtime 시작
docker run -it --rm \
    --name ust-cloudxr-runtime \
    --privileged \
    --network host \
    --gpus=all \
    -e "ACCEPT_EULA=Y" \
    --mount "type=bind,src=/home/jyp/ust_ws/openxr,dst=/openxr" \
    nvcr.io/nvidia/cloudxr-runtime-early-access:6.0.1-webrtc

# → "CloudXR Runtime started" 메시지 확인
# → 이 터미널은 열어둔 채로 유지 (Ctrl+C = 종료)
```

**확인**: IPC 소켓 생성됨
```bash
# 다른 터미널에서:
ls -la /home/jyp/ust_ws/openxr/run/ipc_cloudxr
# → 파일이 존재하면 성공
```

### Step 3: WSS Proxy + CloudXR.js 웹서버 시작 (호스트 터미널 3)

```bash

# 3-1. WSS Proxy 시작

docker run -d --name wss-proxy \
    --network host \
    -e BACKEND_HOST=127.0.0.1 \
    -e BACKEND_PORT=49100 \
    -e PROXY_PORT=48322 \
    cloudxr-wss-proxy

curl -k https://localhost:48322/ 2>&1 | head -3
```

### Step 4: XRoboToolkit + 통합 브릿지 시작 (호스트 터미널 4)

```bash
# ─── 호스트에서 실행 (터미널 4) ───

# 4-1. XRoboToolkit PC Service 시작
XRT_DIR="$HOME/ust_ws/XRoboToolkit-PC-Service/RoboticsService"

# .deb로 설치한 경우:
/opt/apps/roboticsservice/runService.sh &

# 또는 소스 빌드한 경우:
export LD_LIBRARY_PATH="${LD_LIBRARY_PATH:+$LD_LIBRARY_PATH:}$XRT_DIR/Redistributable/linux:$XRT_DIR/Redistributable/linux/grpc/lib"
cd "$XRT_DIR" && ./bin/RoboticsServiceProcess &

echo "[XRT] PC Service 시작됨"

# 4-2. ConsoleDemo (XRT → TCP JSON 브릿지)
cd "$XRT_DIR/Redistributable/linux"
./ConsoleDemo &
echo "[XRT] ConsoleDemo 브릿지 시작됨 (TCP :7777)"

# 4-3. 통합 브릿지 (XRT + UDCAP → Isaac Lab)
cd ~/ust_ws/ust_260220
python3 teleop/unified_bridge.py \
    --xrt_port 7777 \
    --vmc_port 39539 \
    --output_port 8888 &

echo "[Bridge] 통합 브릿지 시작됨 (TCP :8888)"
```

## 6. 빠른 시작 스크립트 (한 번에 실행)

### 6.1 호스트 전체 서비스 시작 (터미널 1개로)

```bash
#!/bin/bash
# start_all_services.sh - 호스트에서 실행
# 사용법: source start_all_services.sh

echo "===== PICO VR Teleop 전체 서비스 시작 ====="
HOST_IP=$(hostname -I | awk '{print $1}')

# [1] CloudXR Runtime (백그라운드)
echo "[1/6] CloudXR Runtime..."
docker stop ust-cloudxr-runtime 2>/dev/null; docker rm ust-cloudxr-runtime 2>/dev/null
docker run -d --rm \
    --name ust-cloudxr-runtime \
    --privileged --network host --gpus=all \
    -e "ACCEPT_EULA=Y" \
    --mount "type=bind,src=/home/jyp/ust_ws/openxr,dst=/openxr" \
    nvcr.io/nvidia/cloudxr-runtime-early-access:6.0.1-webrtc
echo "  CloudXR Runtime 시작됨"

# IPC 소켓 대기 (최대 30초)
echo "  IPC 소켓 대기 중..."
for i in $(seq 1 30); do
    [ -e "/home/jyp/ust_ws/openxr/run/ipc_cloudxr" ] && break
    sleep 1
done
echo "  IPC 소켓 준비됨"

# [2] XRoboToolkit PC Service
echo "[2/6] XRoboToolkit PC Service..."
if ! pgrep -f "RoboticsServiceProcess" > /dev/null; then
    XRT_DIR="$HOME/ust_ws/XRoboToolkit-PC-Service/RoboticsService"
    export LD_LIBRARY_PATH="${LD_LIBRARY_PATH:+$LD_LIBRARY_PATH:}$XRT_DIR/Redistributable/linux:$XRT_DIR/Redistributable/linux/grpc/lib"
    cd "$XRT_DIR" && ./bin/RoboticsServiceProcess &
    cd ~
fi
echo "  XRoboToolkit 실행 중"

# [3] ConsoleDemo 브릿지
echo "[3/6] ConsoleDemo..."
if ! pgrep -f "ConsoleDemo" > /dev/null; then
    XRT_DIR="$HOME/ust_ws/XRoboToolkit-PC-Service/RoboticsService"
    cd "$XRT_DIR/Redistributable/linux" && ./ConsoleDemo &
    cd ~
fi
echo "  ConsoleDemo 실행 중"

# [4] 통합 브릿지
echo "[4/6] 통합 브릿지..."
if ! pgrep -f "unified_bridge" > /dev/null; then
    python3 ~/ust_ws/ust_260220/teleop/unified_bridge.py \
        --xrt_port 7777 --vmc_port 39539 --output_port 8888 &
fi
echo "  통합 브릿지 실행 중 (TCP :8888)"

# [5] WSS Proxy (Isaac Lab 시작 후에 필요하지만 미리 준비)
echo "[5/6] WSS Proxy..."
docker stop wss-proxy 2>/dev/null; docker rm wss-proxy 2>/dev/null
docker run -d --name wss-proxy --network host \
    -e BACKEND_HOST=127.0.0.1 -e BACKEND_PORT=49100 -e PROXY_PORT=48322 \
    cloudxr-wss-proxy
echo "  WSS Proxy 준비됨 (Isaac Lab 49100 리스닝 후 활성화)"

# [6] CloudXR.js 웹서버
echo "[6/6] CloudXR.js 웹서버..."
cd ~/ust_ws/cloudxr_js/isaac
npm run dev-server:https &
cd ~
echo "  CloudXR.js 실행 중 (HTTPS :8080)"

echo ""
echo "===== 전체 서비스 시작 완료 ====="
echo ""
echo "다음 단계:"
echo "  1. Docker Isaac Lab에서 실행:"
echo "     export XDG_RUNTIME_DIR=/workspace/isaaclab/ust_ws/openxr/run"
echo "     export XR_RUNTIME_JSON=/workspace/isaaclab/ust_ws/openxr/share/openxr/1/openxr_cloudxr.json"
echo "     export IPC_IGNORE_VERSION=1"
echo "     ./isaaclab.sh -p ust_ws/ust_260220/scripts/run_teleop.py --teleop_device pico --use_usd_scene"
echo ""
echo "  2. PICO에서 XRoboToolkit App → $HOST_IP 연결"
echo "  3. PICO 브라우저 → https://$HOST_IP:48322/ 인증서 수락"
echo "  4. PICO 브라우저 → https://$HOST_IP:8080/ CloudXR 연결"
echo ""
echo "  전체 종료: pkill -f 'RoboticsServiceProcess|ConsoleDemo|unified_bridge'"
echo "            docker stop ust-cloudxr-runtime wss-proxy"
```

## 7. 트러블슈팅

| 증상 | 원인 | 해결 |
|------|------|------|
| Isaac Lab 시작 시 XR 오류 | CloudXR Runtime 미실행 | Step 1 먼저 실행 확인 |
| 49100 포트 미리스닝 | Isaac Sim 로딩 중 | 1-2분 대기 |
| WSS Proxy 502 오류 | 49100 미준비 상태에서 프록시 시작 | Isaac Lab 로딩 완료 후 `docker restart wss-proxy` |
| PICO 브라우저 연결 실패 | 인증서 미수락 | `https://호스트IP:48322/` 먼저 접속하여 인증서 수락 |
| XRoboToolkit 연결 안됨 | 다른 WiFi 또는 방화벽 | 동일 5GHz WiFi 확인, `ufw allow 7777` |
| UDCAP 데이터 없음 | VMC 설정 오류 | 미니PC VMC 대상 IP/포트 확인 |
| advance()가 None 반환 | 통합 브릿지 미연결 | Step 4 프로세스 확인 |
| VR 화면은 보이는데 로봇 안 움직임 | XRoboToolkit 미연결 | Step 6 XRoboToolkit App 확인 |
| 로봇 움직이는데 VR 화면 없음 | CloudXR 미연결 | Step 7 브라우저 연결 확인 |
