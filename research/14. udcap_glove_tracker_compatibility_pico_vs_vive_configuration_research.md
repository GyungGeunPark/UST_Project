## 1. UDCAP VR Gloves + 팔뚝 트래커: 반드시 필요한가?

### 1.1 UDCAP의 트래킹 아키텍처

UDCAP VR Gloves의 센서는 **손가락 관절 각도만** 측정한다:

```
UDCAP VR Glove 센서 구성:
┌──────────────────────────────────────┐
│  12개 Elastic Sensor (0.1mm 두께)     │
│  → 15개 손가락 관절 추적               │
│  → 21개 관절각(joint angles) 출력      │
│  → 0.01° 해상도                       │
│                                      │
│  ※ 추적하는 것:                       │
│  ✓ 각 손가락의 굽힘(flexion)           │
│  ✓ 손가락 벌림(abduction)              │
│  ✓ 엄지 대립(opposition)              │
│                                      │
│  ※ 추적하지 않는 것:                   │
│  ✗ 손의 3D 위치 (x, y, z)             │
│  ✗ 손/손목의 방향 (roll, pitch, yaw)   │
│  ✗ 팔꿈치/어깨 위치                    │
│  ✗ 손목 관절 각도                      │
└──────────────────────────────────────┘
```

**핵심**: UDCAP은 **카메라나 IMU가 내장되어 있지 않다**. 순수하게 elastic (신축) 센서만으로 손가락 관절 각도를 측정하는 구조다. 따라서 손이 3D 공간 어디에 있는지는 전혀 알 수 없다.

### 1.2 UDCAP이 지원하는 트래킹 플랜 (Tracking Plan)

UDCAP Software에서 공식 지원하는 **Spatial Position Tracking Plan**:

| Tracking Plan | 트래커 종류 | 손 위치 추적 방식 | 정밀도 |
|--------------|-----------|-----------------|--------|
| **Lighthouse (Vive Tracker 3.0)** | Vive Tracker 3.0 글러브 마운트 | Lighthouse 적외선 → **서브밀리미터** | ★★★★★ |
| **Lighthouse (Tundra Tracker)** | Tundra Tracker 글러브 마운트 | Lighthouse 적외선 → **서브밀리미터** | ★★★★★ |
| **PICO Controller** | PICO 컨트롤러를 글러브에 마운트 | 헤드셋 카메라 inside-out | ★★★☆☆ |
| **Quest Controller** | Quest 컨트롤러를 글러브에 마운트 | 헤드셋 카메라 inside-out | ★★★☆☆ |
| **Vive Ultimate Tracker** | Ultimate Tracker 글러브 마운트 | 자체 카메라 inside-out | ★★★★☆ |
| **Custom Solution** | 사용자 정의 | 수동 오프셋 조정 | 가변 |

### 1.3 트래커 없이 글러브만 사용하면?

**불가능하다.** 트래커 없이 UDCAP만 사용하면:
- 손가락이 어떻게 구부러져 있는지는 알 수 있지만
- **손이 어디에 있는지 (위치)** 를 전혀 알 수 없다
- SteamVR에서 가상 손이 화면에 나타나지 않거나 고정된 위치에 떠 있게 됨
- 로봇 텔레오퍼레이션에서는 **End-Effector 목표 위치를 설정할 수 없음**

### 1.4 그렇다면 팔뚝 트래커(PICO Motion Tracker)로 대체 가능한가?

**"이론적으로 가능하지만, 공식 미지원"** 이라는 결론이다:

| 항목 | Vive Tracker 3.0 (글러브 마운트) | PICO Motion Tracker (팔뚝 장착) |
|------|-------------------------------|-------------------------------|
| **위치 정밀도** | 서브밀리미터 (< 1mm) | 5cm 평균 편차 |
| **각도 정밀도** | < 1.6° | 6° 평균 편차 |
| **트래킹 방식** | Lighthouse 적외선 (외부 기준점) | IMU + 헤드셋 IR 카메라 (inside-out) |
| **UDCAP 공식 지원** | **지원** (Tracking Plan 프리셋) | **미지원** |
| **SteamVR hand 역할** | 가능 (Tracker Management에서 할당) | **불가** (hand 역할 할당 없음) |
| **글러브 마운트** | 전용 마운팅 어댑터 제공 | 어댑터 없음 (팔뚝 스트랩만) |
| **추적 범위** | 베이스 스테이션 시야 내 어디서나 | 헤드셋 카메라 시야 내에서만 정확 |
| **가격** | ~$130/개 + 베이스 스테이션 ~$150x2 | ~$50/개 (별도 베이스 스테이션 불요) |

### 1.5 PICO Motion Tracker의 SteamVR 한계

**SenseGlove 공식 문서**에서 확인된 핵심 한계:

> "Unlike Vive (Wrist) Trackers, Pico Motion Trackers **do not show up in the `UnityEngine.InputDevices.GetDevices` list**, and wrist tracking using Pico Motion Trackers does **NOT work 'out of the box'** within the SenseGlove Unity Plugin."

또한:

> "The PICO API **does not allow you to assign a left and right hand** to a tracker."

즉, PICO Motion Tracker는:
1. SteamVR에서 **generic tracker**로 인식되지만, **hand 역할로 할당할 수 없음**
2. Unity/SteamVR의 표준 InputDevice API에 나타나지 않음
3. 별도 PICO SDK (`PXR_MotionTracking`) 를 통해서만 데이터 접근 가능
4. UDCAP Software의 트래킹 플랜에 **PICO Motion Tracker 전용 프리셋이 없음**

### 1.6 결론: 팔뚝 트래커 vs 글러브 마운트 트래커

```
┌─────────────────────────────────────────────────────┐
│ UDCAP VR Gloves를 쓰려면 반드시 외부 트래커가 필요하다.│
│                                                     │
│ 선택지 A: Vive Tracker 3.0을 글러브에 마운트           │
│   → 서브밀리미터 정밀도, UDCAP 공식 지원                │
│   → Lighthouse 베이스 스테이션 2개 필요 (~$300 추가)    │
│                                                     │
│ 선택지 B: PICO 컨트롤러를 글러브에 마운트               │
│   → UDCAP 공식 지원 (PICO Controller Tracking Plan)   │
│   → 베이스 스테이션 불요, 추가 비용 없음                 │
│   → 정밀도는 Lighthouse보다 낮음                       │
│                                                     │
│ 선택지 C: PICO Motion Tracker를 팔뚝에 장착            │
│   → UDCAP 공식 미지원, SteamVR hand 역할 불가          │
│   → 커스텀 개발 필요, 5cm 위치 편차                     │
│   → 팔뚝에 장착하므로 손목~손 간 오프셋 보정 필요         │
│                                                     │
│ ★ 추천: 선택지 B (PICO 컨트롤러 마운트)                 │
│   → 추가 비용 없음, 공식 지원, 충분한 정밀도             │
│   → PICO 팔뚝 트래커는 Full-Body 용으로만 사용          │
└─────────────────────────────────────────────────────┘
```

## 2. PICO vs Vive 트래커/헤드셋 전체 구성 비교

### 2.1 UDCAP 공식 지원 트래커 목록

UDCAP 문서 및 하드웨어 설치 가이드에서 확인된 **공식 지원 트래커**:

| 트래커 | 마운팅 어댑터 | SteamVR 역할 | 트래킹 방식 |
|--------|------------|-------------|-----------|
| **HTC Vive Tracker 2.0** | 1/4" 스크류 마운트 | Hand (L/R) | Lighthouse |
| **HTC Vive Tracker 3.0** | 1/4" 스크류 마운트 | Hand (L/R) | Lighthouse |
| **Tundra Tracker** | 전용 UDCAP 어댑터 | Hand (L/R) | Lighthouse |
| **Vive Ultimate Tracker (UTK)** | 클립 마운트 | Hand (L/R) | Inside-out (자체 카메라) |
| **Quest Controller** | 전용 Quest 어댑터 | Controller | Inside-out (헤드셋 카메라) |
| **PICO Controller** | 소프트웨어 설정 | Controller | Inside-out (헤드셋 카메라) |

> **PICO Motion Tracker**: 목록에 **없음**. 마운팅 어댑터도, 소프트웨어 프리셋도 없음.

### 2.2 PICO 생태계 구성 (추천안)

#### Option P1: PICO + PICO 컨트롤러 마운트 (최소 비용)

```
PICO 4 Ultra Enterprise         기존 보유
├── PICO Controller (L)          기존 보유 → UDCAP 글러브에 마운트 (손 위치 추적)
├── PICO Controller (R)          기존 보유 → UDCAP 글러브에 마운트 (손 위치 추적)
├── Motion Tracker (발목 2개)     ~$100
├── Motion Tracker Waist (허리)   ~$55
└── UDCAP VR Gloves              ~$559~$699
────────────────────────────────────
추가 비용: ~$714~$854
총 비용 (헤드셋 제외): ~$714~$854
```

**데이터 플로우**:
```
UDCAP Elastic Sensor → 손가락 21 관절각 (2.4GHz USB 동글 → PC)
PICO Controller → 손 6DoF 위치/방향 (PICO Connect → SteamVR)
PICO Motion Tracker → 하반신 + 허리 (PICO Body Tracking API)
PICO Headset → 머리 6DoF (HMD 트래킹)
        │
        ▼
  SteamVR / UDCAP Software (PC)
        │
        ▼
  Isaac Lab (CloudXR 또는 PICO Connect 경유)
```

**장점**:
- 추가 하드웨어 비용 최소 (컨트롤러는 이미 보유)
- UDCAP 공식 지원 (PICO Controller Tracking Plan)
- CloudXR/Isaac Lab과의 기존 통합 경로 활용 가능
- PICO Body Tracking (허리+발목)과 동시 사용 가능

**단점**:
- 컨트롤러를 글러브에 마운트하면 부피가 커짐 (컨트롤러 무게 ~170g 추가)
- 컨트롤러 inside-out 트래킹은 Lighthouse 대비 정밀도 낮음
- 컨트롤러 버튼/트리거 접근이 불편해질 수 있음

#### Option P2: PICO + Vive Ultimate Tracker (추가 정밀도)

```
PICO 4 Ultra Enterprise         기존 보유
├── Vive Ultimate Tracker x2     ~$400 (글러브 마운트용)
│   └── Wireless Dongle          포함
├── Motion Tracker (발목 2개)     ~$100
├── Motion Tracker Waist (허리)   ~$55
└── UDCAP VR Gloves              ~$559~$699
────────────────────────────────────
추가 비용: ~$1,114~$1,254
```

**장점**:
- Vive Ultimate Tracker는 **자체 inside-out 카메라**로 위치 추적 → 베이스 스테이션 불요
- UDCAP 공식 지원 (UTK Tracking Plan)
- 컨트롤러보다 가볍고 글러브에 적합
- PICO 헤드셋 + Vive 트래커 혼합 사용 가능

**단점**:
- $200/개 × 2 = $400 추가 비용
- PICO 생태계와 Vive 트래커 간 Space Calibrator로 좌표계 보정 필요
- Ultimate Tracker는 Lighthouse 트래커보다 정밀도 낮음

- PICO Body Tracking AI 알고리즘 없음 → 트래커 위치 보간만 가능
- Full Kit이 세일 한정가 ($800) → 정가는 $1,199

## 4. PICO Motion Tracker를 UDCAP에 직접 사용하는 방법 (참고)

만약 향후 PICO Motion Tracker를 글러브에 마운트하여 사용하고 싶다면, **커스텀 개발**이 필요하다:

### 4.1 SenseGlove의 선례

SenseGlove Nova 2는 PICO Motion Tracker 마운팅 솔루션을 개발했으며 (2024-11-25), 주요 내용:

```python
# PICO Motion Tracker 데이터 접근 (Unity C# 예시)
# 표준 SteamVR InputDevice API에서는 보이지 않음
# PICO Unity Integration SDK의 PXR_MotionTracking API 직접 사용 필요

using Unity.XR.PXR;  // PICO SDK

public class PicoMTWristTracker : MonoBehaviour
{
    void Update()
    {
        // PICO API로 트래커 위치/회전 직접 가져오기
        var trackerState = PXR_MotionTracking.GetTrackerState(trackerId);
        transform.position = trackerState.position;
        transform.rotation = trackerState.rotation;
    }
}
```

### 4.2 한계

| 항목 | 설명 |
|------|------|
| SteamVR 미통합 | PICO Motion Tracker는 SteamVR InputDevice 리스트에 안 나옴 |
| Hand 역할 할당 불가 | PICO API에서 tracker에 left/right hand 할당 불가 |
| UDCAP 비호환 | UDCAP Software의 Spatial Position에 PICO MT 프리셋 없음 |
| 오프셋 문제 | 팔뚝 장착 시 손목~손끝 간 오프셋 보정 커스텀 필요 |
| 정밀도 한계 | 5cm 위치 편차 → 정밀 그리핑에 부족 |

### 4.3 결론

현재 시점에서 PICO Motion Tracker를 UDCAP 글러브의 **공간 위치 추적용으로 직접 사용하는 것은 비실용적**이다. PICO Controller 마운트 또는 Vive 계열 트래커를 사용하는 것이 합리적이다.

### 5.2 팔뚝 트래커와 UDCAP 글러브 동시 사용 분석

**PICO 컨트롤러를 글러브에 마운트하는 경우**, Enhanced Forearm Tracking의 추가 가치:

| 시나리오 | 팔뚝 트래커 없이 (3트래커) | 팔뚝 트래커 포함 (5트래커) | 차이 |
|---------|------------------------|------------------------|------|
| 손 위치 추적 | PICO 컨트롤러 (inside-out) | 컨트롤러 + 팔뚝 IMU 보조 | **미미** (컨트롤러가 이미 정확) |
| 팔꿈치 위치 | 헤드셋 AI 추정 | 팔뚝 IMU로 직접 측정 | **유의미** (팔 포즈 정확) |
| PICO Body Tracking 상체 | AI 추정 (부정확) | 팔뚝 데이터 포함 (정확) | **유의미** |
| 손 카메라 FOV 밖 추적 | 컨트롤러 IMU로 단기 보정 | 컨트롤러 + 팔뚝 IMU 이중 보정 | **약간** |

### 5.3 수정된 추천

```
★ 기본 구성 (추천):
  발목 2 + 허리 1 + PICO 컨트롤러 마운트 + UDCAP = ~$714~$854
  → 팔뚝 트래커 불필요 (컨트롤러가 손 위치를 직접 추적)

★ 확장 구성 (선택):
  + 팔뚝 트래커 2개 (+$100)
  → 팔꿈치/팔 포즈 정확도 향상, Body Tracking 상체 데이터 개선
  → SONIC/GR00T WBC에서 전신 모션 데이터 품질 향상에 기여
  → 필수는 아니지만 "있으면 더 좋은" 수준
```

**결론**: PICO 컨트롤러를 UDCAP 글러브에 마운트하면, **팔뚝 트래커 2개는 "있으면 좋지만 필수는 아닌"** 옵션이다. 손 위치는 컨트롤러가 추적하고, 팔뚝 트래커는 팔꿈치 포즈와 전신 Body Tracking 데이터 품질만 개선한다.
