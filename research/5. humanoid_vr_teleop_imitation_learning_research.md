## 2. Isaac Lab 내 휴머노이드 로봇 총정리

### 2.1 사용 가능한 휴머노이드 로봇 목록

| 로봇 | 제조사 | DOF | VR 텔레오퍼레이션 | 손(Hand) | 주요 태스크 |

| **Unitree G1** | Unitree | 23 (기본) / **29 (확장)** | **O** | TriHand(3손가락) / Inspire(5손가락) | 보행 + 로코매니퓰레이션 + 픽앤플레이스 |
| **Fourier GR1T2** | Fourier Intelligence | **40+** | **O** | Fourier Hand(6DOF/손) | 픽앤플레이스, 조립, 따르기(Pouring) |

### 2.2 각 로봇 상세 분석

#### A. Unitree G1 (29DOF 확장 버전)

**설정 파일**: `source/isaaclab_assets/isaaclab_assets/robots/unitree.py`

```
G1_CFG         - 기본 23DOF (보행 전용)
G1_MINIMAL_CFG - 최적화 버전 (충돌 메시 최소화)
G1_29DOF_CFG   - 29DOF (로코매니퓰레이션용, 팔+허리 포함)
G1_INSPIRE_FTP_CFG - G1 + Inspire 5손가락 덱스터러스 핸드
```

**관절 구성 (29DOF)**:
- 다리: 좌/우 각 7DOF (hip_roll/yaw/pitch + knee + ankle_pitch/roll/yaw) = 14DOF
- 허리: 3DOF (waist_yaw/roll/pitch)
- 팔: 좌/우 각 4DOF (shoulder_pitch/roll/yaw + elbow) = 8DOF
- 손목: 좌/우 각 2DOF (wrist) = 4DOF
- 핸드: TriHand (3손가락) 또는 Inspire (5손가락) - 별도 DOF

**태스크**:
- 보행: `locomotion/velocity/config/g1/rough_env_cfg.py`, `flat_env_cfg.py`
- 로코매니퓰레이션: `locomanipulation/pick_place/locomanipulation_g1_env_cfg.py`
- 고정 베이스 매니퓰레이션: `fixed_base_upper_body_ik_g1_env_cfg.py`
- Inspire 핸드 픽앤플레이스: `pickplace_unitree_g1_inspire_hand_env_cfg.py`

**VR 리타게터**:
- `G1TriHandUpperBodyRetargeterCfg` (TriHand 3손가락)
- `UnitreeG1RetargeterCfg` (Inspire 5손가락)
- `G1LowerBodyStandingRetargeterCfg` (하체 보행 제어)

#### B. Fourier GR1T2

**설정 파일**: `source/isaaclab_assets/isaaclab_assets/robots/fourier.py`

```
GR1T2_CFG         - 표준 GR1T2 + Fourier Hand
GR1T2_HIGH_PD_CFG - 높은 PD 게인 (픽앤플레이스 최적화)
```

**관절 구성 (40+ DOF)**:
- 머리: head_* (2DOF)
- 몸통: waist_* (3DOF)
- 다리: hip/knee/ankle (좌/우 각 6DOF) = 12DOF
- 팔: shoulder/elbow/wrist (좌/우 각 7DOF) = 14DOF
- Fourier Hand: 좌/우 각 6DOF = 12DOF

**태스크**:
- 픽앤플레이스: `pickplace_gr1t2_env_cfg.py`
- 허리 활성화 버전: `pickplace_gr1t2_waist_enabled_env_cfg.py`
- 배기파이프 조립: `exhaustpipe_gr1t2_base_env_cfg.py`, PINK IK 버전
- 너트 따르기: `nutpour_gr1t2_base_env_cfg.py`, PINK IK 버전

**VR 리타게터**:
- `GR1T2RetargeterCfg` (OpenXR 핸드 트래킹 → Fourier Hand)

#### C. Unitree H1

**설정 파일**: `source/isaaclab_assets/isaaclab_assets/robots/unitree.py`

```
H1_CFG         - 19DOF 전체 버전
H1_MINIMAL_CFG - 충돌 메시 최소화 버전
```

**관절 구성 (19DOF)**:
- 다리: 좌/우 각 5DOF (hip_yaw/roll/pitch + knee + ankle)
- 팔: 좌/우 각 4DOF (shoulder_pitch/roll/yaw + elbow)
- 몸통: 1DOF (torso)

**VR 지원**: **없음** - 텔레오퍼레이션 리타게터 미구현

## 3. VR 텔레오퍼레이션 지원 현황 상세 분석

### 3.1 지원 VR/XR 디바이스

Isaac Lab 2.3.0은 **OpenXR 표준** 기반으로 다양한 XR 디바이스를 지원:

| 디바이스 | 지원 방식 | 핸드 트래킹 | 권장도 |
|---------|----------|:---------:|:-----:|
| **Apple Vision Pro** | CloudXR + OpenXR | O (네이티브) | ★★★★★ |
| **Meta Quest 3/3S** | CloudXR.js (WebXR) | O (WebXR) | ★★★★ |
| **HTC Vive + Manus 글러브** | OpenXR + Manus API | O (글러브) | ★★★ |
| **키보드/SpaceMouse** | 직접 입력 | X | ★★ |

### 3.2 VR 텔레오퍼레이션 아키텍처

```
[XR 디바이스] → [OpenXR Runtime] → [CloudXR 스트리밍] → [Isaac Lab]
                                                          ↓
                                                    [Retargeter]
                                                    ├── Upper Body: 양팔 + 손가락 리타게팅
                                                    └── Lower Body: 보행 제어 (옵션)
                                                          ↓
                                                    [IK Controller (PINK)]
                                                          ↓
                                                    [Joint Position Commands]
```

### 3.3 리타게팅 시스템 상세

**파일 경로**: `source/isaaclab/isaaclab/devices/openxr/retargeters/`

#### G1 리타게터 구조:
```
retargeters/humanoid/unitree/
├── inspire/
│   ├── g1_upper_body_retargeter.py    ← Inspire 5손가락 핸드
│   └── g1_dex_retargeting_utils.py    ← 덱스터러스 리타게팅 유틸
├── trihand/
│   ├── g1_upper_body_retargeter.py    ← TriHand 3손가락
│   └── g1_dex_retargeting_utils.py
└── g1_lower_body_standing.py          ← 하체 스탠딩 제어
```

#### GR1T2 리타게터 구조:
```
retargeters/humanoid/fourier/
├── gr1t2_retargeter.py                ← Fourier Hand 리타게팅
└── gr1_t2_dex_retargeting_utils.py    ← 덱스터러스 리타게팅 유틸
```

### 3.4 리타게팅 데이터 흐름

**G1 (Inspire 핸드 예시)**:
```python
# OpenXR → 26 hand joints per hand → Retargeter
left_wrist_pose (7D: pos3 + quat4)
right_wrist_pose (7D: pos3 + quat4)
retargeted_hand_joints (N-DOF: 각 손가락 관절각)
→ torch.cat([left_wrist, right_wrist, hand_joints]) → IK Controller
```

**GR1T2**:
```python
# OpenXR → Hand joints → GR1TR2DexRetargeting
left_wrist_pose (7D)
right_wrist_pose (7D) + Z-axis 180° rotation correction
fourier_hand_joints (12D: 6DOF × 2hands)
→ torch.cat([left_wrist, right_wrist, hand_joints]) → IK Controller
```

- 핸드 트래킹으로 자연스러운 물체 파지

## 5. 모방학습(Imitation Learning) 파이프라인 완전 가이드

### 5.1 Isaac Lab Mimic 파이프라인 개요

Isaac Lab Mimic은 **MimicGen에서 영감받은** 합성 데이터 생성 프레임워크로, 소수의 인간 시연(10개 내외)을 수천~수십만 개의 합성 궤적으로 확장한다.

```
┌─────────────────────────────────────────────────────────────────┐
│                    Isaac Lab Mimic 파이프라인                      │
│                                                                 │
│  ① VR 텔레오퍼레이션      ② 자동 어노테이션      ③ 합성 데이터 생성   │
│  ┌──────────┐           ┌──────────┐          ┌──────────┐      │
│  │ record_  │  HDF5     │annotate_ │  HDF5    │generate_ │      │
│  │ demos.py │────────→  │demos.py  │───────→  │dataset.py│      │
│  └──────────┘  ~10개    └──────────┘ 태스크    └──────────┘      │
│       ↑시연              자동 서브태스크        1000+ 합성 궤적      │
│   [VR/키보드]             경계 검출                               │
│                                                                 │
│  ④ 정책 학습              ⑤ 평가                                  │
│  ┌──────────┐           ┌──────────┐                             │
│  │ train.py │  학습된    │ play.py  │                             │
│  │(Robomimic)│───────→  │ (추론)   │                             │
│  └──────────┘  정책      └──────────┘                             │
│   BC/BC-RNN               성공률 평가                              │
│   GMM Policy                                                     │
└─────────────────────────────────────────────────────────────────┘
```

### 5.2 단계별 상세 가이드

#### Step 1: 시연 데이터 수집 (`record_demos.py`)

```bash
# VR 핸드트래킹으로 GR1T2 시연 수집
./isaaclab.sh -p scripts/tools/record_demos.py \
  --task Isaac-PickPlace-GR1T2-Abs-v0 \
  --device cpu \
  --teleop_device handtracking \
  --dataset_file ./datasets/gr1t2_pickplace_demos.hdf5 \
  --num_demos 10

# SpaceMouse로 Franka 시연 수집 (대안)
./isaaclab.sh -p scripts/tools/record_demos.py \
  --task Isaac-Stack-Cube-Franka-IK-Rel-v0 \
  --device cpu \
  --teleop_device spacemouse \
  --dataset_file ./datasets/franka_stack_demos.hdf5 \
  --num_demos 10
```

**시연 수집 팁**:
- 짧고 직접적인 동작 유지 (불필요한 정지 없이)
- 부드럽고 연속적인 모션 유지
- 실패한 시연은 R키로 리셋 후 재시도
- 성공 후 약간의 버퍼 시간 유지

**조작 키 (키보드 모드)**:
- 이동: W/S (X), A/D (Y), Q/E (Z)
- 회전: Z/X, T/G, C/V
- 그리퍼: K (토글)
- 리셋: R

#### Step 2: 서브태스크 어노테이션 (`annotate_demos.py`)

```bash
# 자동 어노테이션 (권장)
./isaaclab.sh -p scripts/imitation_learning/isaaclab_mimic/annotate_demos.py \
  --device cpu \
  --task Isaac-PickPlace-GR1T2-Mimic-v0 \
  --auto \
  --input_file ./datasets/gr1t2_pickplace_demos.hdf5 \
  --output_file ./datasets/gr1t2_pickplace_annotated.hdf5

# 수동 어노테이션 (미세 조정 시)
./isaaclab.sh -p scripts/imitation_learning/isaaclab_mimic/annotate_demos.py \
  --device cpu \
  --task Isaac-PickPlace-GR1T2-Mimic-v0 \
  --input_file ./datasets/gr1t2_pickplace_demos.hdf5 \
  --output_file ./datasets/gr1t2_pickplace_annotated.hdf5
```

**수동 어노테이션 키**:
- N: 재생 시작
- B: 일시정지
- S: 서브태스크 경계 마킹
- Q: 문제 에피소드 건너뛰기

**서브태스크 구조 예시 (GR1T2 Pick-Place)**:
```python
subtask_configs["right"] = [
    SubTaskConfig(
        object_ref="object",                      # 대상 오브젝트
        subtask_term_signal="idle_right",          # 완료 시그널
        selection_strategy="nearest_neighbor_object",  # 선택 전략
        selection_strategy_kwargs={"nn_k": 3},     # K-NN 파라미터
        action_noise=0.003,                        # 행동 노이즈
        num_interpolation_steps=0,                 # 보간 스텝
    ),
    SubTaskConfig(
        object_ref="object",
        subtask_term_signal=None,                  # 마지막 서브태스크
        selection_strategy="nearest_neighbor_object",
        action_noise=0.003,
        num_interpolation_steps=3,                 # 스티칭 보간
    ),
]
```

#### Step 3: 합성 데이터 생성 (`generate_dataset.py`)

```bash
# 소규모 검증 (먼저 실행하여 성공률 확인)
./isaaclab.sh -p scripts/imitation_learning/isaaclab_mimic/generate_dataset.py \
  --device cpu \
  --num_envs 10 \
  --generation_num_trials 10 \
  --input_file ./datasets/gr1t2_pickplace_annotated.hdf5 \
  --output_file ./datasets/gr1t2_generated_small.hdf5

# 대규모 생성 (검증 후)
./isaaclab.sh -p scripts/imitation_learning/isaaclab_mimic/generate_dataset.py \
  --device cpu \
  --headless \
  --num_envs 50 \
  --generation_num_trials 1000 \
  --input_file ./datasets/gr1t2_pickplace_annotated.hdf5 \
  --output_file ./datasets/gr1t2_generated_full.hdf5
```

**데이터 생성 원리**:
1. 원본 시연을 서브태스크 세그먼트로 분리
2. 새로운 오브젝트 배치에 대해 세그먼트 변환(Object-Centric Transform)
3. 변환된 세그먼트들을 보간(Interpolation)으로 스티칭
4. 성공 여부 검증 후 저장

**기대 성공률**:

| 태스크 | 데이터 생성 성공률 | 생성 시간 |
|--------|:----:|:----:|
| Franka Stack (state) | ~50% | ~30분 |
| GR1T2 Pick-Place | 65-80% | 18-40분 |
| G1 Locomanipulation | 65-82% | 18-40분 |
| GR1T2 Nut Pour | 가변적 | ~10시간 |

#### Step 4: Robomimic으로 정책 학습 (`train.py`)

```bash
# Robomimic 설치 (최초 1회)
sudo apt install cmake build-essential
./isaaclab.sh -i robomimic

# Behavior Cloning 학습
./isaaclab.sh -p scripts/imitation_learning/robomimic/train.py \
  --task Isaac-PickPlace-GR1T2-Abs-v0 \
  --algo bc \
  --dataset ./datasets/gr1t2_generated_full.hdf5 \
  --normalize_training_actions

# BC-RNN (Recurrent) 학습 - 권장
./isaaclab.sh -p scripts/imitation_learning/robomimic/train.py \
  --task Isaac-PickPlace-GR1T2-Abs-v0 \
  --algo bc_rnn \
  --dataset ./datasets/gr1t2_generated_full.hdf5 \
  --normalize_training_actions
```

**학습 알고리즘 비교**:

| 알고리즘 | 설명 | 장점 | 단점 |
|---------|------|------|------|
| **BC** | 기본 Behavior Cloning | 빠른 학습 | 순차적 의사결정 약함 |
| **BC-RNN** | LSTM 기반 BC | 시간적 상관관계 캡처 | 학습 시간 증가 |
| **BC-GMM** | 가우시안 혼합 모델 BC | 다중 모드 행동 | 복잡도 높음 |

**핵심 학습 파라미터**:
- 정책: Recurrent GMM (LSTM 2레이어, hidden dim 400)
- 입력: EEF 포즈 + 그리퍼 상태 + 상대 오브젝트 포즈
- 출력: 델타 포즈 액션
- 학습 속도: ~50 iter/sec (RTX 4090 기준)

#### Step 5: 학습된 정책 평가 (`play.py`)

```bash
# State-based 정책 평가
./isaaclab.sh -p scripts/imitation_learning/robomimic/play.py \
  --device cpu \
  --task Isaac-PickPlace-GR1T2-Abs-v0 \
  --num_rollouts 50 \
  --checkpoint ./logs/robomimic/model_epoch_100.pth

# Visuomotor 정책 평가 (카메라 입력 포함)
./isaaclab.sh -p scripts/imitation_learning/robomimic/play.py \
  --device cpu \
  --enable_cameras \
  --task Isaac-PickPlace-GR1T2-Visuomotor-v0 \
  --num_rollouts 50 \
  --checkpoint ./logs/robomimic/model_epoch_100.pth
```

**중요**: 중간 체크포인트가 최종 체크포인트보다 좋은 경우가 많으므로 여러 epoch의 체크포인트를 평가해야 함.

**기대 정책 성공률**:

| 태스크 | BC 학습 시간 | 정책 성공률 |
|--------|:----:|:----:|
| Franka Stack | 1000 epochs (~30분) | 40-60% |
| GR1T2 Pick-Place | 2000 epochs (~29분) | 75-86% |
| G1 Locomanipulation | 2000 epochs (~40분) | 75-85% |
| GR1T2 Nut Pour | 600 epochs (~15시간) | 50-60% |

```
  60 steps   70 steps         ~30 steps
```


### 7.2 모방학습 체크리스트

- [ ] 로봇 선택 (G1 vs GR1T2 vs 커스텀)
- [ ] 태스크 정의 (픽앤플레이스 / 조립 / 이동+조작)
- [ ] VR 디바이스 설정 (CloudXR + OpenXR)
- [ ] 시연 수집 (10개 이상, 높은 품질)
- [ ] 서브태스크 어노테이션 (자동 → 수동 검증)
- [ ] 소규모 데이터 생성으로 성공률 검증 (>50%)
- [ ] 대규모 데이터 생성 (1000+ 궤적)
- [ ] Robomimic 학습 (BC-RNN 권장)
- [ ] 다양한 체크포인트 평가
- [ ] 시뮬레이션 → 실제 전이 (Domain Randomization)

### 7.3 성능 최적화 팁

1. **데이터 품질 > 데이터 양**: 10개의 고품질 시연이 100개의 저품질보다 좋음
2. **서브태스크 어노테이션 정확도**: 자동 어노테이션 후 반드시 수동 검증
3. **Action Normalization**: `--normalize_training_actions` 플래그 필수
4. **중간 체크포인트 평가**: 최종 epoch이 아닌 중간 epoch이 더 좋을 수 있음
5. **Domain Randomization**: 배경, 조명, 오브젝트 색상/크기 랜덤화
6. **GPU 활용**: 생성 시 `--num_envs 50+`로 병렬화
