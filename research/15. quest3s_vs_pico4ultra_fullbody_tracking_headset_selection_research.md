## 1. PICO Motion Tracker + Quest 3S: 호환성 분석

### 1.1 결론: 호환 불가

PICO Motion Tracker는 **PICO 헤드셋 전용** 액세서리다.

| 항목 | 설명 |
|------|------|
| **연결 방식** | 2.4GHz 전용 프로토콜 (PICO 헤드셋과 직접 페어링) |
| **트래킹 원리** | 트래커의 12개 IR LED → PICO 헤드셋 IR 카메라가 인식 |
| **호환 헤드셋** | PICO 4 Ultra, PICO 4 Pro, PICO 4, PICO Neo3 **만** |
| **Quest 호환** | **불가** - Quest 헤드셋의 IR 카메라는 PICO 트래커 인식 불가 |

**기술적 이유**: PICO Motion Tracker는 "자립형(self-sufficient) 트래커"가 아니다. 트래커 자체에는 위치 추적 카메라가 없고, **PICO 헤드셋의 IR 카메라가 트래커의 IR LED를 보고** 위치를 계산한다. 따라서 PICO 헤드셋 없이는 위치 추적 자체가 불가능하다.

> Meta의 CTO는 "Pico Motion Tracker가 성공하지 않는 한 Quest용 모션 트래커를 만들지 않을 것"이라고 공식 발언했다. ([UploadVR](https://www.uploadvr.com/meta-wont-make-motion-trackers-for-quest-unless-pico-motion-trackers/))

### 1.2 Quest 3S의 Body Tracking 현황

| 트래킹 영역 | 방식 | 정확도 | 로봇 텔레오퍼레이션 적합성 |
|------------|------|--------|----------------------|
| **머리** | 헤드셋 6DoF (inside-out) | ★★★★★ | 적합 |
| **손/손가락** | 카메라 기반 핸드 트래킹 | ★★★☆☆ | 간단한 그리핑만 가능 |
| **상체 (팔/어깨/가슴)** | Inside-Out Body Tracking (IOBT) | ★★★★☆ | 적합 (Quest 3/3S 전용) |
| **하체 (다리/무릎/발)** | **Generative Legs (AI 추정)** | ★☆☆☆☆ | **부적합** |
| **허리** | AI 추정 | ★★☆☆☆ | 부적합 |

### 1.3 Generative Legs의 한계 (핵심)

Meta의 Generative Legs는 **실제 트래킹이 아니라 AI 추정**이다:

```
Generative Legs가 할 수 있는 것:
  ✓ 점프 감지 (상체 움직임으로 추론)
  ✓ 웅크리기 감지
  ✓ 자연스러운 걷기 애니메이션 생성

Generative Legs가 할 수 없는 것:
  ✗ 개별 다리 들기 인식 (한쪽 다리만 들면 감지 안 됨!)
  ✗ 발차기 동작
  ✗ 무릎 굽힘 정확한 각도
  ✗ 걸음 패턴/보폭 정확한 측정
  ✗ 앉기/눕기 자세의 정확한 다리 위치
```

**로봇 텔레오퍼레이션 관점**: G1 휴머노이드의 보행 제어에는 **양발의 정확한 위치와 방향**이 필수적이다. Generative Legs의 AI 추정은 실제 발 위치와 크게 다를 수 있어 **SONIC/GR00T WBC의 전신 텔레오퍼레이션에 사용할 수 없다**.

## 2. Quest 3S 기반 Full-Body Tracking 대안

Quest 3S를 유지하면서 Full-Body Tracking을 구현하는 방법:

### 2.1 Option B-1: Vive Ultimate Tracker (추천 대안)

```
기존: Meta Quest 3S (보유)
추가:
├── Vive Ultimate Tracker x5     ~$1,000 ($200/개)
│   배치: 양발 2 + 양팔꿈치 2 + 허리 1
├── Wireless Dongle              ~$60
├── 스트랩 세트                    ~$30
└── UDCAP VR Gloves              ~$559~$699
────────────────────────────────────────
추가 비용: ~$1,649~$1,789
```

**장점**:
- Quest 3S 유지 (추가 헤드셋 구매 불요)
- Vive Ultimate Tracker는 **자체 inside-out 카메라** → 베이스 스테이션 불요
- **Quest 3S + SteamVR에서 공식 지원** (Steam Link/Virtual Desktop/ALVR 경유)
- UDCAP 글러브와 **UTK Tracking Plan 공식 호환**
- 최대 5개 동시 사용

**단점**:
- $1,000+ 트래커 비용 (PICO Motion Tracker 5개 $255 대비 4배)
- NVIDIA SONIC/GR00T WBC의 **공식 지원 경로가 아님** (커스텀 통합 필요)
- XRoboToolkit은 Quest 3도 지원하지만, Motion Tracker 데이터 경로가 PICO 최적화
- CloudXR Isaac Lab은 Quest 3를 Early Access로 지원하나, PICO가 1차 지원 대상

### 2.2 Option B-2: SlimeVR (최저가 대안)

```
기존: Meta Quest 3S (보유)
추가:
├── SlimeVR Lower-Body Set (5개)  ~$185
│   배치: 가슴 1 + 허벅지 2 + 발목 2
└── UDCAP VR Gloves               ~$559~$699
────────────────────────────────────────
추가 비용: ~$744~$884
```

**장점**:
- **$185로 Full-Body Tracking** (가장 저렴)
- Quest 3S 공식 지원
- 베이스 스테이션 불요 (WiFi IMU)
- 오픈소스 (커스텀 가능)
- 20시간 배터리 (v1.2)

**단점**:
- **IMU drift**: 시간이 지나면 yaw(좌우 회전) 편차 누적 → 주기적 재보정 필요
- **위치 추적 없음**: 순수 회전(rotation)만 측정, 위치는 역운동학으로 추정
- 정밀도가 PICO/Vive 트래커 대비 현저히 낮음
- SONIC/GR00T WBC 직접 지원 없음
- 로봇 텔레오퍼레이션에 정밀도 부족할 가능성 높음

### 2.3 Option B-3: Quest 3S IOBT + ALVR (소프트웨어 전용)

SimIntel 커뮤니티 프로젝트에서 구현한 방식:

```
기존: Meta Quest 3S (보유)
추가:
├── ALVR (무료, 오픈소스)
├── SteamVR (무료)
├── OSC 데이터 수신기 (커스텀 코드)
└── UDCAP VR Gloves              ~$559~$699
────────────────────────────────────────
추가 비용: ~$559~$699 (글러브만)
```

**데이터 플로우**:
```
Quest 3S IOBT → 9개 관절 (7DoF each)
  ├── Head, Hip, Chest
  ├── Feet (L/R), Knees (L/R)
  └── Elbows (L/R)
      │
      ▼
  ALVR → SteamVR → OSC (UDP:9000)
      │
      ▼
  BodyOscReceiver → Isaac Lab
```

**장점**:
- 추가 하드웨어 비용 없음 (글러브 제외)
- 9개 관절 Full-Body 데이터 제공
- Isaac Lab 통합 커뮤니티 코드 존재

**한계점** (중요):
- **다리 트래킹은 AI 추정** → Generative Legs 한계 그대로 적용
- "Leg tracking accuracy relies on Quest 3 inference rather than direct measurement"
- 현재 **손 리타게팅만 구현**, 전신 리타게팅은 "future work"
- 커뮤니티 프로젝트 → 안정성/유지보수 보장 없음

## 6. 핵심 분석: 왜 PICO 4 Ultra를 추천하는가

### 6.1 NVIDIA 생태계 통합

UST 프로젝트의 기술 스택:
```
NVIDIA SONIC/GR00T WBC
  └── XRoboToolkit (PICO 1차 지원)
       └── PICO 4 Ultra + Motion Tracker
            └── CloudXR → Isaac Lab
                 └── G1 + INSPIRE Hand 시뮬레이션
```

이 파이프라인에서 **PICO는 공식 1차 지원 디바이스**이고, Quest는 "커뮤니티에서 작동하게 만든" 수준이다.

### 6.2 비용 효율성

| 비교 | PICO 구매 경로 | Quest 유지 경로 (Vive UT) |
|------|--------------|-------------------------|
| 헤드셋 | $599 (신규) | $0 (기존) |
| Body Tracker | $155 (3개) | $1,060 (5개) |
| 글러브 | ~$629 | ~$629 |
| **총합** | **~$1,383** | **~$1,689** |
| SONIC/GR00T 지원 | **공식** | 커스텀 |

**PICO를 새로 사면 오히려 $306 더 저렴**하고, 공식 지원까지 받는다.

### 6.3 Quest 3S를 버리는 것이 아닌 "병행 사용"

Quest 3S는 다음 용도로 계속 활용:
- **상체 텔레오퍼레이션** (Phase 1: 테이블탑 조작) - 기존 그대로
- **VR 개발/테스트** - SteamVR 게임, 앱 테스트
- **MR 데모** - 혼합현실 시연
- **핸드 트래킹 프로토타이핑** - 빠른 테스트용

PICO 4 Ultra는 **Full-Body 텔레오퍼레이션 전용**으로 사용:
- Phase 2: 전신 보행 + 조작
- Phase 3: 고령자 돌봄 (앉기/눕기 시나리오)
- SONIC/GR00T WBC 데이터 수집

## 7. Quest 3S 유지 시나리오별 상세 분석

### 7.1 CloudXR + Isaac Lab

| 항목 | PICO 4 Ultra | Quest 3S |
|------|-------------|----------|
| CloudXR 지원 | **공식 (EA 프로그램)** | **공식 (EA 프로그램)** |
| 접속 방식 | PICO → CloudXR.js (HTTPS) | Quest → CloudXR.js (HTTPS) |
| Body Tracking 전송 | PICO Body Tracking API | **Quest IOBT (상체만)** |
| 하체 데이터 | Motion Tracker (직접 측정) | Generative Legs (AI 추정) |

> **핵심**: CloudXR 자체는 Quest 3도 지원하지만, **Body Tracking 데이터의 품질**이 결정적으로 다르다. CloudXR는 단순히 영상 스트리밍 + 핸드 트래킹 채널이므로, Full-Body 데이터는 별도 경로(XRoboToolkit, OSC 등)로 전달해야 한다.

### 7.2 SONIC/GR00T WBC VR Teleop

GR00T WBC 공식 VR Teleop 설정:
- **지원 헤드셋**: PICO 4 / PICO 4 Pro (문서 기준)
- **지원 트래커**: PICO Motion Tracker 2개 (발목)
- **데이터 전송**: XRoboToolkit (PC service + PICO app)
- **Quest 3 지원**: **공식 문서에 없음**

XRoboToolkit 논문(2025):
- "Current support includes devices such as PICO 4 Ultra and Meta Quest 3"
- Quest 3도 지원하지만, **PICO Motion Tracker 데이터 경로는 PICO 전용**
- Quest로 XRoboToolkit 사용 시 **컨트롤러/핸드 트래킹만** 가능, Motion Tracker 없음

### 7.3 Quest 3S + ALVR 커뮤니티 솔루션

SimIntel 프로젝트의 Quest 3 Full-Body Teleop:
- 9개 관절 트래킹 (Head, Hip, Chest, Feet, Knees, Elbows)
- **하체는 Quest IOBT inference** → "leg tracking accuracy relies on Quest 3 inference"
- 현재 **손 리타게팅만 구현**, 전신은 "future work"
- Ubuntu 25.04 + NVIDIA RTX 4090에서 테스트
- **한계**: 다리 들기 동작 인식 불가, 걸음 패턴 부정확
