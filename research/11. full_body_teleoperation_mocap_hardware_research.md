## 1. 요약 (Executive Summary)

### 1.1 문제 정의

UST 프로젝트는 3단계로 진행된다:

| 단계 | 테스크 | 필요한 제어 | 현재 가능 여부 |
|------|--------|------------|---------------|
| **Phase 1** | 테이블 위 물체 정리 (양팔, 고정 베이스) | 상체 + 손가락 | ✅ Quest 3S / MANUS 글러브 |
| **Phase 2** | 떨어진 물체 줍기 → 특정 장소 이동 | **전신 보행 + 양팔 조작** | ❌ 불가능 |
| **Phase 3** | 노인 낙상 방지 (접근 → 잡기 → 지지) | **전신 보행 + 힘 제어 + 양팔** | ❌ 불가능 |

**핵심 문제**: Meta Quest 3S는 핸드 트래킹만 제공하며 하반신(보행) 제어가 불가능하다. Phase 2-3 구현을 위해 **전신 모션 캡쳐 + 텔레오퍼레이션 시스템**이 필수적이다.

### 1.2 핵심 권장사항

**1순위 권장**: PICO 4 Ultra Enterprise + PICO Motion Tracker (발목 2개) + MANUS 글러브

- **비용**: ~$3,500-6,000 (헤드셋 + 트래커 + 글러브)
- **근거**: NVIDIA SONIC/GR00T WBC가 정확히 이 조합(PICO + 발목 트래커)으로 전신 텔레오퍼레이션을 구현했으며, Isaac Lab에 네이티브 통합되어 있음
- **장점**: NVIDIA 공식 지원, Isaac Lab 2.3 네이티브 통합, Unitree G1 검증 완료, 100% 성공률(50개 실제 모션 테스트)

**2순위 대안**: HOMIE 오픈소스 외골격 시스템 ($500)
- 비용 대비 최고 성능, Unitree G1 직접 지원, RSS 2025 발표

## 2. 현재 시스템 분석 및 한계

### 2.1 현재 하드웨어 스택

```
[Meta Quest 3S] → CloudXR 6.0.1 → [Isaac Sim 5.1] → [Unitree G1 Sim]
     │                                     │
     ├── Hand Tracking (26 joints/hand)     ├── Pink IK Controller
     ├── Head Pose (6DOF)                   ├── Dex-Retargeting (INSPIRE 12DOF/hand)
     └── Controller Pose (6DOF × 2)         └── DifferentialIK (arms)
```

**추적 가능 영역**: 머리(6DOF), 양손(26 joints × 2), 컨트롤러(6DOF × 2)
**추적 불가 영역**: 몸통(torso), 허리(waist), 골반(pelvis), 양다리(legs), 발(feet)

### 2.2 Quest 3S 전신 추적 한계

| 기능 | Quest 3S 지원 | 전신 텔레오퍼레이션 요구 |
|------|-------------|---------------------|
| 핸드 트래킹 | ✅ 26 joints/hand | ✅ 충분 |
| 머리 포즈 | ✅ 6DOF | ✅ 충분 |
| 상체 트래킹 (IOBT) | ⚠️ 팔꿈치/어깨만 (v60+) | ⚠️ 부분적 |
| 하체 트래킹 | ❌ Generative Legs (추정치) | ❌ 불충분 |
| 발 위치 | ❌ 없음 | ❌ 불충분 |
| 몸통 회전 | ❌ 없음 | ❌ 불충분 |

**Quest 3S의 "Generative Legs"**: 추정(estimation)이지 실제 추적(tracking)이 아님. 점프/스쿼트 감지는 가능하나 정확한 발 위치/무릎 각도 추적 불가.

### 2.3 CloudXR 통합 현황

현재 CloudXR 6.0.1-webrtc Docker 런타임 기반으로 Quest 3S → Isaac Sim 스트리밍이 동작하지만:
- OpenXR 세션에서 핸드/컨트롤러 데이터만 획득 가능
- 전신 스켈레톤 데이터 스트리밍 프로토콜 없음
- PICO Motion Tracker 같은 외부 트래커 데이터 통합 경로 없음

### 3.2 프레임워크 상세 분석

#### 3.2.1 SONIC / GR00T Whole-Body Control (NVIDIA, 2025) ⭐ 최우선 권장

**핵심**: 대규모 모션 데이터(1억 프레임, 700시간)로 학습한 휴머노이드 행동 기반 모델

```
Human Operator          →  SMPL Pose  →  SONIC Policy  →  Robot Joint Commands
(PICO + 발목 트래커)       (전신 추정)     (42M params)      (Unitree G1 29DOF)
```

**VR 텔레오퍼레이션 모드 (2가지)**:

| 모드 | 센서 | 추적 포인트 | 용도 |
|------|------|-----------|------|
| **Full-body VR** | PICO 헤드셋 + 컨트롤러 2개 + 발목 트래커 2개 | 5-point | 전신 보행 + 조작 |
| **Lightweight VR** | PICO 헤드셋 + 컨트롤러 2개 | 3-point | 양팔 조작 (발 추적 불필요 시) |

**핵심 성과**:
- Unitree G1에서 50개 다양한 실제 모션 궤적에 대해 **100% 성공률**
- 점프, 복잡한 loco-manipulation 포함
- Isaac Lab에서 학습/평가 완료
- GR00T-WholeBodyControl 오픈소스 (https://github.com/NVlabs/GR00T-WholeBodyControl)

**멀티모달 제어 지원**:
- VR 텔레오퍼레이션 (전신)
- 웹캠 비디오 (RGB 기반)
- 텍스트 명령
- 음악 동기화 댄스

**학습 스케일**: 42M 파라미터, 100M 프레임, 9k GPU hours

#### 3.2.2 HumanPlus (Stanford, CoRL 2024)

**핵심**: RGB 카메라 1대만으로 전신 텔레오퍼레이션 + 자율 학습

```
RGB Camera → SMPL Pose Estimation → Retargeting → RL Policy → Robot
   (1대)       (실시간 전신 추정)      (인체→로봇)    (sim-to-real)
```

**장점**:
- **하드웨어 비용 ~$0** (기존 RGB 카메라 사용)
- Shadowing (실시간 모방) + Imitation Learning (자율 학습)
- 신발 신기, 선반 정리, 옷 접기 등 다양한 테스크 60-100% 성공률
- 40시간 인체 모션 데이터셋으로 학습

**단점**:
- 정확도가 VR/MoCap 대비 낮음 (카메라 기반 포즈 추정의 한계)
- 33DOF 커스텀 로봇 기준 → G1 29DOF로 포팅 필요
- 옥클루전(가림) 시 성능 저하
- 실시간 텔레오퍼레이션보다는 데이터 수집 + 자율 학습에 적합

#### 3.2.3 OmniH2O (CMU LeCAR Lab, CoRL 2024)

**핵심**: 다양한 입력 모달리티를 통한 범용 전신 텔레오퍼레이션

```
입력 소스 (택 1)     →  Kinematic Pose  →  RL Policy  →  Robot
- VR 헤드셋                (범용 인터페이스)   (sim-to-real)
- RGB 카메라
- 음성 명령 (GPT-4o)
```

**장점**:
- 다중 입력 모달리티 (VR / RGB / 텍스트)
- OmniH2O-6 데이터셋 공개 (6개 일상 테스크)
- GPT-4o 통합으로 자율 제어 가능

**단점**:
- 주로 Unitree H1 기반 (G1 포팅 필요)
- VR 모드에서도 하반신 추적 정확도 이슈

#### 3.2.4 TWIST (Stanford/SFU, CoRL 2025)

**핵심**: 광학 MoCap 기반 고정밀 전신 추적 + RL+BC 하이브리드 학습

```
Optical MoCap (Studio) → Online Retargeter → RL+BC Policy → Robot
   (고정밀 전신)           (0.7s 지연)        (0.2s 추론)     (G1, T1)
```

**장점**:
- 최고 수준의 추적 정확도 (광학 MoCap)
- RL+BC 하이브리드가 순수 RL이나 DAgger보다 우수
- G1, Booster T1 검증 완료
- 다양한 전신 기술: loco-manipulation, 표현적 동작

**단점**:
- **광학 MoCap 시스템 필요 (비이동식, 고비용)**
- 전체 시스템 지연 ~0.9초
- MoCap 스튜디오 환경 종속

#### 3.2.5 HOMIE (Shanghai AI Lab/CUHK, RSS 2025) ⭐ 가성비 최고

**핵심**: $500 저비용 외골격 + 페달로 전신 텔레오퍼레이션

```
Operator                    →  Joint Angles  →  RL Policy  →  Robot
├── 외골격 팔 (7DOF × 2)       (직접 매핑)      (보행+상체)    (G1, GR-1)
├── 모션 글러브 (15DOF × 2)
└── 발 페달 (보행/스쿼트)
```

**하드웨어 구성 ($500 미만)**:
- 3D 프린팅 등각 외골격 팔 (7DOF × 2) - Unitree G1 팔 길이에 맞춤 설계
- 저비용 모션 감지 글러브 (15DOF × 2)
- 발 페달 (걷기/스쿼트/높이 조절)

**핵심 성과**:
- OpenTeleVision 대비 **2배 빠른** 테스크 완료
- 70%+ 모방학습 성공률
- 대칭 활용 시 10배 학습 가속
- RTX 4090에서 ~3시간 학습

**장점**:
- **$500 미만 최저 비용**
- Unitree G1 직접 지원 (팔 길이 맞춤 설계)
- IK 불필요 (등각 매핑으로 리타겟팅 오류 제거)
- 완전 오픈소스 (https://github.com/OpenRobotLab/OpenHomie)

**단점**:
- 3D 프린터 필요 (외골격 제작)
- 정교한 손가락 제어는 MANUS 대비 부족
- 착용 편의성 이슈
- 시각/촉각 피드백 없음

#### 3.2.6 HumanoidExo (NUDT/Midea, 2025)

**핵심**: 경량 외골격 + LiDAR + 손목 카메라로 대규모 데이터 수집

```
Operator                        →  Joint Angles + Vision  →  VLA + RL  →  Robot
├── 등각 외골격 팔 (7DOF × 2)       (직접 매핑)                (자율 학습)    (G1)
├── Dexmo 촉각 글러브
├── Mid-360 LiDAR                   (오도메트리)
└── 손목 카메라 × 2                  (환경 인식)
```

**핵심 성과**:
- 텔레오퍼레이션 5회 + 외골격 데이터 195회 → 성공률 5% → **80%**
- 8m 걷기 + 간섭 복구
- 새로운 환경/물체로 일반화
- **외골격 데이터만으로 새로운 스킬(보행) 학습 가능**

**차별점**: "embodiment gap 최소화" — 외골격이 인체와 로봇 사이의 구조적 차이를 최소화

#### 3.2.7 Unitree xr_teleoperate (공식)

**핵심**: Unitree 공식 XR 텔레오퍼레이션 (상체 중심)

지원 장치: Apple Vision Pro, PICO 4 Ultra Enterprise, Meta Quest 3

```
XR Device  →  Hand/Controller Pose  →  IK  →  Robot (G1/H1)
             + Camera Stream (서버→XR)
```

**한계**: 상체 텔레오퍼레이션 중심, 보행 제어는 별도 RL 정책 또는 조이스틱

## 4. 하드웨어 옵션 상세 분석

### 4.1 VR 헤드셋

| 장치 | 가격 | 핸드 트래킹 | 바디 트래킹 | 외부 트래커 | Isaac Lab 통합 |
|------|------|-----------|-----------|-----------|---------------|
| **PICO 4 Ultra Enterprise** | ~$800 | ✅ | ✅ IOBT + 트래커 | ✅ PICO Motion Tracker | ✅ SONIC/GR00T |
| Meta Quest 3S | ~$300 | ✅ | ⚠️ IOBT (상체만) | ❌ 미지원 | ✅ CloudXR |
| Meta Quest 3 | ~$500 | ✅ | ⚠️ IOBT (상체만) | ❌ 미지원 | ✅ CloudXR |
| Apple Vision Pro | ~$3,500 | ✅✅ (최고) | ❌ visionOS 제한 | ❌ 미지원 | ✅ 공식 XR Client |

#### PICO 4 Ultra Enterprise ⭐ 전신 텔레오퍼레이션용 최적

- **PICO Motion Tracker** (발목 장착): 27g, 지연 ~20ms, 위치 편차 5cm, 각도 편차 6°
- 24개 스켈레톤 포인트 추적 (발목 트래커 2개만으로)
- 걸음 감지 정확도 98%+
- Full-Body Tracking 모드: 발목 2개 + (선택) 허리 1개
- **SONIC이 정확히 이 장치로 G1 전신 텔레오퍼레이션 검증 완료**

#### Apple Vision Pro — 핸드 트래킹에는 최적이나 전신 부적합

- 12개 동기화 카메라 + M2 + R1 Neural Engine → mm 수준 핸드 트래킹
- 100Hz 추적 주파수
- **한계**: visionOS에서 카메라 스트림 API 없음 → 커스텀 바디 포즈 감지 불가
- ARKit Body Tracking은 iOS에서만 완전 지원, visionOS에서는 제한적

#### Xsens Link + Xsens Humanoid SW ⭐ 전문 등급

**Xsens Humanoid 소프트웨어** (2025년 11월 출시):

**네이티브 통합**: ROS 2, NVIDIA Isaac Sim, MuJoCo, Linux 수신기

### 6.4 SMPL 리타겟팅 파이프라인

모든 전신 텔레오퍼레이션 프레임워크의 공통 요소는 **SMPL/SMPL-X 인체 모델**이다:

```
인체 동작 입력          SMPL 포즈                로봇 관절
┌──────────┐    ┌──────────────────┐    ┌────────────────┐
│ VR 5-point │    │ 24 body joints   │    │ G1 29 DOF      │
│ IMU 슈트    │ →  │ + shape params   │ →  │ (7 arm × 2     │
│ RGB 카메라   │    │ + global orient  │    │ + 3 waist      │
│ 외골격       │    │ (SMPL format)    │    │ + 6 leg × 2    │
└──────────┘    └──────────────────┘    │ + 12 hand × 2)  │
                                         └────────────────┘
```

**SONIC 접근법**: Sparse Sensor (5-point) → SMPL → RL Policy (직접 관절 명령)
**HumanPlus 접근법**: RGB → SMPL (포즈 추정) → Retargeting → RL Policy

```
┌─────────────────────────────────────────────────────────────┐

│  전신 정확도: ★★★★★ (SONIC 100% 성공률)                       │
│  손가락 정확도: ★★★★★ (MANUS mm 수준)                         │
│  Isaac Lab 호환: ★★★★★ (네이티브)                             │
└─────────────────────────────────────────────────────────────┘
```

**선택 근거**:

1. **NVIDIA 공식 검증**: SONIC이 정확히 PICO + 발목 트래커 조합으로 G1에서 100% 성공률 달성
2. **Isaac Lab 네이티브**: GR00T-WBC가 Isaac Lab 위에 구축됨 → 별도 프레임워크 포팅 불필요
3. **기존 코드 재사용**: `g1_upper_body_retargeter.py`, `dex_retargeter.py`, `manus_vive.py` 등 활용
4. **확장성**: 비디오/텍스트/음악 모달리티도 지원 → 향후 자율 제어로 전환 용이
5. **점진적 도입**: Phase 1은 Quest 3S 유지, Phase 2에서 PICO 추가 → 리스크 최소화

### 8.2 대안 권장 (예산 제한 시)

**대안 A: HOMIE 외골격 ($500)**
- 3D 프린터 보유 시 최적
- 등각 매핑으로 높은 정확도
- G1 공식 지원, 오픈소스
- 단, 착용 편의성과 손가락 정밀도는 PICO+MANUS 대비 떨어짐

**대안 B: PICO 4 Ultra + 트래커만 ($900, MANUS 없이)**
- PICO 내장 핸드 트래킹으로 손가락 제어 (정밀도 낮음)
- 전신 보행은 완전히 지원
- 나중에 MANUS 추가 가능

**대안 C: RGB 카메라만 ($0, HumanPlus 방식)**
- 초기 프로토타이핑에만 권장
- 정확도 부족으로 정교한 테스크에는 부적합
