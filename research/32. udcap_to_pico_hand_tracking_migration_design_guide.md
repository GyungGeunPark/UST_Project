## 1. 현재 시스템 분석 (왜 UDCAP가 안 되는지)

### 1.1 UDCAP 데이터 파이프라인 (현재)

```
[Windows 미니PC]                                          [Windows 메인PC + Pico 4 Ultra/VD]
 UDCAP Software ──VMC OSC UDP 39539──▶ vmc_receiver.py ──┐
                                                          │
 (Pico 컨트롤러는 Index 컨트롤러로 위장 by UDCAP)         ▼
 SteamVR Skeletal Input 2.0 / Index finger curl ──▶ vr_sampler.py ──▶ snapshot["hands"], action_inputs["finger_curls"]
                                                          │
                                                          ▼
                                          gr1t2_retargeter._resolve_hand_joints()
                                                          │
                              우선순위 1) DexPilot       2) Skeletal 31-bone   3) finger-curl   4) VMC bones   5) trigger/grip   6) idle
                                                          │
                                                          ▼
                                          fourier_hand_mapper.pack_22d() (좌·우 각 11D → 22D, PACK_22D_SIGNS 부호 적용)
                                                          │
                                                          ▼
                                              env.step(action[14:36] = 22 hand joints)
```

### 1.2 9.10 ~ 9.18 fix 누적에도 잔존하는 UDCAP 한계

| 이슈 | 원인 | 현재 완화 (9.18까지) | 한계 |
|---|---|---|---|
| 1) frozen finger (특히 L 중지/약지/소지 Δ < 0.05 rad) | UDCAP 글러브 굽힘 센서 자체가 해당 손가락에 변화량 거의 안 실음 | 200 frame 후 stuck-finger 자동 진단 메시지 | 코드로 해결 불가 — 글러브 하드웨어/펌웨어 단의 신호 부재 |
| 2) 좌·우 손 신호 강도 비대칭 (RSSI/페어링 차이) | 무선 동글, 글러브 IMU 캘리브 차이 | tanh amplification, finger_proximal_scale CLI 튜닝 | 한쪽이 saturate 되면 반대쪽은 mid-range — 정밀 조작 불능 |
| 3) VMC bone REST POSE 비단위 쿼터니언 | UDCAP가 "hand open"에서도 ~16° 오프셋 quat 송출 | 첫 10 frame 평균 zero-cal | 캘 윈도우(0.5s) 내 사용자 미세 움직임이 그대로 baseline → 후속 모션 일부 흡수 |
| 4) thumb yaw midpoint 버그 패턴 잔존 가능성 | 9.15 piecewise linear 로 치료됨 | yaw=0 → 정확히 0 매핑 | 글러브 thumb yaw 센서 자체가 부정확하면 무용 |
| 5) Skeletal Input 2.0 미구현 | UDCAP 드라이버 한계 | finger-curl(Index profile) action으로 대체 | curl 5채널만 — 마디별 굽힘 정보 없음 |
| 6) 양쪽 글러브 + Pico 컨트롤러 + VD 컨트롤러 충돌 | SteamVR Add-On 다중 등록(`prism`/`udcap`/`VD`) | `prism` OFF 권고 | 사용자가 SteamVR Add-On 직접 토글 필요 |

요약: **UDCAP의 한계는 코드가 아니라 신호원의 한계** — 손가락 마디 단위 정확도가 근본적으로 부족.

### 1.3 22D 액션 레이아웃 (변경 없음 — 마이그레이션의 contract)

`fourier_hand_mapper.pack_22d()`가 합치는 22D 손가락 슬롯은 PICO 마이그레이션 후에도 **그대로 유지**한다. 이는 USD/Pink IK/`hand_joint_names` 와 묶인 계약이다.

```
[ 0] L_index_proximal       [10] L_index_intermediate     [20] L_thumb_distal
[ 1] L_middle_proximal      [11] L_middle_intermediate    [21] R_thumb_distal
[ 2] L_pinky_proximal       [12] L_pinky_intermediate
[ 3] L_ring_proximal        [13] L_ring_intermediate
[ 4] L_thumb_proximal_yaw   [14] L_thumb_proximal_pitch
[ 5] R_index_proximal       [15] R_index_intermediate
[ 6] R_middle_proximal      [16] R_middle_intermediate
[ 7] R_pinky_proximal       [17] R_pinky_intermediate
[ 8] R_ring_proximal        [18] R_ring_intermediate
[ 9] R_thumb_proximal_yaw   [19] R_thumb_proximal_pitch

PACK_22D_SIGNS = (-1)*10 + (-1)*4 + (+1) + (-1)*4 + (+1) + (+1)*2  # 22 entries
                 ↑ 굽힘 방향이 음수인 GR1T2 USD 한계 ([-1.57, 0]) 기반 sign-flip
```

PICO 측 출력은 **반드시 unsigned 양수 굽힘 magnitude (0..1.57 rad)**로 11-vector를 만들어 `pack_22d(left_11, right_11)`에 넘긴다. 부호 반전은 packer가 그대로 적용한다.

## 2. PICO 4 Ultra 핸드 트래킹 — 신호원 사양

### 2.1 데이터 소스: XRoboToolkit App (Pico) → XRoboToolkit-PC-Service (PC)

레퍼런스: `XRoboToolkit-PC-Service/README.md` §"PICO Device JSON Data Description" → "Hand Gesture"

```json
{
  "leftHand": {
    "isActive": 0|1,
    "count": 26,
    "scale": 1.0,
    "timeStampNs": <int64>,
    "HandJointLocations": [
      { "p": "px,py,pz,qx,qy,qz,qw", "s": <ulong>, "r": <float> },
      ... 26 entries
    ]
  },
  "rightHand": { ... 동일 구조 }
}
```

| 필드 | 의미 | 사용 |
|---|---|---|
| `isActive` | 0=low / 1=high tracking quality | **이 값이 0이면 해당 손은 fallback 단계로 즉시 넘긴다** |
| `count` | 항상 26 | 검증용 invariant |
| `scale` | 사용자 손 크기 (1.0 = standard) | 우리는 각도 기반이라 무시 |
| `HandJointLocations[i].p` | i번 관절의 7D pose `(x,y,z,qx,qy,qz,qw)`, **left-handed** Y-up Z-in, **헤드 pose 원점** | 마디별 굽힘 각도 추출 입력 |
| `HandJointLocations[i].s` | 비트마스크 `OrientationValid=1, PositionValid=2, OrientationTracked=4, PositionTracked=8` | `s & 0xF == 0xF` 인 관절만 신뢰 |
| `HandJointLocations[i].r` | 관절 반경 (m) | 사용 안 함 |

### 2.2 26-joint 인덱스 표 (README 발췌, 마이그레이션 핵심)

```
0  Palm                  ← 손바닥 중심 (origin for some)
1  Wrist                 ← 손목 (마이그레이션 시 wrist-local 기준점)
2  Thumb_metacarpal      ┐
3  Thumb_proximal        │ thumb chain (4 joints + tip)
4  Thumb_distal          │
5  Thumb_tip             ┘
6  Index_metacarpal      ┐
7  Index_proximal        │
8  Index_intermediate    │ index chain (5 joints + tip)
9  Index_distal          │
10 Index_tip             ┘
11 Middle_metacarpal     ┐ ... middle (5)
12 Middle_proximal       │
13 Middle_intermediate   │
14 Middle_distal         │
15 Middle_tip            ┘
16 Ring_metacarpal       ┐ ... ring (5)
17 Ring_proximal         │
18 Ring_intermediate     │
19 Ring_distal           │
20 Ring_tip              ┘
21 Little_metacarpal     ┐ ... pinky (5)
22 Little_proximal       │
23 Little_intermediate   │
24 Little_distal         │
25 Little_tip            ┘
```

### 2.3 좌표계와 단위
- 위치: meters, **left-handed** (X right, Y up, Z **in** = 화면 안쪽)
- 회전: quaternion `(qx, qy, qz, qw)`
- 원점: XRoboToolkit 앱 시작 시 헤드 pose
- 시계열: `timeStampNs` 단조 증가, 보통 **72Hz 송출** (Pico 4 Ultra 기본 카메라 fps)
- 좌표계 차이는 **마디별 굽힘 각도 추출에 영향 없음** — 우리는 wrist-local 상대벡터/상대쿼터니언만 사용

### 2.4 통신 옵션 비교

XRoboToolkit-PC-Service에서 호스트 PC로 데이터를 끌어오는 방법은 세 가지:

| 옵션 | 방식 | 장점 | 단점 |
|---|---|---|---|
| **A) ConsoleDemo subprocess** | `RoboticsServiceProcess` 백그라운드 + `ConsoleDemo` 자식 프로세스 stdout 파싱 | • SDK 빌드/링크 불필요<br>• ust_260220 의 `unified_bridge.py` 와 동일 패턴 → 재사용 가능<br>• Windows 바이너리 이미 `Redistributable/win/` 에 존재 | • subprocess stdout 버퍼링 주의 (`stdbuf -oL` 또는 Windows에서는 `setvbuf` 동등 환경변수 필요) |
| **B) gRPC 직접 연결** | Python `grpcio` 로 `RoboticsServiceProcess` 의 PXREAGRPCServer 직접 호출 | • subprocess 한 단계 제거, 지연 ↓<br>• ConsoleDemo 의존성 제거 | • `.proto` 정의 + 코드 생성 + 의존성 추가<br>• ust_ws 에 검증된 사례 없음 → 새 위험 |
| **C) Pico 앱이 직접 TCP 송출** | XRoboToolkit App APK 내부에서 호스트 IP 로 raw TCP JSON 송신 | • PC 서비스 불필요 | • 공식 지원 미확인 / APK 수정 필요 |

권장: **옵션 A** — 검증된 패턴, ust_260220 코드 80% 재사용. Windows 포트 시 `Redistributable/win/ConsoleDemo.exe` 와 그 디렉토리의 DLL/`grpc/lib/`만 PATH 에 넣어주면 끝.

### 2.5 운영 위험 요소 (PICO 측)

| 위험 | 완화 |
|---|---|
| 1) 손이 카메라 시야 밖 → `isActive=0` | retargeter 우선순위에서 자동으로 PICO 단계 skip → UDCAP/skeletal 로 fallthrough. UI 로 "L hand: lost (out of view)" 표시 권장. |
| 2) 손가락이 다른 손/물체 뒤에 occlusion | 일부 joint `s & 0xF != 0xF` → 그 joint 만 보정 (사용 안 함, mimic 으로 대체) |
| 3) Pico Connect / Virtual Desktop / XRoboToolkit App **공존 가능성** | research §26 (Pico OS 5.14+ 멀티태스킹) 결론: **공존 가능**. 단 SteamVR Add-On 에서 `prism` (Pico Connect) 비활성, VD + XRoboToolkit only |
| 4) XRoboToolkit App **포그라운드 실행** 강제 | Pico OS 5.14 멀티태스크 모드 + XRoboToolkit App 활성 유지 (홈 버튼 누르면 백그라운드로 가서 송출 멈춤) |
| 5) 헤드셋 시작 시 좌표계 드리프트 | Pico 6DoF SLAM 신뢰 — 사용자에게 시작 직후 정면 응시 30초 권장 (research §13) |
| 6) WiFi 지연/jitter | XRoboToolkit JSON ~72Hz, 5GHz 단독 SSID + AP 직결 권장 (research §17) |

### 3.3 손가락 소스 우선순위 chain (변경)

```
NEW priority order in gr1t2_retargeter._resolve_hand_joints():

1. DexPilot                         (URDF 가능 시, 변경 없음)
2. PICO 26-joint hand tracking      ← ✱ 신규

4. SteamVR finger-curl 5-channel    (UDCAP Index profile, 기존)
5. VMC OSC bones                    (UDCAP Path B, 기존)
6. Trigger/grip button gesture      (legacy, 기존)
7. Idle (zeros)
```

각 단계는 "데이터가 있고 의미 있게 변동하는가"로 판정:
- PICO: `isActive == 1` AND 최신 frame age < 200 ms AND 26 joint 모두 `s & 0xF == 0xF`
- 그 외 단계는 기존 로직 그대로

### 3.4 PicoHandMapper 알고리즘 (26 joint → 11D)

#### 3.4.1 기본 원칙
- **각도 기반(scalar bend angle)** — quaternion 분해의 axis ambiguity 회피
- 입력은 wrist-local 좌표계 보장됨 (PICO 자체가 마디별 절대 좌표 송출하지만, 우리는 인접 joint 사이 **벡터**만 사용)
- 좌·우 출력 11D 양수 magnitude (0..joint_limit) — 부호는 `pack_22d` 가 처리

#### 3.4.2 손가락 4개 (index/middle/ring/pinky) 굽힘 각도

각 손가락마다 metacarpal → proximal → intermediate → distal → tip 순서로 5 joint 가 있다. 우리는 **MCP(proximal vs intermediate)** 의 한 각도와 **PIP(intermediate vs distal)** 의 한 각도를 추출.

```python
def finger_flex_angles(joints):
    """
    joints[0] = metacarpal (palm side)
    joints[1] = proximal
    joints[2] = intermediate
    joints[3] = distal
    joints[4] = tip
    Returns:
        mcp_flex: float, radian — proximal joint 굽힘 (0=펴짐, ~1.57=완전 굽힘)
        pip_flex: float, radian — intermediate joint 굽힘
    """
    p_mc = joints[0].p   # 3D vec
    p_pr = joints[1].p
    p_in = joints[2].p
    p_di = joints[3].p
    v_pmc_to_pr  = p_pr - p_mc           # bone1: metacarpal→proximal
    v_pr_to_in   = p_in - p_pr           # bone2: proximal→intermediate
    v_in_to_di   = p_di - p_in           # bone3: intermediate→distal
    mcp_flex = pi - angle_between(v_pmc_to_pr, v_pr_to_in)
    pip_flex = pi - angle_between(v_pr_to_in,  v_in_to_di)
    return mcp_flex, pip_flex
```

여기서 `angle_between(a, b) = acos(dot(a,b) / (|a||b|))`. 손가락이 곧게 펴지면 두 인접 본은 동일 방향 → angle=0 → flex=π → 단위 변환으로 0. 완전히 굽히면 90° → flex=π/2 → joint limit 부근.

`pi` 와의 관계 보정 후 [0, π] 범위 → `[0, _PROXIMAL_MAX]` (=1.57) 클램프.

#### 3.4.3 엄지 (thumb) — 4 joint 만

엄지는 metacarpal-proximal-distal-tip 4 joint (intermediate 없음). Fourier 손은 thumb 에 yaw(opposition) + pitch(flex) 두 자유도가 있으므로:

- **Thumb yaw (opposition)** — 손바닥 평면(wrist-palm-index_metacarpal 으로 정의되는 평면)에 thumb_metacarpal 벡터를 투영하고, "손바닥 안쪽 방향"과의 각도 측정. URDF range `[-0.5, 1.0]`. yaw=0 = 자연 휴식 자세.
  ```python
  v_palm_normal = cross(p_index_mc - p_wrist, p_palm - p_wrist)
  v_palm_to_index = p_index_mc - p_palm
  v_palm_to_thumb_mc = p_thumb_mc - p_palm
  # 손바닥 평면에 thumb_metacarpal 투영
  v_thumb_in_palm = v_palm_to_thumb_mc - dot(v_palm_to_thumb_mc, v_palm_normal) * v_palm_normal
  yaw_signed = signed_angle(v_palm_to_index, v_thumb_in_palm, axis=v_palm_normal)
  # piecewise linear (9.15 fix 와 동일 로직)
  thumb_yaw = yaw_signed * THUMB_YAW_RANGE[1] if yaw_signed >= 0 else yaw_signed * abs(THUMB_YAW_RANGE[0])
  ```

- **Thumb pitch (flex)** — metacarpal → proximal → distal 사이 굽힘 각도, 손가락 4개와 동일 공식. URDF range `[0, 1.22]`.
- **Thumb distal** — proximal → distal → tip mimic, 또는 단순히 `thumb_pitch * distal_mimic` (현재 0.75 — `fourier_hand_mapper` 와 동일 정책).

#### 3.4.4 출력 11-vector 패킹 (FOURIER_JOINT_DIM 순서, fourier_hand_mapper와 동일)

```
out[0] = index_proximal_flex   (mcp_flex, 4-finger 공식)
out[1] = middle_proximal_flex
out[2] = pinky_proximal_flex   ← Little 사용
out[3] = ring_proximal_flex
out[4] = thumb_yaw             (opposition)
out[5] = index_intermediate    = pip_flex (또는 mimic 0.85 × out[0])
out[6] = middle_intermediate   = pip_flex
out[7] = pinky_intermediate    = pip_flex
out[8] = ring_intermediate     = pip_flex
out[9] = thumb_pitch
out[10] = thumb_distal         = thumb_pitch_distal_flex (또는 mimic 0.75 × out[9])
```

- PIP 직접 측정은 PICO 가 카메라 occlusion 시 noisy → **기본 정책: out[5..8] 은 mimic = 0.85 × out[0..3]**, 단 `--pico_pip_mode direct` flag 로 직접 측정 모드 전환 가능.
- thumb distal 도 기본 mimic (0.75 × out[9]).

#### 3.4.5 Smoothing & filter

- **Per-joint EMA (지수 이동 평균)** — `out_smoothed = alpha * out_raw + (1-alpha) * out_smoothed_prev`, alpha ≈ 0.6 (≈ 30Hz 효과). 사용자 cmd 라인으로 튜닝.
- **신뢰도 게이트** — frame 의 isActive=1 AND status flags valid → 적용 / 그 외 직전 smoothed 값 유지 (0.3 s 한정). 0.3 s 초과 시 chain 다음 단계로 fallthrough.

#### 3.4.6 좌·우 부호 (sanity check)

PICO 는 left/right 각각 **left-handed** 좌표계로 송출. 우리가 추출하는 **각도는 부호 없는 magnitude (≥0)** 라 그대로 사용해도 됨. `pack_22d` 의 `PACK_22D_SIGNS` 가 GR1T2 USD 의 negative 굽힘 방향으로 변환.

엄지 yaw 만 piecewise linear 후 packer 가 -1 곱하므로 결과적으로 [-1.0, +0.5] 범위 (URDF `[-0.5, +1.0]` 의 부호 반전 후) 가 정상.

```python
def _pico_hand_usable(self, hand) -> bool:
    """PICO 손 데이터를 신뢰할 수 있는지 판정."""
    if not hand.is_active:
        return False
    if hand.timestamp_age_ms > self.cfg.pico_frame_max_age_ms:
        return False
    valid_joints = int((hand.joints_s & 0x0F == 0x0F).sum())

        return False
    return True
```

### Step 1 — `pico_hand_bridge.py` 작성 (신규)

`ust_ws/ust_fourier_260421/scripts/pico_hand_bridge.py`:

```python
#!/usr/bin/env python3
"""PICO 4 Ultra 핸드 트래킹 브릿지 (Windows).

ust_260220의 unified_bridge.py 의 Windows + 손 전용 슬림 버전.
RoboticsServiceProcess.exe를 백그라운드 서비스로 가정하고
ConsoleDemo.exe를 subprocess로 실행한 뒤 stdout 'device data{json}'
라인을 파싱하여 PICO Hand 데이터만 추출, TCP :8890 로 송출.

Usage:
    python pico_hand_bridge.py
    python pico_hand_bridge.py --console_demo "C:\\path\\to\\ConsoleDemo.exe" --output_port 8890
"""
from __future__ import annotations

import argparse, json, os, signal, socket, subprocess, sys, threading, time
from pathlib import Path
from typing import Optional


def _find_console_demo() -> str:
    cands = [
        Path(__file__).resolve().parents[3]    # ust_ws/
            / "XRoboToolkit-PC-Service" / "RoboticsService"
            / "Redistributable" / "win" / "ConsoleDemo.exe",
    ]
    for p in cands:
        if p.is_file():
            return str(p)
    return ""


class XRTHandReceiver:
    _PREFIX = "device data"

    def __init__(self, console_demo_path: str) -> None:
        self.path = console_demo_path
        self._latest_hand: Optional[dict] = None
        self._lock = threading.Lock()
        self._proc: Optional[subprocess.Popen] = None
        self._running = False
        self._n = 0

    def start(self) -> None:
        self._running = True
        threading.Thread(target=self._loop, daemon=True).start()

    def _loop(self) -> None:
        if not self.path:
            print("[bridge] ConsoleDemo.exe 경로를 찾지 못했습니다.")
            return
        cwd = str(Path(self.path).parent)
        env = os.environ.copy()
        # Windows: PATH에 grpc/lib 추가 (DLL 로드용)
        grpc_lib = str(Path(cwd) / "grpc" / "lib")
        env["PATH"] = grpc_lib + os.pathsep + env.get("PATH", "")
        # 라인 버퍼링 — Python 3.7+ stdout이 PIPE면 자식 stdio 도 unbuffer
        env["PYTHONUNBUFFERED"] = "1"

        while self._running:
            try:
                print(f"[bridge] start: {self.path}")
                self._proc = subprocess.Popen(
                    [self.path],
                    stdout=subprocess.PIPE, stderr=subprocess.PIPE,
                    cwd=cwd, env=env,
                    bufsize=1,                   # line-buffered
                    universal_newlines=True,
                )
                for line in self._proc.stdout:
                    if not self._running: break
                    line = line.strip()
                    if not line.startswith(self._PREFIX):
                        continue
                    js = line[len(self._PREFIX):].strip()
                    try:
                        outer = json.loads(js)
                        value = outer.get("value", outer)
                        if isinstance(value, str):
                            value = json.loads(value.replace("\\", ""))
                        hand = value.get("Hand")
                        if not hand: continue
                        with self._lock:
                            self._latest_hand = {
                                "left":  hand.get("leftHand"),
                                "right": hand.get("rightHand"),
                                "ts_ns": value.get("timeStampNs", time.time_ns()),
                            }
                            self._n += 1
                        if self._n == 1:
                            print(f"[bridge] ✓ 첫 Hand 데이터 수신")
                    except json.JSONDecodeError:
                        pass
                self._proc.wait(timeout=3)
            except Exception as e:
                print(f"[bridge] err: {e}")
            time.sleep(2)

    def get(self) -> Optional[dict]:
        with self._lock:
            return self._latest_hand

    def stop(self) -> None:
        self._running = False
        if self._proc and self._proc.poll() is None:
            self._proc.terminate()


def serve(recv: XRTHandReceiver, port: int, rate_hz: float) -> None:
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    s.bind(("0.0.0.0", port))
    s.listen(1)
    interval = 1.0 / rate_hz
    print(f"[bridge] TCP listening on :{port}")
    while True:
        try:
            client, addr = s.accept()
            print(f"[bridge] client {addr}")
            try:
                while True:
                    payload = recv.get()
                    if payload is None:
                        time.sleep(interval); continue
                    msg = json.dumps(payload, separators=(",", ":")) + "\n"
                    client.sendall(msg.encode("utf-8"))
                    time.sleep(interval)
            except (BrokenPipeError, ConnectionResetError, OSError):
                print("[bridge] client gone")
                continue
        except KeyboardInterrupt:
            return


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--console_demo", default=_find_console_demo())
    ap.add_argument("--output_port", type=int, default=8890)
    ap.add_argument("--rate", type=float, default=72.0)
    args = ap.parse_args()

    if not args.console_demo:
        print("ConsoleDemo.exe not found; pass --console_demo")
        sys.exit(1)

    recv = XRTHandReceiver(args.console_demo)
    recv.start()

    try:
        serve(recv, args.output_port, args.rate)
    finally:
        recv.stop()
```

### Step 2 — `pico_hand_receiver.py` 작성 (신규)

`ust_ws/ust_fourier_260421/teleop/pico_hand_receiver.py`:

핵심 책임:
- TCP 클라이언트 (자동 재연결, 5초 timeout)

```python
"""Receives PICO 4 Ultra hand tracking data over TCP from pico_hand_bridge.py.

Exposes the latest 26-joint snapshot as :class:`PicoHand` dataclasses for
:class:`gr1t2_retargeter.GR1T2FourierSteamVRRetargeter`.
"""
from __future__ import annotations

from dataclasses import dataclass
import json, socket, threading, time
from typing import Mapping, Optional

import numpy as np


@dataclass
class PicoHand:
    is_active: bool
    joints_p: np.ndarray   # (26, 3)  positions (m)
    joints_q: np.ndarray   # (26, 4)  qx,qy,qz,qw
    joints_s: np.ndarray   # (26,)    status flags (uint32)
    timestamp_ns: int
    timestamp_age_ms: float = 0.0


def _parse_pose7(csv: str) -> tuple:
    parts = csv.split(",")
    if len(parts) < 7: return (0,)*7
    return tuple(float(x) for x in parts[:7])


def _parse_hand_dict(d: Optional[dict], now_ns: int) -> Optional[PicoHand]:
    if not d: return None
    is_active = bool(d.get("isActive", 0))
    locs = d.get("HandJointLocations") or []
    n = len(locs)
    if n < 26:
        return None
    p = np.zeros((26, 3), dtype=np.float32)
    q = np.zeros((26, 4), dtype=np.float32)
    s = np.zeros((26,), dtype=np.uint32)
    for i, jl in enumerate(locs[:26]):
        x, y, z, qx, qy, qz, qw = _parse_pose7(jl.get("p", ""))
        p[i] = (x, y, z)
        q[i] = (qx, qy, qz, qw)
        s[i] = int(jl.get("s", 0))
    ts = int(d.get("timeStampNs", now_ns)) if d.get("timeStampNs") else now_ns
    return PicoHand(is_active, p, q, s, ts, (now_ns - ts) / 1e6)


class PicoHandReceiver:
    def __init__(
        self,
        host: str = "127.0.0.1",
        port: int = 8890,
        connect_timeout: float = 5.0,
        frame_max_age_ms: int = 200,
    ) -> None:
        self._host, self._port = host, port
        self._connect_timeout = connect_timeout
        self._frame_max_age_ms = frame_max_age_ms

        self._lock = threading.Lock()
        self._latest_left: Optional[PicoHand] = None
        self._latest_right: Optional[PicoHand] = None
        self._latest_ts_ns: int = 0
        self._connected = False
        self._running = False
        self._n_frames = 0

    def start(self) -> None:
        self._running = True
        threading.Thread(target=self._loop, daemon=True).start()

    def stop(self) -> None:
        self._running = False

    @property
    def is_connected(self) -> bool:
        return self._connected

    def get_hands(self) -> Optional[Mapping[str, PicoHand]]:
        with self._lock:
            now_ns = time.time_ns()
            if self._latest_ts_ns == 0:
                return None
            age_ms = (now_ns - self._latest_ts_ns) / 1e6
            if age_ms > self._frame_max_age_ms:
                return None
            out: dict = {}
            if self._latest_left:
                self._latest_left.timestamp_age_ms = age_ms
                out["left"] = self._latest_left
            if self._latest_right:
                self._latest_right.timestamp_age_ms = age_ms
                out["right"] = self._latest_right
            return out or None

    def _loop(self) -> None:
        while self._running:
            try:
                sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
                sock.settimeout(self._connect_timeout)
                sock.connect((self._host, self._port))
                sock.settimeout(None)
                self._connected = True
                print(f"[PicoHandReceiver] connected {self._host}:{self._port}")
                buffer = ""
                while self._running:
                    chunk = sock.recv(65536).decode("utf-8")
                    if not chunk: break
                    buffer += chunk
                    while "\n" in buffer:
                        line, buffer = buffer.split("\n", 1)
                        line = line.strip()
                        if not line: continue
                        try:
                            payload = json.loads(line)
                        except json.JSONDecodeError:
                            continue
                        now_ns = time.time_ns()
                        left = _parse_hand_dict(payload.get("left"), now_ns)
                        right = _parse_hand_dict(payload.get("right"), now_ns)
                        ts_ns = int(payload.get("ts_ns", now_ns))
                        with self._lock:
                            if left is not None:  self._latest_left = left
                            if right is not None: self._latest_right = right
                            self._latest_ts_ns = ts_ns
                            self._n_frames += 1
                self._connected = False
            except (ConnectionRefusedError, ConnectionResetError, OSError, socket.timeout):
                self._connected = False
                if self._running:
                    time.sleep(2)
```

### Step 3 — `pico_hand_mapper.py` 작성 (신규)

`ust_ws/ust_fourier_260421/teleop/pico_hand_mapper.py`:

핵심 책임:
- 26 joint positions → 11D Fourier per-side vector
- 손가락 4개 MCP/PIP 각도, 엄지 yaw/pitch/distal 각도 추출

```python
"""PICO 4 Ultra (XRoboToolkit) 26-joint hand → Fourier 11-joint mapper.

Drop-in finger source for :class:`GR1T2FourierSteamVRRetargeter`.
Output layout (11,) matches :data:`fourier_hand_mapper.FOURIER_JOINT_DIM`
so the result can be passed straight to :func:`fourier_hand_mapper.pack_22d`
together with the other side, and the standard PACK_22D_SIGNS will apply.
"""
from __future__ import annotations

import math
from typing import Optional

import numpy as np

from .fourier_hand_mapper import (
    FOURIER_JOINT_DIM, IDX_INDEX_PROX, IDX_MIDDLE_PROX, IDX_PINKY_PROX,
    IDX_RING_PROX, IDX_THUMB_YAW, IDX_INDEX_INT, IDX_MIDDLE_INT,
    IDX_PINKY_INT, IDX_RING_INT, IDX_THUMB_PITCH, IDX_THUMB_DIST,
    _PROXIMAL_MAX, _THUMB_YAW_RANGE, _THUMB_PITCH_MAX,
)
from .pico_hand_receiver import PicoHand


# PICO 26-joint indices (per XRoboToolkit JSON schema)
J_PALM, J_WRIST = 0, 1
J_THUMB = (2, 3, 4, 5)              # metacarpal, proximal, distal, tip
J_INDEX = (6, 7, 8, 9, 10)          # metacarpal, proximal, intermediate, distal, tip
J_MIDDLE = (11, 12, 13, 14, 15)
J_RING = (16, 17, 18, 19, 20)
J_LITTLE = (21, 22, 23, 24, 25)


def _angle_between(a: np.ndarray, b: np.ndarray) -> float:
    na, nb = float(np.linalg.norm(a)), float(np.linalg.norm(b))
    if na < 1e-9 or nb < 1e-9: return 0.0
    cos = float(np.dot(a, b) / (na * nb))
    return math.acos(max(-1.0, min(1.0, cos)))


def _signed_angle(a: np.ndarray, b: np.ndarray, axis: np.ndarray) -> float:
    """Signed angle from a to b measured around `axis`."""
    cross = np.cross(a, b)
    sign = 1.0 if float(np.dot(cross, axis)) >= 0.0 else -1.0
    return sign * _angle_between(a, b)


class PicoHandMapper:
    def __init__(
        self,
        proximal_scale: float = 1.0,
        thumb_scale: float = 1.0,
        intermediate_mimic: float = 0.85,
        distal_mimic: float = 0.75,
        pip_mode: str = "mimic",
        smoothing_alpha: float = 0.6,
        min_valid_joints: int = 22,
    ) -> None:
        self.proximal_scale = float(proximal_scale)
        self.thumb_scale = float(thumb_scale)
        self.intermediate_mimic = float(intermediate_mimic)
        self.distal_mimic = float(distal_mimic)
        assert pip_mode in ("mimic", "direct")
        self.pip_mode = pip_mode
        self.alpha = float(smoothing_alpha)
        self.min_valid_joints = int(min_valid_joints)

        self._smoothed = {False: np.zeros(FOURIER_JOINT_DIM, dtype=np.float32),
                          True:  np.zeros(FOURIER_JOINT_DIM, dtype=np.float32)}

    def reset(self) -> None:
        for k in self._smoothed:
            self._smoothed[k] = np.zeros(FOURIER_JOINT_DIM, dtype=np.float32)

    def map_hand_pico(self, hand: PicoHand, is_right: bool) -> np.ndarray:
        out = np.zeros(FOURIER_JOINT_DIM, dtype=np.float32)
        if not hand.is_active:
            return self._smoothed[is_right]   # 직전 smoothed 유지

        valid = (hand.joints_s & 0x0F == 0x0F)
        if int(valid.sum()) < self.min_valid_joints:
            return self._smoothed[is_right]

        p = hand.joints_p   # (26, 3)

        # 4 손가락 (index, middle, ring, pinky)
        for chain, prox_idx, int_idx in (
            (J_INDEX,  IDX_INDEX_PROX,  IDX_INDEX_INT),
            (J_MIDDLE, IDX_MIDDLE_PROX, IDX_MIDDLE_INT),
            (J_RING,   IDX_RING_PROX,   IDX_RING_INT),
            (J_LITTLE, IDX_PINKY_PROX,  IDX_PINKY_INT),
        ):
            mc, pr, inter, di, tip = (p[i] for i in chain)
            v_mcpr = pr - mc
            v_prin = inter - pr
            v_indi = di - inter
            mcp_flex = math.pi - _angle_between(v_mcpr, v_prin)
            out[prox_idx] = max(0.0, min(_PROXIMAL_MAX,
                                self.proximal_scale * mcp_flex))
            if self.pip_mode == "direct":
                pip_flex = math.pi - _angle_between(v_prin, v_indi)
                out[int_idx] = max(0.0, min(_PROXIMAL_MAX,
                                    self.proximal_scale * pip_flex))
            else:  # mimic
                out[int_idx] = out[prox_idx] * self.intermediate_mimic

        # 엄지 — yaw/pitch
        wrist  = p[J_WRIST]
        palm   = p[J_PALM]
        idx_mc = p[J_INDEX[0]]
        thb_mc = p[J_THUMB[0]]
        thb_pr = p[J_THUMB[1]]
        thb_di = p[J_THUMB[2]]

        # 손바닥 평면: wrist→palm, wrist→index_metacarpal
        v_wp = palm - wrist
        v_wi = idx_mc - wrist
        n_palm = np.cross(v_wp, v_wi)        # 손바닥 법선
        # palm-frame thumb_metacarpal 방향
        v_pt = thb_mc - palm
        v_pt_in_palm = v_pt - (np.dot(v_pt, n_palm) /
                               max(1e-9, float(np.linalg.norm(n_palm))**2)) * n_palm
        # palm-frame index_metacarpal 방향
        v_pi_in_palm = (idx_mc - palm) - (np.dot(idx_mc - palm, n_palm) /
                       max(1e-9, float(np.linalg.norm(n_palm))**2)) * n_palm
        yaw = _signed_angle(v_pi_in_palm, v_pt_in_palm, n_palm)  # rad
        # 9.15 piecewise (yaw=0 → 0)
        yaw_norm = max(-1.0, min(1.0, yaw / (math.pi/2)))
        if yaw_norm >= 0.0:
            out[IDX_THUMB_YAW] = yaw_norm * _THUMB_YAW_RANGE[1]
        else:
            out[IDX_THUMB_YAW] = yaw_norm * abs(_THUMB_YAW_RANGE[0])
        out[IDX_THUMB_YAW] = max(_THUMB_YAW_RANGE[0],
                                 min(_THUMB_YAW_RANGE[1], out[IDX_THUMB_YAW]))

        # 엄지 pitch (metacarpal-proximal-distal 굽힘)
        v_mtp = thb_pr - thb_mc
        v_pdi = thb_di - thb_pr
        thumb_pitch = math.pi - _angle_between(v_mtp, v_pdi)
        out[IDX_THUMB_PITCH] = max(0.0, min(_THUMB_PITCH_MAX,
                                    self.thumb_scale * thumb_pitch))
        out[IDX_THUMB_DIST] = out[IDX_THUMB_PITCH] * self.distal_mimic

        # smoothing
        prev = self._smoothed[is_right]
        smooth = self.alpha * out + (1.0 - self.alpha) * prev
        self._smoothed[is_right] = smooth.astype(np.float32)
        return self._smoothed[is_right]
```

### 5.2 런타임 위험

| 위험 | 대응 |
|---|---|
| 손이 카메라 시야 밖 → 손가락 멈춤 | retargeter 의 `_pico_hand_usable` 가 자동 fallthrough. 사용자에게는 source=skeletal 또는 button 으로 표시 |
| 격렬한 움직임으로 PICO 카메라 motion blur | XRT JSON `isActive=0` 송출 → 동일 fallthrough |
| 양손 겹침 (occlusion) | status flag 검사로 일부 joint 무효 → `min_valid_joints=22` 미달 시 fallthrough |
| 사용자 손 크기 매우 큼/작음 | scale 필드 무시, 각도 기반 알고리즘이므로 영향 미미. 필요 시 `--finger_proximal_scale` 로 보정 |
| Bridge ↔ device 사이 TCP 끊김 | receiver 자동 재연결 (2초 backoff), 그 동안 fallthrough |
| 외란 — 물체가 손과 가까워서 카메라가 손 인식 못함 | XRT 자체가 `isActive=0` 보고 |
| Fallback chain 의 source 선택이 빠르게 토글 (잡음) | mapper 의 EMA smoothing(α=0.6) + retargeter 의 `_pico_hand_usable` last-good 0.3s 윈도우로 흡수 |
