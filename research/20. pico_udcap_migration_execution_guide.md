## 3. 실행 순서

### Step 1: 호스트 서비스 시작

```bash
# 호스트(Ubuntu 24.04)에서 실행:
cd /workspace/isaaclab
```

```
PICO 4 Ultra에서:
1. XRoboToolkit App 실행

3. "Connect" → 상태: "WORKING" 확인
4. Motion Tracker 데이터 수신 확인 (App 내 시각화)
```

### Step 3: Windows 미니PC 시작

```
1. UDCAP Software 실행 (관리자 권한)
2. 글러브 연결 확인
3. VMC 전송 시작 (Settings → Data Transmission)
```

**호스트에서 VMC 수신 확인:**
```bash
python3 -c "
from pythonosc import dispatcher, osc_server
d = dispatcher.Dispatcher()
d.set_default_handler(lambda addr, *args: print(f'{addr}: {args[:3]}...'))
s = osc_server.ThreadingOSCUDPServer(('0.0.0.0', 39539), d)
print('VMC 수신 대기 중 (39539)... Ctrl+C로 종료')
s.serve_forever()
"
# UDCAP 데이터가 수신되면 /VMC/Ext/Bone/Pos 메시지 출력됨
```

### Step 4: Docker Isaac Lab에서 텔레오퍼레이션 실행

```bash

# 커스텀 USD 씬 (ust_human1.usd) + PICO 텔레오퍼레이션 (추천)
# ======================================================================

    --teleop_device pico --use_usd_scene

./isaaclab.sh -p ust_ws/ust_260220/scripts/record_demos.py \
    --teleop_device pico --use_usd_scene --num_demos 50

# === 커스텀 USD 씬 + HG-DAgger 교정 루프 (Phase 2) ===
./isaaclab.sh -p ust_ws/ust_260220/scripts/run_hg_dagger.py \
    --checkpoint ./models/bc_rnn/model_best.pth \
    --teleop_device pico --enable_vr

# 프리미티브 씬 (기존, 하위 호환)
```

## 5. HG-DAgger 개입 조작법 (PICO 컨트롤러)

| 동작 | PICO 컨트롤러 | 비고 |
|------|-------------|------|
| **개입 시작** | 양손 그립 동시 꽉 쥐기 (3프레임 유지) | 정책 자율 → 사람 제어 |
| **자율 복귀** | 양손 트리거 동시 당기기 (3프레임 유지) | 사람 제어 → 정책 자율 |
| **에피소드 리셋** | 양손 메뉴 버튼 동시 (3프레임) | 환경 리셋 |
| **오른쪽 그리퍼 닫기** | 오른쪽 트리거 > 50% | 물체 파지 |
| **왼쪽 그리퍼 닫기** | 왼쪽 트리거 > 50% | 물체 파지 |
| **양팔 이동** | 컨트롤러 공간 이동 | 델타 포즈로 변환 |

## 6. 디버그 및 트러블슈팅

### 6.1 브릿지 연결 확인

```bash
# 통합 브릿지 데이터 확인 (호스트에서)
python3 -c "
import socket, json
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.connect(('localhost', 8888))
buf = ''
for _ in range(5):
    buf += s.recv(65536).decode()
    while '\n' in buf:
        line, buf = buf.split('\n', 1)
        data = json.loads(line)
        xrt = data.get('xrt', {})
        udcap = data.get('udcap_fingers', {})
        print(f'XRT keys: {list(xrt.keys()) if xrt else \"없음\"}')
        print(f'UDCAP left bones: {len(udcap.get(\"left\", {}))}')
        print(f'UDCAP right bones: {len(udcap.get(\"right\", {}))}')
        print('---')
s.close()
"
```

### 6.2 디바이스 액션 디버그

```python
# Docker 내에서 Python으로 직접 테스트
import sys
sys.path.insert(0, "ust_ws/ust_260220")
from teleop import PICOFullBodyTeleopDevice

device = PICOFullBodyTeleopDevice(bridge_port=8888)
device.start()

import time
time.sleep(2)

action = device.advance()
if action is not None:
    print(f"Action shape: {action.shape}")
    print(f"Right EEF delta pos: {action[0:3]}")
    print(f"Right EEF delta rot: {action[3:6]}")
    print(f"Right gripper: {action[6]}")
    print(f"Left EEF delta pos: {action[7:10]}")
    print(f"Right hand joints: {action[14:26]}")
else:
    print("데이터 없음 - 브릿지 연결 확인")

device.stop()
```

### 6.3 일반적인 문제

| 증상 | 원인 | 해결 |
|------|------|------|
| `[PICODevice] 브릿지 연결 성공` 미출력 | 통합 브릿지 미실행 | `setup_pico_env.sh` 다시 실행 |
| XRT 데이터 비어있음 | PICO 미연결 | XRoboToolkit App에서 호스트 IP 확인 |
| UDCAP 데이터 없음 | VMC 미설정 또는 방화벽 | 미니PC VMC 설정 + 방화벽 확인 |
| 팔 움직임 없음 | 좌표계 변환 오류 | g1_retargeter.py Z축 반전 확인 |
| 개입 의도 없이 트리거됨 | grip_threshold 낮음 | `pico_intervention.py` threshold 0.9로 상향 |
| advance()가 None 반환 | 브릿지 데이터 미수신 | 6.1 브릿지 연결 확인 참조 |

## 7. 파라미터 튜닝 가이드

### 7.1 EEF 감도 조절

```python
# kitchen_sorting_env_cfg.py 내 pico_device_cfg
self.pico_device_cfg = {
    "position_scale": 1.0,    # 위치 감도 (↑ = 더 크게 움직임)
    "rotation_scale": 1.0,    # 회전 감도
    "gripper_threshold": 0.5, # 그리퍼 닫힘 트리거 (↓ = 더 쉽게 닫힘)
    ...
}
```

### 7.2 개입 디바운스 조절

```python
# teleop/pico_intervention.py
interface = PICOInterventionInterface(
    device=pico_device,
    grip_threshold=0.8,      # 개입 트리거 민감도 (↑ = 더 세게 쥐어야)
    trigger_threshold=0.8,    # 복귀 트리거 민감도
    debounce_frames=3,        # 디바운스 (↑ = 더 오래 유지해야 트리거)
)
```
