## 1. Isaac Sim 실행 방법

### 1.1 Docker 컨테이너 내에서 GUI 실행

현재 작업 환경은 Docker 컨테이너이므로, GUI를 사용하려면 **X11 포워딩** 또는 **VNC**가 필요합니다.

#### 방법 A: Isaac Sim GUI + Isaac Lab 확장 (권장)

```bash
# Docker 컨테이너 내에서:
./isaaclab.sh -s
```

이 명령은 내부적으로 다음을 실행합니다:
```bash
/workspace/isaaclab/_isaac_sim/kit/kit \
    /workspace/isaaclab/apps/isaaclab.python.kit \
    --ext-folder /workspace/isaaclab/source
```

**결과**: Isaac Sim GUI가 열리며 Isaac Lab 확장 + Content Browser + Stage + Property 패널 사용 가능.

#### 방법 B: Isaac Sim 순수 GUI (확장 없이)

```bash
/workspace/isaaclab/_isaac_sim/kit/kit \
    /workspace/isaaclab/_isaac_sim/apps/isaacsim.exp.full.kit
```

#### 방법 C: 특정 USD 파일을 열면서 실행

```bash
./isaaclab.sh -s /path/to/your/scene.usd
```

#### 방법 D: 렌더링 품질 선택

```bash
# 고품질 (씬 디자인 시 추천)
/workspace/isaaclab/_isaac_sim/kit/kit \
    /workspace/isaaclab/apps/rendering_modes/quality.kit \
    --ext-folder /workspace/isaaclab/source

# 성능 우선 (빠른 반복 작업 시)
/workspace/isaaclab/_isaac_sim/kit/kit \
    /workspace/isaaclab/apps/rendering_modes/performance.kit \
    --ext-folder /workspace/isaaclab/source
```

### 1.2 X11 디스플레이 설정 (Docker에서 GUI 사용 시)

```bash
# 호스트에서:
xhost +local:docker

# Docker 컨테이너에서 확인:
echo $DISPLAY
# → :0 또는 :1 이면 정상

# 테스트:
glxinfo | head -5
# → GPU 정보 출력되면 정상
```

Docker Compose에서 X11 설정 (`docker/x11.yaml` 참조):
```yaml
services:
  isaac-lab:
    environment:
      - DISPLAY=${DISPLAY}
    volumes:
      - /tmp/.X11-unix:/tmp/.X11-unix:rw
```

### 1.4 Isaac Sim GUI 핵심 패널

Isaac Sim을 열면 다음 패널을 사용합니다:

| 패널 | 위치 | 용도 |
|------|------|------|
| **Viewport** | 중앙 | 3D 씬 시각화, 마우스 조작 |
| **Stage** | 우측 | USD 프림 계층 구조 트리 |
| **Property** | 우측 하단 | 선택한 프림의 속성 편집 |
| **Content Browser** | 하단 | NVIDIA 에셋 검색/드래그 |
| **Console** | 하단 | Python 스크립트 실행 |

**핵심 조작**:
- `W/E/R`: 이동/회전/스케일 기즈모 전환
- `F`: 선택 프림으로 카메라 포커스
- `마우스 휠`: 줌
- `Alt+좌클릭 드래그`: 오빗 회전
- `Alt+우클릭 드래그`: 패닝

## 4. Isaac Sim GUI에서 씬 모델링 절차

### 4.1 새 USD 스테이지 생성


### 4.2 기본 환경 설정

```
1. Stage 패널에서 우클릭 → Create → Xform → "World" 이름 지정
2. "World" 선택 → 우클릭 → Create → Ground Plane
3. Viewport → Rendering → RTX Real-Time (고품질)
```

```
1. Stage → 우클릭 → Create → Light → Dome Light
   - Property: intensity=3000, color=(0.95, 0.90, 0.80)

2. Stage → 우클릭 → Create → Light → Distant Light
   - Property: intensity=1500, angle=(-45, 0, 0) (위에서 비춤)
```

### 4.4 테이블 배치

**방법 A: Nucleus 에셋 사용 (추천)**

```
   - Translation: (0.0, 0.55, 0.0)
```

**방법 B: 프리미티브 직접 생성 (현재 코드와 동일)**

```
   - Physics → Rigid Body: Kinematic
   - Collision: Enable
   - Material: Wood texture
```

### 4.7 물체 물리 속성 설정

각 물체에 대해 Property 패널에서:

```
1. Physics → Rigid Body → Add
   - Kinematic: OFF (움직이는 물체)
   - Mass: (위 표 참조)

2. Physics → Collision → Add
   - Collision Approximation: Convex Hull (단순한 물체)
     또는 Triangle Mesh (복잡한 형태)

3. Physics → Material → Add
   - Static Friction: 0.7
   - Dynamic Friction: 0.5
   - Restitution: 0.1
```

| 카메라 | 위치 | 방향 | 해상도 | FPS |
|--------|------|------|--------|-----|
| **Robot Head** | 로봇 pelvis 기준 (0, 0.12, 0.68) | 30° 하향 | 1280×720 | 60 |
| **Overhead** | (0, 0.55, 2.0) | 직하 (90°) | 1280×720 | 30 |

> **주의**: 카메라는 코드에서 자동 생성됩니다 (`--enable_cameras` 플래그).
> GUI에서 수동 배치 불필요. 비전 학습이 아닌 기본 텔레오퍼레이션에서는 사용하지 않음.

### 10.8 XR Anchor (VR 기준점)

| 속성 | 값 | 설명 |
|------|-----|------|
| **위치** | `(0.0, 0.0, 0.0)` | 로봇 발 아래 = 월드 원점 |
| **회전** | `(1.0, 0.0, 0.0, 0.0)` | 기본 방향 |

VR 사용자의 원점이 이 위치에 매핑됩니다.
