## 1. 마이그레이션 개요

### 1.1 현재 시스템 (Quest 3S)

```
Quest 3S ──(CloudXR.js/WebXR)──▶ CloudXR Runtime 6.0.1 (Docker)
    │                                      │
    │  OpenXR IPC (/openxr/run)            │
    │                                      ▼
    └──────────────────────────────▶ Isaac Lab (Docker)
                                     ├── OpenXRDevice (isaaclab.devices.openxr)
```

**데이터 흐름**: Quest 3S → CloudXR.js WebXR → CloudXR Runtime → OpenXR IPC → Isaac Lab OpenXRDevice

### 1.2 목표 시스템 (PICO + UDCAP)

```
PICO 4 Ultra ──(WiFi/TCP)──▶ XRoboToolkit PC Service (호스트 네이티브)
    │                              │ C++ SDK 콜백 → JSON
    │                              ▼
    │                         Python 브릿지 (호스트)
    │                              │
    │  CloudXR.js (VR 렌더링)      │  XRT 데이터 (Head, Body, Hand, Controller, MT)
    │                              │
    │                              │  + UDCAP 핑거 데이터 (VMC/OSC from 미니PC)
    │                              ▼
    └──(CloudXR 동일)──▶     통합 브릿지 (호스트)
                                   │ TCP :8888
                                   ▼
                              Isaac Lab (Docker)
                              ├── PICOFullBodyTeleopDevice (신규)
                              ├── G1UpperBodyRetargeter (신규)
                              ├── InspireHandRetargeter (신규)
                              └── 38D Action (14 EEF + 24 hand)
```

### 1.3 마이그레이션 범위

| 영역 | 변경 수준 | 설명 |
|------|---------|------|
| CloudXR VR 렌더링 (Path A) | **변경 없음** | CloudXR.js는 디바이스 무관, PICO 4U 프로파일 이미 존재 |
| VR 데이터 수신 (Path B) | **전면 교체** | OpenXR IPC → XRoboToolkit TCP JSON |

PICO 컨트롤러 버튼은 XRoboToolkit JSON으로 전달됨:

```json
{
  "controllers": {
    "left": {
      "grip": 0.0,           // float 0.0~1.0
      "trigger": 0.0,        // float 0.0~1.0
      "primaryButton": false, // X 버튼
      "secondaryButton": false, // Y 버튼
      "menuButton": false     // Menu 버튼
    },
    "right": {
      "grip": 0.0,
      "trigger": 0.0,
      "primaryButton": false, // A 버튼
      "secondaryButton": false, // B 버튼
      "menuButton": false
    }
  }
}
```

**매핑 변경**:

| 기능 | Quest 3S (OpenXR) | PICO 4 Ultra (XRoboToolkit) |
|------|-------------------|----------------------------|
| 개입 시작 | 양손 grip 동시 | `left.grip > 0.8 AND right.grip > 0.8` |
| 자율 복귀 | 양손 trigger 동시 | `left.trigger > 0.8 AND right.trigger > 0.8` |
| 에피소드 리셋 | 특수 제스처 | `left.menuButton AND right.menuButton` |
| 그리퍼 닫기 | 핀치 제스처 | `trigger > 0.5` (좌/우 독립) |

#### 2.2.2 InterventionManager 수정

```python
# corrective/phase2/intervention_manager.py 수정

class PICOInterventionInterface:
    """PICO 4 Ultra 기반 교정 개입 인터페이스.

    Quest의 OpenXR 제스처 대신 XRoboToolkit JSON의 컨트롤러 버튼 사용.
    """

    def __init__(self, teleop_device: "PICOFullBodyTeleopDevice"):
        self.device = teleop_device
        self.grip_threshold = 0.8
        self.trigger_threshold = 0.8

    def check_intervention_trigger(self) -> bool:
        """개입 시작: 양손 그립 동시 누름."""
        data = self.device.get_raw_controller_data()
        if data is None:
            return False
        left = data.get("controllers", {}).get("left", {})
        right = data.get("controllers", {}).get("right", {})
        return (left.get("grip", 0) > self.grip_threshold and
                right.get("grip", 0) > self.grip_threshold)

    def check_resume_trigger(self) -> bool:
        """자율 복귀: 양손 트리거 동시 누름."""
        data = self.device.get_raw_controller_data()
        if data is None:
            return False
        left = data.get("controllers", {}).get("left", {})
        right = data.get("controllers", {}).get("right", {})
        return (left.get("trigger", 0) > self.trigger_threshold and
                right.get("trigger", 0) > self.trigger_threshold)

    def advance(self):
        """VR 텔레오퍼레이션 액션 반환 (38D)."""
        return self.device.advance()
```

## 4. 핵심 구현: PICOFullBodyTeleopDevice

### 4.1 디바이스 클래스 설계

```python
# teleop/pico_fullbody_device.py
"""PICO 4 Ultra + Motion Tracker + UDCAP 통합 텔레오퍼레이션 디바이스

데이터 소스:
- XRoboToolkit: Head 6DoF, Body 24pt, Hands 26j×2, Controllers, MT×3
- UDCAP: Finger joint angles (VMC/OSC via Windows 미니PC)
- 통합 브릿지: TCP port 8888 (호스트에서 실행)

출력: 38D action tensor (14 EEF + 24 hand joints)
  - EEF: 7D × 2 = 14D (pos3 + quat4, 양팔)
  - Hand: 12D × 2 = 24D (Inspire 5지 핸드 관절)
"""

import socket
import json
import threading
import torch
import numpy as np
from typing import Optional, Dict, Tuple


class PICOFullBodyTeleopDevice:
    """PICO 4 Ultra Full-Body 텔레오퍼레이션 디바이스.

    Isaac Lab의 텔레오퍼레이션 디바이스 인터페이스를 구현.
    기존 OpenXRDevice를 대체.
    """

    def __init__(
        self,
        bridge_host: str = "localhost",
        bridge_port: int = 8888,
        action_dim: int = 38,
        use_udcap_fingers: bool = True,
    ):
        """
        Args:
            bridge_host: 통합 브릿지 호스트 (Docker network_mode:host → localhost)
            bridge_port: 통합 브릿지 TCP 포트
            action_dim: 출력 액션 차원 (14 EEF + 24 hand = 38)
            use_udcap_fingers: UDCAP 핑거 데이터 사용 여부
        """
        self.bridge_host = bridge_host
        self.bridge_port = bridge_port
        self.action_dim = action_dim
        self.use_udcap_fingers = use_udcap_fingers

        self._latest_data: Optional[dict] = None
        self._raw_controller_data: Optional[dict] = None
        self._lock = threading.Lock()
        self._connected = False

        # 리타게터
        self._retargeter = G1PICORetargeter()

        # 이전 포즈 (델타 계산용)
        self._prev_left_pose = None
        self._prev_right_pose = None

    def start(self):
        """브릿지 연결 및 데이터 수신 시작."""
        self._recv_thread = threading.Thread(target=self._recv_loop, daemon=True)
        self._recv_thread.start()

    def _recv_loop(self):
        """TCP 수신 루프."""
        while True:
            try:
                sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
                sock.connect((self.bridge_host, self.bridge_port))
                self._connected = True
                print(f"[PICODevice] Connected to bridge at {self.bridge_host}:{self.bridge_port}")
                buffer = ""

                while True:
                    chunk = sock.recv(65536).decode('utf-8')
                    if not chunk:
                        break
                    buffer += chunk
                    while '\n' in buffer:
                        line, buffer = buffer.split('\n', 1)
                        if line.strip():
                            try:
                                data = json.loads(line)
                                with self._lock:
                                    self._latest_data = data
                                    self._raw_controller_data = data.get("xrt", {})
                            except json.JSONDecodeError:
                                pass
            except (ConnectionRefusedError, ConnectionResetError, OSError) as e:
                self._connected = False
                print(f"[PICODevice] Connection lost: {e}, reconnecting...")
                import time
                time.sleep(1)

    def advance(self) -> torch.Tensor:
        """텔레오퍼레이션 액션 반환 (38D tensor).

        Returns:
            action: (38,) tensor
                [0:7]   = right EEF delta pose (pos3 + rot_euler3 + gripper1)
                [7:14]  = left EEF delta pose (pos3 + rot_euler3 + gripper1)
                [14:26] = right hand joints (12 Inspire joints)
                [26:38] = left hand joints (12 Inspire joints)
        """
        with self._lock:
            data = self._latest_data

        if data is None:
            return torch.zeros(self.action_dim)

        return self._retargeter.retarget(data, self.use_udcap_fingers)

    def get_raw_controller_data(self) -> Optional[dict]:
        """XRoboToolkit 컨트롤러 원시 데이터 (개입 트리거용)."""
        with self._lock:
            return self._raw_controller_data

    def reset(self):
        """디바이스 상태 리셋."""
        self._prev_left_pose = None
        self._prev_right_pose = None
        self._retargeter.reset()

    @property
    def is_connected(self) -> bool:
        return self._connected
```

### 4.2 G1 리타게터 설계

```python
# teleop/g1_retargeter.py
"""XRoboToolkit + UDCAP 데이터 → G1 38D 액션 변환

좌표계 변환:
- XRoboToolkit: 오른손 좌표계 (X right, Y up, Z in)
- Isaac Lab/USD: 오른손 좌표계 (X right, Y up, Z out)
→ Z축 반전 필요 (position.z *= -1, quaternion 조정)
"""

import torch
import numpy as np
from typing import Dict, Optional, Tuple


class G1PICORetargeter:
    """XRT+UDCAP → G1 38D 액션 리타게터.

    기존 Isaac Lab의 UnitreeG1RetargeterCfg가 OpenXR 52관절을 사용하는 것과 달리,
    이 리타게터는 XRoboToolkit JSON + UDCAP VMC를 입력으로 받음.
    """

    # XRT Hand Joint 인덱스 (26관절, XR_HAND_JOINT_EXT 기준)
    # 0=Palm, 1=Wrist, 2-5=Thumb, 6-10=Index, 11-15=Middle, 16-20=Ring, 21-25=Little
    XRT_THUMB_INDICES = [2, 3, 4, 5]
    XRT_INDEX_INDICES = [6, 7, 8, 9, 10]
    XRT_MIDDLE_INDICES = [11, 12, 13, 14, 15]
    XRT_RING_INDICES = [16, 17, 18, 19, 20]
    XRT_LITTLE_INDICES = [21, 22, 23, 24, 25]

    # Inspire 5지 핸드 관절 매핑 (12 관절/손)
    # [thumb_bend, thumb_rotation, index_bend, index_spread,
    #  middle_bend, middle_spread, ring_bend, ring_spread,
    #  little_bend, little_spread, thumb_opposition, wrist_rotation]
    INSPIRE_JOINT_DIM = 12

    def __init__(self, position_scale: float = 1.0, rotation_scale: float = 1.0):
        self.position_scale = position_scale
        self.rotation_scale = rotation_scale

        # 이전 프레임 데이터 (델타 계산용)
        self._prev_right_controller_pose = None
        self._prev_left_controller_pose = None

    def retarget(self, merged_data: dict, use_udcap: bool = True) -> torch.Tensor:
        """통합 데이터 → 38D 액션 텐서.

        Args:
            merged_data: 통합 브릿지에서 수신한 JSON
                {
                    "xrt": { head, controllers, hands, body, trackers },
                    "udcap_fingers": { left: {...}, right: {...} }
                }
            use_udcap: UDCAP 핑거 데이터 사용 여부

        Returns:
            (38,) tensor: [right_eef(7), left_eef(7), right_hand(12), left_hand(12)]
        """
        action = torch.zeros(38)

        xrt = merged_data.get("xrt", {})
        udcap = merged_data.get("udcap_fingers", {})

        # 1. EEF 델타 포즈 (컨트롤러 위치 기반)
        controllers = xrt.get("controllers", {})
        right_eef = self._compute_eef_delta(
            controllers.get("right", {}), is_right=True
        )
        left_eef = self._compute_eef_delta(
            controllers.get("left", {}), is_right=False
        )

        action[0:3] = right_eef[:3]    # right pos delta
        action[3:6] = right_eef[3:6]   # right rot delta
        action[6] = self._compute_gripper_cmd(controllers.get("right", {}))

        action[7:10] = left_eef[:3]    # left pos delta
        action[10:13] = left_eef[3:6]  # left rot delta
        action[13] = self._compute_gripper_cmd(controllers.get("left", {}))

        # 2. 핸드 관절 (UDCAP 우선, 없으면 XRT hand tracking)
        if use_udcap and udcap.get("right"):
            action[14:26] = self._udcap_to_inspire(udcap["right"], is_right=True)
        elif xrt.get("hands", {}).get("right"):
            action[14:26] = self._xrt_hand_to_inspire(
                xrt["hands"]["right"], is_right=True
            )

        if use_udcap and udcap.get("left"):
            action[26:38] = self._udcap_to_inspire(udcap["left"], is_right=False)
        elif xrt.get("hands", {}).get("left"):
            action[26:38] = self._xrt_hand_to_inspire(
                xrt["hands"]["left"], is_right=False
            )

        return action

    def _compute_eef_delta(self, controller: dict, is_right: bool) -> torch.Tensor:
        """컨트롤러 포즈 → EEF 델타 (6D: pos3 + rot3).

        XRT 컨트롤러 pose: "x,y,z,qx,qy,qz,qw" 콤마 구분 문자열
        """
        delta = torch.zeros(6)
        pose_str = controller.get("pose", "")
        if not pose_str:
            return delta

        values = [float(v) for v in pose_str.split(",")]
        if len(values) < 7:
            return delta

        # XRT 좌표계 → Isaac Lab 좌표계 (Z축 반전)
        pos = torch.tensor([values[0], values[1], -values[2]])
        quat = torch.tensor([values[3], values[4], -values[5], values[6]])  # qz 반전

        prev = self._prev_right_controller_pose if is_right else self._prev_left_controller_pose

        if prev is not None:
            delta[:3] = (pos - prev[:3]) * self.position_scale
            # 간단한 오일러 델타 (쿼터니언 차이 → 오일러)
            delta[3:6] = self._quat_delta_to_euler(prev[3:], quat) * self.rotation_scale

        if is_right:
            self._prev_right_controller_pose = torch.cat([pos, quat])
        else:
            self._prev_left_controller_pose = torch.cat([pos, quat])

        return delta

    def _compute_gripper_cmd(self, controller: dict) -> float:
        """컨트롤러 트리거 → 그리퍼 명령 (0=열림, 1=닫힘)."""
        trigger = controller.get("trigger", 0.0)
        return float(trigger)  # 0.0~1.0 → 그리퍼 닫기 비율

    def _udcap_to_inspire(self, udcap_joints: dict, is_right: bool) -> torch.Tensor:
        """UDCAP VMC 관절 데이터 → Inspire 12D 관절.

        UDCAP은 VMC/OSC로 각 손가락의 bone rotation을 전송.
        이를 Inspire 5지 핸드의 12 관절 각도로 매핑.
        """
        inspire = torch.zeros(self.INSPIRE_JOINT_DIM)

        # UDCAP bone name → rotation (qx,qy,qz,qw) 매핑
        # 각 손가락의 굽힘(bend)과 벌림(spread) 추출
        for bone_name, (qx, qy, qz, qw) in udcap_joints.items():
            bend_angle = self._quat_to_bend_angle(qx, qy, qz, qw)

            if "Thumb" in bone_name:
                if "Proximal" in bone_name:
                    inspire[0] = bend_angle          # thumb_bend
                elif "Metacarpal" in bone_name:
                    inspire[1] = self._quat_to_rotation_angle(qx, qy, qz, qw)  # thumb_rotation
                    inspire[10] = bend_angle         # thumb_opposition
            elif "Index" in bone_name:
                if "Proximal" in bone_name:
                    inspire[2] = bend_angle          # index_bend
                    inspire[3] = self._quat_to_spread_angle(qx, qy, qz, qw)  # index_spread
            elif "Middle" in bone_name:
                if "Proximal" in bone_name:
                    inspire[4] = bend_angle          # middle_bend
                    inspire[5] = self._quat_to_spread_angle(qx, qy, qz, qw)  # middle_spread
            elif "Ring" in bone_name:
                if "Proximal" in bone_name:
                    inspire[6] = bend_angle          # ring_bend
                    inspire[7] = self._quat_to_spread_angle(qx, qy, qz, qw)  # ring_spread
            elif "Little" in bone_name:
                if "Proximal" in bone_name:
                    inspire[8] = bend_angle          # little_bend
                    inspire[9] = self._quat_to_spread_angle(qx, qy, qz, qw)  # little_spread

        return inspire

    def _xrt_hand_to_inspire(self, hand_data: dict, is_right: bool) -> torch.Tensor:
        """XRoboToolkit hand tracking 26관절 → Inspire 12D (UDCAP 미사용 시 폴백).

        XRT 핸드 트래킹은 PICO의 내장 카메라 기반 핸드 트래킹 사용.
        UDCAP보다 정밀도 낮지만 글러브 없이 사용 가능.
        """
        inspire = torch.zeros(self.INSPIRE_JOINT_DIM)

        joints = hand_data.get("joints", [])
        if len(joints) < 26:
            return inspire

        # 26관절에서 각 손가락 proximal 관절의 굽힘 추출
        for i, finger_indices in enumerate([
            self.XRT_THUMB_INDICES,
            self.XRT_INDEX_INDICES,
            self.XRT_MIDDLE_INDICES,
            self.XRT_RING_INDICES,
            self.XRT_LITTLE_INDICES,
        ]):
            if len(finger_indices) > 1:
                proximal = joints[finger_indices[1]]  # proximal 관절
                pose_str = proximal.get("pose", {})
                if isinstance(pose_str, dict):
                    rot = pose_str.get("rotation", {})
                    qx = rot.get("x", 0)
                    qy = rot.get("y", 0)
                    qz = rot.get("z", 0)
                    qw = rot.get("w", 1)
                    bend = self._quat_to_bend_angle(qx, qy, qz, qw)
                    inspire[i * 2] = bend  # bend
                    if i > 0:  # thumb은 spread 대신 rotation
                        inspire[i * 2 + 1] = self._quat_to_spread_angle(qx, qy, qz, qw)

        return inspire

    def _quat_to_bend_angle(self, qx, qy, qz, qw) -> float:
        """쿼터니언 → 굽힘 각도 (0~1 정규화)."""
        # 간단한 X축 회전 추출 (굽힘 = X축 회전)
        import math
        angle = 2.0 * math.acos(min(abs(qw), 1.0))
        return min(angle / math.pi, 1.0)  # 0~1 정규화

    def _quat_to_spread_angle(self, qx, qy, qz, qw) -> float:
        """쿼터니언 → 벌림 각도 (-1~1 정규화)."""
        import math
        spread = math.atan2(2.0 * (qw * qz + qx * qy), 1.0 - 2.0 * (qy**2 + qz**2))
        return max(-1.0, min(1.0, spread / (math.pi / 4)))

    def _quat_to_rotation_angle(self, qx, qy, qz, qw) -> float:
        """쿼터니언 → 회전 각도 (엄지용)."""
        import math
        rotation = math.atan2(2.0 * (qw * qy + qx * qz), 1.0 - 2.0 * (qy**2 + qz**2))
        return max(-1.0, min(1.0, rotation / (math.pi / 2)))

    def _quat_delta_to_euler(self, q_prev: torch.Tensor, q_curr: torch.Tensor) -> torch.Tensor:
        """쿼터니언 델타 → 오일러 각도 델타 (3D)."""
        # q_delta = q_curr * q_prev_inv
        q_prev_inv = torch.tensor([q_prev[0], q_prev[1], q_prev[2], -q_prev[3]])
        # 간단한 근사: 작은 각도에서 (qx, qy, qz) ≈ 회전 벡터/2
        dq = q_curr - q_prev  # 근사
        return dq[:3] * 2.0

    def reset(self):
        """리타게터 상태 리셋."""
        self._prev_right_controller_pose = None
        self._prev_left_controller_pose = None
```

### 7.2 서비스 시작 순서

```
1. CloudXR Runtime Docker 시작 (기존)
   └── VR 렌더링 스트리밍 준비

2. XRoboToolkit PC Service 시작 (호스트)
   └── PICO 헤드셋 연결 대기

3. C++ → Python 브릿지 시작 (호스트)
   └── XRT SDK 콜백 → TCP :7777

4. Windows 미니PC 시작 (별도 PC)
   └── UDCAP Software → VMC → UDP :39539

5. 통합 브릿지 시작 (호스트)
   └── XRT(:7777) + VMC(:39539) → 통합 TCP :8888

6. PICO 헤드셋에서:
```

## 부록 B: UDCAP VMC 본(bone) 이름 매핑

VMC 프로토콜의 `/VMC/Ext/Bone/Pos` 주소로 전달되는 bone 이름:

```
왼손:
  LeftThumbMetacarpal, LeftThumbProximal, LeftThumbDistal
  LeftIndexProximal, LeftIndexIntermediate, LeftIndexDistal
  LeftMiddleProximal, LeftMiddleIntermediate, LeftMiddleDistal
  LeftRingProximal, LeftRingIntermediate, LeftRingDistal
  LeftLittleProximal, LeftLittleIntermediate, LeftLittleDistal

오른손:
  RightThumbMetacarpal, RightThumbProximal, RightThumbDistal
  RightIndexProximal, RightIndexIntermediate, RightIndexDistal
  ... (동일 패턴)
```

각 본: position (3D) + quaternion (4D) = 7 floats

Inspire 5지 핸드 12관절 매핑:
- Thumb: Metacarpal(opposition+rotation) + Proximal(bend) = 3 DOF
- Index~Little: Proximal(bend+spread) = 2 DOF × 4 = 8 DOF
- Wrist: rotation = 1 DOF
- **총 12 DOF/손**
