# 교정 티칭 AI 시스템 (Corrective Teaching AI) 연구 조사

> 작성일: 2026-02-20
> 목적: 로봇이 불확실한 상황에서 사람에게 도움을 요청하고, 사람의 교정(시연/피드백)을 반영하여 학습하는 시스템의 연구 현황, 구현 가능성, 미래 방향 조사

---

## 1. 개요

### 1.1 교정 티칭 AI란?

교정 티칭 AI(Corrective Teaching AI)는 다음 세 가지 핵심 능력을 갖춘 로봇 학습 시스템이다:

1. **불확실성 인식**: AI가 자신의 행동이 틀릴 수 있음을 감지
2. **도움 요청**: 불확실할 때 사람에게 적극적으로 도움을 요청
3. **교정 학습**: 사람의 시범(시연), 언어 피드백, 물리적 교정을 반영하여 정책을 개선

이 분야는 **Interactive Imitation Learning (IIL)**, **Human-in-the-Loop (HITL) Learning**, **Learning from Interventions**, **Active Robot Learning** 등 다양한 이름으로 연구되고 있다.

### 1.2 연구의 필요성

전통적 모방학습(Behavioral Cloning)의 한계:
- **분포 이동 (Distribution Shift)**: 정책이 학습 데이터와 다른 상태에 도달하면 성능 급락
- **단방향 학습**: 초기 시연 데이터에만 의존, 실행 중 교정 불가
- **미지 물체/상황**: 새로운 물체나 상황에 대한 적응력 부족
- **에러 누적**: 장기 태스크에서 작은 오류가 누적되어 실패

교정 티칭 AI는 이 한계들을 **사람의 실시간 개입과 교정**으로 해결한다.

## 2. 핵심 연구 분류 및 주요 논문

### 2.1 기반 알고리즘: DAgger 계열

#### DAgger (Dataset Aggregation) - Ross et al. (2011)
- 최초의 인터랙티브 모방학습 알고리즘
- 정책 실행 → 전문가 라벨링 → 데이터 집합에 추가 → 재학습
- **한계**: 모든 상태에서 전문가 라벨 필요 → 사람 부담 과중

#### HG-DAgger (Human-Gated DAgger) - Kelly et al. (2019)
- **사람이 개입 시점을 결정** (Human-gated)
- 로봇 자율 실행 중 사람이 "위험하다" 판단 시 직접 제어 인계
- 개입 데이터와 자율 데이터를 구분하여 학습
- **현재 가장 널리 사용되는 기본 프레임워크**

#### EnsembleDAgger - Menda et al. (2019)
- 다수의 정책 네트워크 앙상블 → 행동 분산(variance)으로 불확실성 추정
- 분산이 임계값 이상이면 자동으로 전문가에게 제어 이양
- **한계**: 다중 모달 행동(여러 올바른 동작)을 불확실성으로 오인

#### ThriftyDAgger - Hoque, Balakrishna et al. (CoRL 2022)
- **2차원 개입 기준**: 상태 **새로움** (앙상블 행동 분산) + **위험** (학습된 비평 네트워크)
- **예산 인식**: 주어진 개입 예산에 맞게 임계값 자동 조정
- 사용자 연구 (N=10, 3대 로봇 동시): 인간 성능 58% 향상, 로봇 성능 80% 향상
- [논문](https://proceedings.mlr.press/v164/hoque22a/hoque22a.pdf) | [프로젝트](https://sites.google.com/view/thrifty-dagger/home)

#### Diff-DAgger - Lee et al. (ICRA 2025)
- **확산 정책(Diffusion Policy)의 학습 손실을 불확실성 측정으로 사용**
- EnsembleDAgger의 다중 모달 오인 문제 해결
- 태스크 실패 예측 정확도 81.5%, 기존 대비 39% 향상
- 확산 손실 낮음 → 자율 진행, 높음 → 전문가 개입 요청
- [논문](https://arxiv.org/abs/2410.14868) | [프로젝트](https://diffdagger.github.io/)

#### Fleet-DAgger - Hoque et al. (CoRL 2023)
- **다수 로봇 동시 감독**: 1명의 인간이 N대의 로봇 감독
- 어떤 로봇에 먼저 개입할지 우선순위 결정 알고리즘
- 플릿 규모 확장 가능한 교정 시스템
- [논문](https://proceedings.mlr.press/v205/hoque23a.html)

#### CHG-DAgger (Cooperative Human-Gated DAgger) - OpenReview 2025
- 사람과 로봇이 **동시에 제어 공유** (Shared Control)
- 완전 인계 대신 부드러운 블렌딩 (α × 사람 + (1-α) × 로봇)
- 더 자연스러운 교정 경험, 컨텍스트 스위치 비용 감소
- [논문](https://openreview.net/forum?id=nWiHRy3ZXy)

### 2.2 교정 특화 학습 방법

#### IWR (Intervention Weighted Regression) - Spencer et al. (Stanford)
- 개입 데이터와 자율 데이터를 분리 관리
- **개입 샘플에 더 높은 가중치** (병목 상태에 집중)
- 많은 후속 연구의 기반 방법
- [프로젝트](https://sites.google.com/stanford.edu/iwr)

#### RLIF (RL from Interactive Feedback) - Luo et al. (ICLR 2024)
- **개입 신호 자체를 RL의 보상 신호로 활용**
- 전문가가 최적이 아니어도 학습 가능 → 비전문가 교정 허용
- 이론적 프레임워크: RL과 DAgger의 통합 분석
- **핵심 발견**: 교정으로부터의 RL이 단순 모방보다 우수
- [논문](https://arxiv.org/abs/2311.12996) | [프로젝트](https://rlif-page.github.io/)

#### Sirius: Robot Learning on the Job - (RSS 2023, UT Austin)
- **자기 개선 로봇 학습 시스템**
- 실행 중 실패 감지 → 사람 개입 → 교정 데이터 수집 → 온라인 재학습
- 누적적 자기 개선 사이클
- [프로젝트](https://ut-austin-rpl.github.io/sirius/)

#### TRANSIC: Sim-to-Real via Online Correction - Jiang et al. (CoRL 2024, Stanford)
- 시뮬레이션 학습 정책에 **실제 환경 교정으로 잔차(Residual) 정책 학습**
- 기본 정책(sim)은 동결, 교정 정책(real)만 학습
- 5개 sim-to-real 태스크에서 평균 77% 성공 (IWR 기준선 18% 대비)
- 카테고리 수준 물체 일반화 달성
- [프로젝트](https://transic-robot.github.io/) | [논문](https://arxiv.org/abs/2405.10315)

#### CR-DAgger (Compliant Residual DAgger) - NeurIPS 2025
- **컴플라이언스 제어 인터페이스**: 사람이 로봇에 힘을 가해 교정 (제어 인계 없이)
- 잔차(delta-action) 정책 학습
- 접촉이 많은 태스크에서 64% 성능 향상 (책 넘기기, 벨트 조립, 케이블 정리, 기어 삽입)
- **핵심 혁신**: 교정이 부드러운 섭동이지, 완전 인계가 아님
- [논문](https://arxiv.org/abs/2506.16685) | [프로젝트](https://compliant-residual-dagger.github.io/)

#### RaC (Recovery and Correction) - September 2025
- 인간 개입 궤적을 **"복구(Recovery)"**와 **"교정(Correction)"**으로 분류
- 복구: 좋은 상태로 되돌리기 / 교정: 서브태스크 수정
- 기존 SOTA 대비 **10배 적은 데이터 수집 시간**으로 우수한 성능
- 테스트 시 스케일링: 복구 횟수에 비례하여 성능 선형 증가
- [논문](https://arxiv.org/abs/2509.07953) | [프로젝트](https://rac-scaling-robot.github.io/)

#### Genie Centurion (GCENT) - Wang et al. (May 2025)
- **되감기-정제(Rewind-and-Refine)** 패러다임
- 실행 실패 시 이전 상태로 되돌리고, 사람이 교정 시연 제공
- Task Sentinel 모듈: 자율적으로 성공 예측 → 개입 트리거
- **1인이 다수 로봇 감독** 체계
- SOTA 대비 40% 높은 성공률; <50% 데이터로 동등한 성능
- [논문](https://arxiv.org/abs/2505.18793) | [프로젝트](https://genie-centurion.github.io/)

### 2.3 교정 데이터 증강

#### IntervenGen (I-Gen) - Hoque, Mandlekar et al. (IROS 2024, Berkeley/NVIDIA)
- **10개의 인간 개입으로부터 대규모 교정 데이터 자동 생성**
- 정책 견고성 최대 39배 향상
- MimicGen과 달리: 개입 데이터(전체 시연X) 생성, 폐쇄 루프 실행 포함
- [논문](https://arxiv.org/abs/2405.01472) | [프로젝트](https://sites.google.com/view/intervengen2024)

#### MimicGen - Mandlekar et al. (NVIDIA, 2023)
- 소수 시연을 분절+재조합하여 100K+ 궤적 생성
- RoboCasa와 연동하여 확장 가능한 로봇 학습
- [프로젝트](https://mimicgen.github.io/)

#### PPL (Predictive Preference Learning) - Cai et al. (NeurIPS 2025)
- 경량 궤적 예측기로 미래 실패 예측 (CPU에서 >1,000 fps)
- 전문가 인계를 예측 상태에 대한 **대조적 선호 라벨**로 변환
- 샘플 효율 2배 향상, 전문가 인계 비용 감소
- [프로젝트](https://metadriverse.github.io/ppl/) | [논문](https://arxiv.org/abs/2510.01545)

### 2.4 불확실성 인식 & 도움 요청 정책

#### KnowNo: Robots That Ask For Help - Ren, Dixit et al. (CoRL 2023)
- **Conformal Prediction으로 LLM 출력의 불확실성 정량화**
- 다지선다 형식: 예측 집합이 2개 이상 옵션 → 사람에게 질문
- 형식적 보장: conformal coverage → 태스크 완료 보장
- LLM을 파인튜닝 없이 그대로 사용 가능
- [논문](https://arxiv.org/abs/2307.01928) | [프로젝트](https://robot-help.github.io/)

#### Introspective Planning (IntroPlan) - Liang et al. (NeurIPS 2024, Princeton)
- LLM이 **자신의 불확실성을 명시적으로 추론**한 후 계획
- 내성적 추론 예시(knowledge base) 검색으로 판단
- Conformal prediction과 결합: 더 적은 질문으로 더 높은 신뢰
- 표준 LLM 플래너 대비 성공률과 안전성 유의미한 향상
- [논문](https://proceedings.neurips.cc/paper_files/paper/2024/file/8451a20c5a7e0ee5671dda28f7daf7f3-Paper-Conference.pdf)

#### ICREATe - (2023, Neural Computing and Applications)
- **인식적(Epistemic) + 우연적(Aleatoric) 불확실성** 이중 추정
- 인식적: 지식 부족 → 더 많은 데이터 필요
- 우연적: 시연 자체의 모호성 → 근본적 한계
- 로봇이 불확실할 때 능동적으로 사람에게 질의
- [논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC10338625/)

#### AIM (Adaptive Intervention Mechanism) - Cai et al. (ICML 2025)
- 프록시 Q-함수가 인간의 개입 결정 패턴을 모방
- 1-2개 전문가 궤적만으로 로봇-게이트 모드 전환 가능
- 안전-중요 상태에 질의 집중 → 고품질 시연 획득
- 전문가 인계 비용 40% 감소
- [논문](https://arxiv.org/abs/2506.09176) | [프로젝트](https://metadriverse.github.io/aim/)

### 2.5 파운데이션 모델 기반 실패 감지 & 복구

#### DoReMi - (ICLR 2024)
- LLM이 실행 제약조건 생성 → VLM이 실시간 제약 위반 감시
- 위반 감지 시 LLM이 즉시 재계획
- 로봇 팔 + 휴머노이드에서 높은 성공률, 짧은 완료 시간
- [논문](https://arxiv.org/abs/2307.00329) | [프로젝트](https://sites.google.com/view/doremi-paper)

#### Inner Monologue - Huang et al. (CoRL 2023, Google)
- LLM 기반 폐쇄 루프 계획 + 환경 피드백 연속 주입
- 성공 감지, 씬 설명을 텍스트로 LLM 프롬프트에 투입
- 동작 실패 시 업데이트된 컨텍스트로 재계획
- [프로젝트](https://innermonologue.github.io/)

#### RACER - Dai et al. (ICRA 2025, UMich)
- **VLM 감독자 + 언어 조건부 정책 액터** 아키텍처
- VLM이 실시간 상세 언어 안내 제공 (에러 교정 + 태스크 실행)
- 자동화 파이프라인: 시연에 실패 복구 궤적 + 세밀한 언어 주석 자동 증강
- RLBench에서 RVT 능가 (표준/동적 목표/제로샷 태스크)
- [논문](https://arxiv.org/abs/2409.14674) | [코드](https://github.com/sled-group/RACER)

### 2.6 언어 기반 교정

#### LILAC (Language-Informed Latent Actions with Corrections) - Cui et al. (Stanford, HRI 2023)
- 실행 중 실시간 자연어 교정 반영 ("아니, 오른쪽으로")
- 언어 입력이 저차원 제어 공간을 수정하는 공유 자율 방식
- Franka Panda 사용자 연구: 높은 완료율, 사용자 선호
- [논문](https://nlp.stanford.edu/pubs/cui2023lilac.pdf) | [코드](https://github.com/Stanford-ILIAD/lilac)

### 2.7 HITL RL (Human-in-the-Loop Reinforcement Learning)

#### HIL-SERL - (UC Berkeley, Science Robotics 2024)
- **사람 시연 + RL 파인튜닝** 통합 프레임워크
- 초기 시연으로 정책 부트스트랩 → RL로 자기 개선
- 사람 개입을 보상 신호로 활용 (RLIF 방식)
- 20분 사람 시연 + 수시간 자율 학습 → 복잡한 조작 태스크
- [프로젝트](https://hil-serl.github.io/)

#### HACTS (Human-As-Copilot Teleoperation System) - 2025
- 양방향 텔레오퍼레이션: 조작자가 로봇 상태를 느낌
- 공유 자율 모드: 사람 감독 하 로봇 자율 실행
- 40% 적은 데이터로 효과적 정책 학습
- [논문](https://arxiv.org/abs/2503.24070)

#### RoboCopilot - (2025)
- Isaac Sim 기반 HITL 인터랙티브 모방학습 시스템
- Continual DAgger + Batched DAgger 레짐 구현
- 시뮬 88-97% 성공, 하드웨어 78% 성공
- [논문](https://arxiv.org/abs/2503.07771)

### 3.1 즉시 구현 가능 (Tier 1: 기존 도구/프레임워크)

| 능력 | 프레임워크 | 성숙도 |
|------|-----------|--------|
| VR 텔레오퍼레이션 시연 수집 | Isaac Lab + OpenXR + CloudXR | **프로덕션** |
| 시연 수집 + 재생 | Isaac Lab Mimic + Robomimic | **프로덕션** |
| 소수 시연에서 데이터 증강 | MimicGen + Isaac Lab Mimic | **프로덕션** |

### 3.2 중간 노력으로 구현 가능 (Tier 2)

| 능력 | 프레임워크 | 노력 |
|------|-----------|------|
| HG-DAgger 인터랙티브 루프 | Isaac Lab + VR 텔레오퍼레이션 | **중간** |
| IWR 데이터 가중치 학습 | 커스텀 학습 파이프라인 | **낮음** |
| 앙상블 불확실성 (EnsembleDAgger) | 다중 정책 헤드 | **중간** |
| VLM 기반 실패 감지 | GPT-4V / Gemini API + 카메라 | **중간** |
| LLM 불확실성 (KnowNo) | Conformal Prediction + LLM API | **중간** |
| TRANSIC 잔차 정책 | Sim 정책 + 교정 정책 합성 | **높음** |

### 3.3 연구 수준 구현 (Tier 3)

| 능력 | 프레임워크 | 노력 |
|------|-----------|------|
| Diff-DAgger + 확산 정책 | 커스텀 확산 정책 + 손실 모니터링 | **높음** |
| CR-DAgger 컴플라이언스 | 힘-토크 센서 + 임피던스 제어 | **높음** |
| Genie Centurion 파이프라인 | 다중 로봇 감독 + 되감기 메커니즘 | **매우 높음** |

### 3.4 Isaac Lab + Robomimic 통합 교정 파이프라인

Isaac Lab은 교정 티칭 파이프라인을 위한 네이티브 지원을 제공한다:

```
[교정 티칭 AI 구현 파이프라인]

Step 1: VR 텔레오퍼레이션으로 초기 시연 수집 (10-50개)
   → Isaac Lab XR Teleop + HDF5 저장

Step 2: 시연 데이터 증강
   → Isaac Lab Mimic + MimicGen → 1,000+ 궤적 생성

Step 3: 기본 정책 학습
   → Robomimic (BC-RNN) 또는 LeRobot (ACT)

Step 4: 정책 배포 + 사람 모니터링
   → 시뮬레이션에서 학습된 정책 실행
   → 카메라 + VLM으로 실패 감지
   → 불확실성 높으면 사람에게 알림

Step 5: 사람 개입 (HG-DAgger 방식)
   → VR 텔레오퍼레이션으로 교정 시연 제공

   → IWR 가중치로 개입 데이터 강조 학습
   → 또는 DAgger 데이터 집합 방식

Step 7: 반복 (수렴까지)
```

### 4.2 물체 인식 불확실성 → 도움 요청 시나리오

우리 프로젝트의 핵심 시나리오 구현 방안:

```
[시나리오: AI가 모르는 물체를 만났을 때]

1. 카메라로 테이블 위 물체 인식
   → VLM (GPT-4V/Gemini) 분석: "테이블 위에 머그, 접시, [미확인 물체] 있음"

2. 불확실성 감지
   → VLM confidence score < 임계값
   → 또는 conformal prediction으로 예측 집합 크기 > 1

3. 사람에게 질문
   → VR HMD 화면에 표시: "이 물체가 무엇인가요? 어디에 넣어야 하나요?"
   → 선택지 제시 또는 자유 응답

4. 사람의 응답 반영
   → "그건 핸드크림이야, 화장대 쪽 바구니에 넣어"
   → 언어 이해 → 목표 위치 설정

5. 사람의 교정 시연 (필요시)
   → VR 텔레오퍼레이션으로 직접 물체 이동 시연
   → 궤적 데이터 저장

6. 학습 반영
   → 새 물체 카테고리 + 목표 위치 저장
   → 시연 궤적으로 정책 파인튜닝
   → 다음에 같은 물체 → 자율 처리
```

### 4.3 동작 교정 시나리오

```
[시나리오: AI가 파지 방법을 틀렸을 때]

1. 정책이 머그를 측면에서 잡으려 시도 (학습된 동작)

2. 불확실성/위험 감지
   → 앙상블 행동 분산 높음 (어디서 잡을지 불확실)
   → 또는 학습된 비평 네트워크가 실패 예측

3. 사람에게 알림
   → "머그를 잡는 방법이 불확실합니다. 도와주세요."

4. 사람의 교정
   → 방법 A: VR 텔레오퍼레이션으로 올바른 파지 시연 (핸들 잡기)
   → 방법 B: 언어 교정 "핸들을 잡아" (LILAC 방식)
   → 방법 C: 물리적 교정 - 로봇 팔을 직접 밀어서 위치 조정 (CR-DAgger)

5. 교정 데이터 저장 + 재학습
   → IWR 가중치로 교정 시연 강조
   → 잔차 정책으로 파지 방식 수정

6. 학습 검증
   → 같은 상황에서 교정된 동작으로 자율 수행
   → 성공 시 → 교정 완료
   → 실패 시 → 추가 교정 반복
```

## 5. 미해결 과제 및 향후 연구 방향

### 5.1 교정 학습의 샘플 효율성

**현재 상태**: 대부분 시스템이 50-200+ 교정 에피소드 필요

| 연구 | 필요 교정 수 | 성능 향상 |
|------|-----------|----------|
| IntervenGen | **10개** | 39배 견고성 향상 |
| PPL | 기존 대비 50% 감소 | 2배 효율 |
| RaC | 기존 대비 **10배 감소** | SOTA |
| GCENT | <50% 데이터 | 40% 성공률 향상 |

**미해결 문제**:
- 각 교정 에피소드에서 최대 정보 추출 방법
- 교정 수집의 최적 스케줄링
- 유사 태스크 간 교정 지식 전이

### 5.2 도움 요청 시점 (불확실성 정량화)

**접근법별 성숙도**:

| 방법 | 불확실성 신호 | 장점 | 단점 |
|------|-------------|------|------|
| 앙상블 불일치 | 행동 분산 | 간단, 검증됨 | 다중모달 혼동 |
| 확산 정책 손실 (Diff-DAgger) | 학습 목표 편차 | 다중모달 처리 | 확산 아키텍처 필요 |
| Conformal Prediction (KnowNo) | 통계적 커버리지 | **형식적 보장** | 교정 데이터셋 필요 |
| 학습된 비평 (ThriftyDAgger) | 실패 확률 추정 | 예산 인식 | 별도 비평 학습 |
| 프록시 Q-함수 (AIM) | 인간 개입 패턴 모방 | 적응적, 저비용 | 초기 데이터 품질 의존 |
| VLM 판단 (DoReMi/RACER) | 제약 위반 감지 | **의미 이해** | 높은 지연, 비싼 추론 |

**근본적 미해결 문제**: 보편적 불확실성 메트릭이 없다. 인식적 불확실성(지식 부족)과 우연적 불확실성(내재적 모호성)을 구분하여 처리하는 원칙적 방법이 필요하다.

### 5.3 교정 통합 시 망각 방지 (Catastrophic Forgetting)

**핵심 긴장**: 교정 데이터로 파인튜닝하면 기존 학습된 좋은 행동을 덮어쓸 위험

**현재 해결책**:
| 방법 | 메커니즘 | 효과 |
|------|---------|------|
| IWR 가중치 | 자율/개입 데이터 분리, 재가중 | 중간 |
| 잔차 정책 (TRANSIC) | 기본 정책 동결 + 교정 delta만 학습 | **높음** |
| 리플레이 버퍼 (HIL-SERL) | 시연+온라인 데이터 균형 샘플링 | 높음 |
| RaC 표준화 | 복구/교정 데이터 구조화 학습 | 높음 |

**미해결 문제**:
- 수백 태스크에 걸친 지속적 학습(Continual Learning)
- 새 환경 적응 시 기존 태스크 지식 보존
- 증가하는 교정 데이터셋의 효율적 메모리 관리

### 5.4 실시간 교정 패러다임의 발전 방향

```
패러다임 1: 완전 인계 (HG-DAgger, RoboCopilot)
   사람이 완전 제어 → 깨끗한 데이터, 높은 비용

   ↓ 발전 방향

패러다임 2: 공유 제어 (CHG-DAgger, LILAC)
   사람+로봇 동시 제어 → 자연스러움, 노이즈 가능

   ↓ 발전 방향

패러다임 3: 컴플라이언스 섭동 (CR-DAgger)    ← 최신 트렌드
   사람이 힘으로 교정 → 최소 방해, delta 교정 데이터
```

### 5.5 다중 모달 피드백 (언어 + 시연)

**현재 능력**:
- LILAC: 실시간 언어 교정이 로봇 제어 공간 수정
- RACER: VLM이 언어 기반 복구 지시 제공
- Inner Monologue: 텍스트 피드백으로 재계획

**미래 방향**:
- 물리적 교정(텔레오퍼레이션) + 언어 설명 ("왼쪽으로 옮겨, 이 물체는 깨지기 쉬우니까") 결합
- 언어로 교정의 **의도**를 명시하여 일반화 향상
- 다턴 대화: 로봇이 명확화 질문 → 교정 시도 → 피드백 → 반복

### 5.6 Sim-to-Real 전이

**핵심 연구**: TRANSIC가 선도 (sim 정책 + real 교정 → 77% 성공)

**미해결 과제**:
- 물리 엔진 오차로 인한 제로샷 전이의 불안정성
- 교정 정책이 특정 실제 환경 아티팩트에 과적합
- 교정 시나리오 특화 도메인 랜덤화 전략 필요

## 6. 분야 전체 트렌드 (2023-2026)

### 6.1 6대 핵심 트렌드

1. **사람-게이트 → 로봇-게이트 → 적응형**: 로봇이 *언제* 도움을 요청할지 스스로 학습
2. **완전 인계 → 컴플라이언스 섭동**: 교정이 점점 부드럽고 비침습적으로 변화
3. **모방 → RL+교정**: RLIF, HIL-SERL이 교정 신호를 보상으로 활용 → 전문가 수준 이상 학습 가능
4. **단일 로봇 → 플릿 규모**: Fleet-DAgger, GCENT가 1인 다중 로봇 감독 체계 구현
5. **저수준 → 의미적 교정**: RACER, LILAC이 개념 수준 교정 가능
6. **확산 정책이 새 표준**: Diff-DAgger가 확산 모델의 자연스러운 불확실성 신호 활용

## 8. 결론

### 8.1 현재 연구 수준 요약

교정 티칭 AI는 2022년 ThriftyDAgger를 시작으로 급속히 발전하고 있다. 2024-2025년에 TRANSIC, IntervenGen, Diff-DAgger, CR-DAgger, RaC, GCENT, PPL, AIM 등 핵심 연구들이 쏟아지면서, **기본적인 교정 학습 시스템은 충분히 구현 가능한 수준**에 도달했다.

### 8.2 핵심 결론

1. **기본 HG-DAgger 교정 루프**는 Isaac Lab + VR 텔레오퍼레이션으로 **즉시 구현 가능**
2. **앙상블 불확실성 + VLM 물체 인식**으로 "도움 요청" 시스템 **중간 노력으로 구현 가능**
3. **잔차 정책 학습 (TRANSIC)**은 기존 정책 보존하면서 교정 반영에 **가장 유망한 접근**
4. **교정 데이터 증강 (IntervenGen)**으로 소수 인간 개입의 효과를 **극대화 가능**
5. **확산 정책 (Diff-DAgger)**이 불확실성 추정에 최적이지만 **구현 복잡도 높음**
6. **VLM/LLM 기반 의미적 이해 (KnowNo, RACER)**가 "물체가 뭔지 모름" 시나리오에 **직접 적용 가능**

### 8.3 추천 우선순위

```
[즉시] HG-DAgger + IWR + VR 텔레오퍼레이션 교정
   → 기본 교정 학습 사이클 검증

[단기] VLM 물체 인식 불확실성 + 앙상블 정책 불확실성
   → "도움 요청" 트리거 구현

[중기] TRANSIC 잔차 정책 + IntervenGen 데이터 증강
   → 교정 효율 극대화

[장기] Diff-DAgger + KnowNo conformal prediction + 언어 교정
   → 완전한 교정 티칭 AI 시스템
```
