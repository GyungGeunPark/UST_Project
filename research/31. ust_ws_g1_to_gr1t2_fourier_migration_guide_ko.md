## 0. 요약 (TL;DR)

### 0.1 왜 GR1T2 + Fourier 6-DoF Hand 인가
1. **2026-04 현재 "전신 + 정밀 5-손가락" 엄격 필터를 통과하면서 Isaac Lab `main` 에 box에서 Pink IK 태스크, DexPilot 리타게팅 YAML, Manus Vive 장치 매니페스트까지 전부 포함된 유일한 Ready 후보** (research/30 §2).
2. Pink IK 타겟 프레임이 `*_hand_pitch_link` (palm) — G1 의 `*_wrist_yaw_link` 대비 **7-DoF 팔 전체가 IK 에 기여**. G1 증상 "손목 워크스페이스가 비좁다"의 근본 원인 해결.
3. `WaistEnabled` 변형은 `waist_yaw/pitch/roll` 3개 관절을 `pink_controlled_joint_names` 에 추가 + `NullSpacePostureTask.controlled_joints` 에도 포함 → 허리가 상체 IK 의 null-space 리던던시로 들어감. 가로 도달 범위 ~1.8 배 확장.
4. 손가락이 11 관절/손 (6 driver + 5 mimic) 로 G1 Inspire FTP 24 관절 (10 driver + 14 mimic) 보다 투명. 공식 `dex-retargeting` DexPilot YAML 이 이미 내장.
5. 스폰 포즈 `pos=(0,0,0.93), rot=(0.7071,0,0,0.7071)` 및 90° Z-회전 전제 동일 — PicoUDCAP 좌표 변환 로직 그대로 재사용.

### 0.3 마이그레이션 기간
- **Week 1**: 자산/에셋 확인 + 신규 폴더 `ust_260421_fourier/` 부트스트랩 + 스모크 테스트.

### 0.4 치명적 리스크 3가지
1. **kitchen_sorting 씬 치수**: GR1T2 ~170 cm vs G1 ~132 cm → 테이블 높이, 도달 원뿔, 오브젝트 z-좌표 전면 재튜닝 필요 (~1일).

3. **허리 타겟 신호원**: WaistEnabled 가 허리 3-DoF 를 IK 에 노출해도 **VR 헤드셋은 허리 포즈를 직접 제공하지 않음**. 옵션 (a) HMD yaw → 허리 yaw 감쇠, (b) VD 10-세그먼트의 `hips` 트래커 쿼터니언 사용. 본 가이드는 (b) 를 1순위로 제안.

1. **로봇 교체**: `G1_INSPIRE_FTP_CFG` → `GR1T2_HIGH_PD_CFG` (Isaac Lab 내장).
2. **액션 레이아웃**: 38D → 36D. 손가락 24 → 22. `pelvis` → `base_link` 베이스. Frame target palm 기반.

## 2. GR1T2 + Fourier 6-DoF Hand 참조 (Isaac Lab 내장 자산)

본 섹션은 마이그레이션에서 그대로 인용할 Isaac Lab `main` 에셋/설정의 **Ground truth**. 모든 경로는 `C:\develop\IsaacLab\` 기준.

### 2.1 로봇 에셋: `source/isaaclab_assets/isaaclab_assets/robots/fourier.py`

**USD**: `{ISAAC_NUCLEUS_DIR}/Robots/FourierIntelligence/GR-1/GR1T2_fourier_hand_6dof/GR1T2_fourier_hand_6dof.usd`

**전신 DoF 분포**:
- 다리 6+6=12, 허리 `waist_yaw/pitch/roll` 3, 팔 7+7=14, 머리 3, 핸드 11+11=22 → **총 54 DoF** (여기에 머리 제외 51, Pink IK 관여 대상은 상체+허리 17 + 손가락 22).

**핵심 액추에이터 그룹**(`GR1T2_HIGH_PD_CFG` 기준, 픽앤플레이스용):
- `trunk`: `waist_.*` — stiffness=4400, damping=40, armature=0.01
- `right-arm` / `left-arm`: `*_shoulder_*`, `*_elbow_*`, `*_wrist_*` — stiffness=4400, damping=40
- `right-hand` / `left-hand`: `R_.*` / `L_.*` — stiffness/damping None (임피던스 제어)

**팔 관절(7 DoF/side)** — Pink IK controlled 대상:
```
left_shoulder_pitch_joint, left_shoulder_roll_joint, left_shoulder_yaw_joint,
left_elbow_pitch_joint, left_wrist_yaw_joint, left_wrist_roll_joint, left_wrist_pitch_joint
(right_ 동일 prefix)
```

**허리 관절(3 DoF)**: `waist_yaw_joint`, `waist_pitch_joint`, `waist_roll_joint`.

**손가락 관절 (11/side, 총 22)**:
```
L_index_proximal_joint,   L_index_intermediate_joint,
L_middle_proximal_joint,  L_middle_intermediate_joint,
L_ring_proximal_joint,    L_ring_intermediate_joint,
L_pinky_proximal_joint,   L_pinky_intermediate_joint,
L_thumb_proximal_yaw_joint, L_thumb_proximal_pitch_joint, L_thumb_distal_joint
(R_ 동일 prefix)
```
- **Driver 6개**: 4 finger proximals + thumb_proximal_yaw + thumb_proximal_pitch.
- **Mimic 5개**: 4 finger intermediates + thumb_distal (proximal 각도에 mechanical linkage).
- Pink IK `num_hand_joints=22` (11 × 2).

**기본 init_state**: `pos=(0, 0, 0.95)`, `rot=(0,0,0,1) identity`, 전 관절 0.0. (씬별로 스폰 pos=(0,0,0.93), rot=(0.7071,0,0,0.7071) 재정의).

### 2.5 내장 리타게터

### 5.1 `gr1t2_retargeter.py` — SteamVRSnapshot → 36D action

#### 5.1.1 공개 API

```python
import torch
import numpy as np
from dataclasses import dataclass, field
from typing import Dict, Optional, Tuple

from ust_ws.ust_260418_win.teleop.coord_transforms import (
    svr_to_isaaclab, forearm_to_wrist, quat_multiply,
)
from ust_ws.ust_260418_win.teleop.fingertip_extractor import extract_fingertips_wrist_frame
from ust_ws.ust_260418_win.teleop.udcap_finger_mapper import UDCAPFingerMapper
from .fourier_hand_mapper import FourierHandMapper
from .waist_estimator import WaistEstimator


@dataclass
class GR1T2FourierRetargeterCfg:
    position_scale: float = 1.0
    rotation_scale: float = 1.0
    gripper_threshold: float = 0.5
    forearm_wrist_offset: Tuple[float, float, float] = (0.12, 0.0, 0.0)

    # Fourier dex-retargeting YAML (DexPilot 주 경로)
    left_hand_retarget_yaml: Optional[str] = None
    right_hand_retarget_yaml: Optional[str] = None
    dex_urdf_dir: Optional[str] = None

    # 허리 3-DoF 배관
    use_waist_origin: bool = True          # base_link(=pelvis base) 프레임 변환
    enable_waist_dof: bool = True          # HMD/hips → waist_yaw/pitch/roll 추정
    waist_source: str = "hips_tracker"     # "hips_tracker" | "hmd_yaw" | "off"
    waist_gain: Tuple[float, float, float] = (1.0, 0.5, 0.3)  # yaw/pitch/roll 감쇠

    # 진단 플래그 (G1 경로와 동일 의미)
    freeze_orientation: bool = False
    subtract_waist_z: bool = False
    debug: bool = False


class GR1T2FourierSteamVRRetargeter:
    """SteamVRSnapshot → Pink IK 36D action tensor for GR1T2 + 6-DoF Fourier hand.

    Output layout (length 36):
      [0:3]   left wrist position   (base_link frame)
      [3:7]   left wrist quat wxyz
      [7:10]  right wrist position
      [10:14] right wrist quat wxyz
      [14:25] left hand (11) — L_index_prox, L_middle_prox, L_pinky_prox, L_ring_prox,
                               L_thumb_prox_yaw, L_index_int, L_middle_int, L_pinky_int,
                               L_ring_int, L_thumb_prox_pitch, L_thumb_distal
      [25:36] right hand (11) — same order with R_ prefix
    """
    ACTION_DIM = 36
    HAND_DIM_PER_SIDE = 11

    # GR1T2 base_link-frame T-pose wrist poses (measured via scripts/calibrate_gr1t2_idle_pose.py)
    # NOTE: 아래 값은 Isaac Lab 2.3 기준 GR1T2_HIGH_PD_CFG 의 기본 자세에서 측정한 근사치.
    # 실환경 배포 전 반드시 calibrate_gr1t2_idle_pose.py 로 재측정할 것.
    DEFAULT_LEFT_POS = (-0.20, 0.00, 1.05)      # base_link +X right, +Y forward, +Z up
    DEFAULT_LEFT_QUAT = (0.707, 0.0, 0.707, 0.0)
    DEFAULT_RIGHT_POS = ( 0.20, 0.00, 1.05)
    DEFAULT_RIGHT_QUAT = (0.707, 0.0, 0.707, 0.0)

    def __init__(self, cfg: GR1T2FourierRetargeterCfg):
        self.cfg = cfg
        self._hand_primary = self._try_init_dex_retargeting(cfg)
        self._hand_fallback = FourierHandMapper()
        self._waist = WaistEstimator(
            source=cfg.waist_source,
            gain=cfg.waist_gain,
        ) if cfg.enable_waist_dof else None

    def retarget(
        self,
        snapshot: Dict,
        udcap_bones: Optional[Dict] = None,
    ) -> torch.Tensor:
        action = torch.zeros(self.ACTION_DIM, dtype=torch.float32)

        # (1) EEF L/R : priority = forearm → controller → idle
        left_pos, left_quat = self._resolve_eef(snapshot, side="left")
        right_pos, right_quat = self._resolve_eef(snapshot, side="right")

        if self.cfg.use_waist_origin:
            left_pos, right_pos = self._subtract_waist(left_pos, right_pos, snapshot)

        if self.cfg.freeze_orientation:
            left_quat  = np.array(self.DEFAULT_LEFT_QUAT)
            right_quat = np.array(self.DEFAULT_RIGHT_QUAT)

        action[0:3]  = torch.from_numpy(left_pos.astype(np.float32))
        action[3:7]  = torch.from_numpy(left_quat.astype(np.float32))
        action[7:10] = torch.from_numpy(right_pos.astype(np.float32))
        action[10:14] = torch.from_numpy(right_quat.astype(np.float32))

        # (2) Hand joints : DexPilot → UDCAP/Skeletal 폴백
        left_11  = self._resolve_hand_joints(snapshot, udcap_bones, side="left")
        right_11 = self._resolve_hand_joints(snapshot, udcap_bones, side="right")
        action[14:25] = torch.from_numpy(left_11.astype(np.float32))
        action[25:36] = torch.from_numpy(right_11.astype(np.float32))

        # (3) Waist targets — WaistEnabled 모드가 아니어도, waist 값은 Pink IK controlled joint 가
        #     아니라 null-space posture 로 쓰이므로 액션 텐서에 명시 노출하지 않는다.
        #     허리 타겟이 필요한 하위 태스크(LocalFrameTask 기반 torso 컨트롤) 확장 시
        #     action 을 40D 로 확장하거나 별도 채널 추가할 것 — 본 마이그레이션 범위 밖.

        return action
```

#### 5.1.2 `_resolve_eef` 구현 개요

1. **Priority A (forearm tracker)**: `snapshot["trackers"].get("left_forearm")` → `forearm_to_wrist(pose, offset=self.cfg.forearm_wrist_offset)` → `svr_to_isaaclab(pos, quat)`.
2. **Priority B (controller)**: `snapshot["controllers"]["left"]["pose"]` → `svr_to_isaaclab`.
3. **Priority C (idle)**: `DEFAULT_LEFT_POS`/`DEFAULT_LEFT_QUAT`.
4. **Right wrist z-축 180° 회전**: GR1T2Retargeter 내장이 right wrist 에 `quat(0,0,0,1)` 을 적용 — UDCAP 측도 동일 변환을 적용해야 Isaac Lab 내부 변환과 정합.
   ```python
   Z180 = np.array([0, 0, 1, 0], dtype=np.float32)   # wxyz form of (0,0,0,1 xyzw)
   right_quat = quat_multiply(right_quat, Z180)
   ```

#### 5.1.3 `_subtract_waist` (base_link 프레임 변환)

GR1T2 base_link 은 pelvis 아래 root. VD `hips` 트래커 의 XY (Z 는 옵션) 을 감산해 사용자 이동에 robust 한 base_link-local 좌표로 변환.

```python
def _subtract_waist(self, l_pos, r_pos, snapshot):
    waist = snapshot["trackers"].get("waist")
    if waist is None:
        return l_pos, r_pos
    wx, wy, wz = svr_to_isaaclab(waist["pos"], waist["quat"])[0]
    l_pos = l_pos - np.array([wx, wy, wz if self.cfg.subtract_waist_z else 0.0])
    r_pos = r_pos - np.array([wx, wy, wz if self.cfg.subtract_waist_z else 0.0])
    return l_pos, r_pos
```

#### 5.1.4 `_resolve_hand_joints` 구현

```python
def _resolve_hand_joints(self, snapshot, udcap_bones, side):
    # (a) DexPilot 주 경로 (OpenXR skeletal → MANO → Fourier)
    if self._hand_primary is not None:
        try:
            hand_bones = snapshot["hands"][side]["bones"]       # (31,7)
            # 31-bone wrist-frame → 21 MANO positions via index remap
            mano_21 = self._to_mano21(hand_bones)               # (21,3)
            joint_11 = self._hand_primary.compute(mano_21, side) # (11,)
            return joint_11
        except Exception as e:
            if self.cfg.debug:
                print(f"[GR1T2Retargeter] DexPilot {side} 실패, 폴백: {e}")

    # (b) UDCAP / Fourier 폴백
    if udcap_bones:
        return self._hand_fallback.map_hand_vmc(udcap_bones, is_right=(side == "right"))
    if snapshot["hands"][side] is not None:
        return self._hand_fallback.map_hand_skeletal(
            snapshot["hands"][side]["bones"],
            is_right=(side == "right"),
            finger_curls=snapshot["hands"][side].get("fingerCurls"),
        )
    return np.zeros(self.HAND_DIM_PER_SIDE, dtype=np.float32)
```

### 5.2 `fourier_hand_mapper.py` — Fourier 11-관절 폴백 매퍼

Inspire 용 `udcap_finger_mapper.py` 의 패턴을 재사용하되, **Fourier 관절 의미에 맞춰 재배치**.

#### 5.2.1 관절 정의

```python
# Fourier 11-joint layout (single hand)
#   0 L_index_proximal          — MCP (pitch) curl
#   1 L_middle_proximal
#   2 L_pinky_proximal
#   3 L_ring_proximal
#   4 L_thumb_proximal_yaw      — thumb opposition (yaw)
#   5 L_index_intermediate      — PIP (mimic → intermediate)  — 폴백에서는 proximal * 0.5 근사
#   6 L_middle_intermediate
#   7 L_pinky_intermediate
#   8 L_ring_intermediate
#   9 L_thumb_proximal_pitch    — thumb flexion (pitch)
#  10 L_thumb_distal            — thumb distal (mimic → proximal_pitch * 0.7 근사)
```

#### 5.2.2 API

```python
class FourierHandMapper:
    JOINT_DIM = 11

    # 상한 (URDF 한계 근사; 실제 URDF 파싱으로 교체 권장)
    _PROXIMAL_MAX_RAD = 1.57
    _THUMB_YAW_MIN, _THUMB_YAW_MAX = -0.5, 1.0
    _THUMB_PITCH_MAX = 1.2

    def map_hand_skeletal(
        self,
        bones_model_frame: np.ndarray,   # (31,7)
        is_right: bool,
        finger_curls: Optional[np.ndarray] = None,  # (5,) 0..1 from SteamVR
    ) -> np.ndarray:
        fc = finger_curls if finger_curls is not None else np.zeros(5)
        # SteamVR finger curl: thumb, index, middle, ring, pinky
        out = np.zeros(self.JOINT_DIM, dtype=np.float32)

        # proximals (index, middle, pinky, ring) via curl 0..1 → 0..PROXIMAL_MAX
        out[0] = fc[1] * self._PROXIMAL_MAX_RAD  # index
        out[1] = fc[2] * self._PROXIMAL_MAX_RAD  # middle
        out[2] = fc[4] * self._PROXIMAL_MAX_RAD  # pinky
        out[3] = fc[3] * self._PROXIMAL_MAX_RAD  # ring

        # thumb yaw : 31-bone thumb0 (idx 2) 의 local Y-회전 사용
        thumb_bones = bones_model_frame[2:6]   # thumb0..3
        out[4] = self._quat_to_thumb_yaw(thumb_bones)   # clamp to [_THUMB_YAW_MIN, _THUMB_YAW_MAX]
        out[9] = fc[0] * self._THUMB_PITCH_MAX          # thumb flex

        # intermediate mimic (폴백 근사; Isaac Sim 내부 mimic constraint 가 재차 교정)
        out[5] = out[0] * 0.5
        out[6] = out[1] * 0.5
        out[7] = out[2] * 0.5
        out[8] = out[3] * 0.5
        out[10] = out[9] * 0.7

        return out

    def map_hand_vmc(
        self,
        vmc_bones: Dict[str, Tuple[float, float, float, float]],
        is_right: bool,
    ) -> np.ndarray:
        prefix = "Right" if is_right else "Left"
        out = np.zeros(self.JOINT_DIM, dtype=np.float32)
        for joint_idx, (bone_name, transform) in enumerate([
            (f"{prefix}IndexProximal",  "bend"),
            (f"{prefix}MiddleProximal", "bend"),
            (f"{prefix}LittleProximal", "bend"),  # pinky
            (f"{prefix}RingProximal",   "bend"),
            (f"{prefix}ThumbMetacarpal","yaw"),
            (f"{prefix}IndexIntermediate",  "bend"),
            (f"{prefix}MiddleIntermediate", "bend"),
            (f"{prefix}LittleIntermediate", "bend"),
            (f"{prefix}RingIntermediate",   "bend"),
            (f"{prefix}ThumbProximal",     "pitch"),
            (f"{prefix}ThumbDistal",       "pitch"),
        ]):
            q = vmc_bones.get(bone_name)
            if q is None:
                continue
            if transform == "bend":
                out[joint_idx] = self._quat_to_bend(q)
            elif transform == "yaw":
                out[joint_idx] = self._quat_to_yaw(q)
            elif transform == "pitch":
                out[joint_idx] = self._quat_to_pitch(q)
        return np.clip(out, 0.0, self._PROXIMAL_MAX_RAD)

    @staticmethod
    def pack_22d(left_11: np.ndarray, right_11: np.ndarray) -> np.ndarray:
        """Convert per-side 11-vecs to Isaac Lab global 22-length vector in
        the canonical interleaved order declared in the env_cfg hand_joint_names:
          [L_idx_prox, L_mid_prox, L_pnk_prox, L_rng_prox, L_thb_yaw,
           R_idx_prox, R_mid_prox, R_pnk_prox, R_rng_prox, R_thb_yaw,
           L_idx_int,  L_mid_int,  L_pnk_int,  L_rng_int,  L_thb_pitch,
           R_idx_int,  R_mid_int,  R_pnk_int,  R_rng_int,  R_thb_pitch,
           L_thb_dist, R_thb_dist]
        """
        out = np.zeros(22, dtype=np.float32)
        # proximals interleaved L/R  (indices 0..4, 5..9)
        out[0:5] = left_11[[0,1,2,3,4]]
        out[5:10] = right_11[[0,1,2,3,4]]
        # intermediates interleaved L/R (indices 10..14, 15..19) 
        #   note: slot 14 = L_thumb_proximal_pitch, slot 19 = R_thumb_proximal_pitch
        out[10:15] = left_11[[5,6,7,8,9]]
        out[15:20] = right_11[[5,6,7,8,9]]
        # thumb distal L, R
        out[20] = left_11[10]
        out[21] = right_11[10]
        return out
```

> **주의**: `GR1T2FourierSteamVRRetargeter.retarget()` 에서 `action[14:25] = left_11` / `action[25:36] = right_11` 로 **per-side 11 길이 벡터를 그대로 쓰면 Isaac Lab 내부 `hand_joint_names` 순서와 불일치**. 내장 `GR1T2Retargeter.retarget()` 는 22-dim 전역 벡터를 `hand_joint_names` 순서에 맞춰 내보낸다. 따라서 실제 구현은 `pack_22d(left_11, right_11)` 로 22-dim 을 만든 뒤 `action[14:36] = packed` 로 대입해야 한다. §2.4 의 순서를 반드시 준수할 것.

### 5.3 `waist_estimator.py` — 허리 3-DoF 신호원

```python
class WaistEstimator:
    """VD hips 트래커 (또는 HMD yaw 폴백) → waist_yaw/pitch/roll 추정.

    base_link 기준 허리 쿼터니언 차이를 yaw/pitch/roll 3-값으로 분해.
    WaistEnabled 모드의 NullSpacePostureTask 목표값으로 전달 (액션 채널엔 없음).
    """
    def __init__(self, source: str = "hips_tracker", gain=(1.0, 0.5, 0.3)):
        self.source = source
        self.gain = gain
        self._zero_quat: Optional[np.ndarray] = None  # 첫 프레임 기준 캘리브

    def estimate(self, snapshot) -> Tuple[float, float, float]:
        if self.source == "off":
            return (0.0, 0.0, 0.0)
        if self.source == "hips_tracker":
            hips = snapshot["trackers"].get("waist")
            if hips is None:
                return (0.0, 0.0, 0.0)
            _, q_il = svr_to_isaaclab(hips["pos"], hips["quat"])
        else:  # hmd_yaw
            hmd = snapshot.get("hmd")
            if hmd is None:
                return (0.0, 0.0, 0.0)
            _, q_il = svr_to_isaaclab(hmd["pos"], hmd["quat"])

        if self._zero_quat is None:
            self._zero_quat = q_il
            return (0.0, 0.0, 0.0)

        # Relative quaternion → Euler (yaw, pitch, roll) in Isaac Lab frame
        q_rel = quat_multiply(q_il, quat_conjugate(self._zero_quat))
        yaw, pitch, roll = quat_to_yaw_pitch_roll(q_rel)
        return (
            yaw   * self.gain[0],
            pitch * self.gain[1],
            roll  * self.gain[2],
        )
```

> **본 추정값은 현재 액션 텐서 레이아웃 36-dim 에 채널이 없으므로** NullSpacePostureTask 의 posture target 에 직접 주입하거나, 향후 액션 tensor 를 39-dim (waist 3 추가) 으로 확장해야 한다. Isaac Lab 2.3 PickPlaceGR1T2WaistEnabledEnvCfg 는 후자 대신 null-space 자동 활용으로 타협했음 — 첫 단계에서는 그대로 따라가고, 3단계에서 "허리 명시 제어" 실험으로 확장.

`mdp/observations.py` 의 `robot_joint_pos`, `robot_links_state`, `object`, `goal_pos_w` 는 regex 또는 symbolic name 기반이므로 **관절 개수/이름만 다르고 관측 그 자체 구조는 변하지 않음**. 그러나 정책 학습 측 관측 벡터 크기는 다음과 같이 달라진다:

| 채널 | G1 | GR1T2 |
|------|----|--------|
| `robot_joint_pos` (Articulation DoF) | 29 | 30 (head 3 포함; `head_.*` 액추에이터) |
| `hand_joint_state` | 24 | 22 |
| `last_action` | 38 | 36 |
| `object`, `object_rot`, `goal_pos_w`, `robot_root_*`, `robot_links_state` | 로봇 독립 | 로봇 독립 |

BC-RNN/HG-DAGGER 가중치는 입력 dim 이 바뀌면 재학습 필요 — §9 의 데이터 수집 절차가 첫 번째 단계.

## 7. Fourier 손가락 리타게팅 세부 설계

### 7.1 주 경로 — DexPilot via dex-retargeting

Isaac Lab 내장 `GR1TR2DexRetargeting` (`gr1_t2_dex_retargeting_utils.py`) 의 로직을 **그대로 서브클래싱** 하거나, YAML + URDF 를 `ust_260421_fourier/config/dex_retargeting/` 로 복제해 `dex_retargeting.retargeting_config.RetargetingConfig.from_dict()` 로 직접 구성.

절차:
1. Isaac Sim 에서 GR1T2 USD 를 최초 로딩 시 `ControllerUtils.convert_usd_to_urdf()` 가 양손 URDF 를 tmp 에 생성 (`_left_hand.urdf`, `_right_hand.urdf`).
2. `fourier_*_dexpilot.yml` 의 `urdf_path` 필드를 생성된 URDF 경로로 덮어쓰기 (내장 `_update_yaml_with_urdf_path()` 패턴).
3. DexPilot 옵티마이저 로드 → 매 프레임 `compute_left(mano_21)` / `compute_right(mano_21)` 호출.

UDCAP SteamVR Skeletal 31-bone → 21 MANO 매핑:
- Isaac Lab `_HAND_JOINTS_INDEX = [1,2,3,4,5,7,8,9,10,12,13,14,15,17,18,19,20,22,23,24,25]` 는 **OpenXR 26-관절** 인덱스.
- SteamVR Skeletal 은 31-bone (wrist + 5 × 6 bones + 5 aux). MANO 21 로 보내려면 아래 인덱스 리매핑 필요:

| MANO idx | OpenXR XR_HAND_JOINT_* | SteamVR 31-bone |
|----------|-------------------------|-----------------|
| 0 wrist | WRIST | 1 wrist |
| 1-4 thumb  | THUMB_METACARPAL..DISTAL | 2,3,4,5 |
| 5-8 index  | INDEX_METACARPAL..DISTAL | 6,7,8,9 |
| 9-12 middle| MIDDLE_METACARPAL..DISTAL| 11,12,13,14 |
| 13-16 ring | RING_METACARPAL..DISTAL  | 16,17,18,19 |
| 17-20 pinky| LITTLE_METACARPAL..DISTAL| 21,22,23,24 |

구현은 `gr1t2_retargeter.py::_to_mano21(bones_31)` 에서 정적 인덱스 리스트로 수행.

### 7.2 폴백 — UDCAP bend/spread → Fourier 11

DexPilot 이 (a) URDF 로딩 실패, (b) NaN 솔브, (c) 1 frame 내 5 ms 예산 초과 시 → `FourierHandMapper` 로 폴백. 5.2 의 `map_hand_skeletal` 이 SteamVR `fingerCurls` (5값) 을 주 입력, VMC bone quaternion 을 보조로 사용.

### 7.3 품질 검증 기준

1. **T-pose 손가락 = 0**: 사용자가 손을 펴고 가만히 있을 때 22 hand joints 전부 |θ| < 0.1 rad.
2. **완전 주먹 = URDF 한계 80%**: 사용자가 주먹을 꽉 쥐었을 때 proximals 가 1.2~1.3 rad (≈80% of 1.57).
3. **엄지 반대편 터치 정상**: 엄지 + 검지 끝이 Isaac Sim 내에서 1 cm 이내로 접근해야 pinch grasp 성공.
4. **폴백 전환 무결**: DexPilot 실패 시 `fallback_event` 카운터가 증가하며 로봇이 급격한 스냅 없이 매끄럽게 이어짐.

`validate_fourier_dex.py` 스크립트가 이 4 항목을 자동 테스트 (합성 MANO 좌표 + URDF 솔브 결과 비교).

## 8. 허리 3-DoF 신호 전략

### 8.1 옵션 비교

| 옵션 | 구현 난이도 | 품질 | 장점 | 단점 |
|------|-------------|------|------|------|
| A. HMD yaw → waist_yaw 감쇠 | 낮음 | 중 | 추가 하드웨어 불필요 | pitch/roll 없음, 고개 돌림과 상체 회전 혼동 |
| B. VD `hips` 트래커 쿼터니언 | 낮음 (이미 5트래커 존재) | **상** | 3-DoF 전부 획득, 물리 측정 | Pico 5 트래커 구성에서 hips 가 AI 추론이면 레이턴시↑ |
| C. 별도 VIVE Tracker 3.0 + libsurvive | 높음 (하드웨어 추가) | 상 | 독립 센서, 낮은 지연 | VD/SteamVR 복합 셋업 위험 |

**1순위 옵션 B** — 현재 VD 10-세그먼트 중 `hips` 물리 트래커가 이미 waist 역할로 매핑되어 있음 (`tracker_binding.json`). `WaistEstimator(source="hips_tracker")` 가 즉시 활용.

### 8.2 NullSpacePosture vs 액션 채널 확장

현 Isaac Lab WaistEnabled 는 액션 dim 을 늘리지 않고 `pink_controlled_joint_names` 에 waist 3개 추가 → Pink IK 솔버가 null-space 리던던시로 자동 활용. 이 설계의 장점:
- BC-RNN 학습 데이터의 액션 차원 변화 없음 (36 유지).
- 사용자가 허리 의도를 명시적으로 조작하지 않아도 솔버가 손목 도달 불가 시 허리를 사용.

단점: 사용자의 "허리 의도" (의도적 회전) 가 데이터에 기록되지 않음. 장기 로드맵 (§11 Phase 4) 에서 액션을 39D 로 확장하고 허리 3-DoF 를 NullSpacePostureTask 의 posture target 으로 명시 전달하는 실험 수행.

### 8.3 디바운스 및 드리프트 방지

- 첫 1초 평균을 `zero_quat` 로 설정 (자동 캘리브).
- yaw/pitch/roll 저역통과 필터 α=0.2 (12Hz cutoff).
- clamp: `waist_yaw ∈ [-1.0, 1.0] rad`, `pitch ∈ [-0.3, 0.5]`, `roll ∈ [-0.4, 0.4]` (URDF 한계 내 80%).

## 9. 교정 티칭 시스템 마이그레이션 (research/7-1, 8 연계)

**핵심 원칙**: `ust_260220/corrective/` 의 3단계 파이프라인 (BC-RNN → HG-DAGGER → Conformal+VLM) 은 **100% 로봇 무관**. 관측/액션 텐서의 shape 만 다르고 I/O 는 차원 독립 HDF5 포맷.

### 9.1 Phase 1: BC-RNN 초기 정책

**변경점 없음**: `scripts/train_bc_rnn.py` 는 `(obs_dim, act_dim)` 을 HDF5 metadata 에서 읽음. GR1T2 데이터셋 (act_dim=36) 으로 처음부터 훈련.

**GR1T2 전용 데이터 수집 절차** (`scripts/record_demos.py` 사용):
```bash
python scripts/record_demos.py \
  --task Isaac-KitchenSorting-GR1T2-Fourier-WaistEnabled-DataCollect-v0 \
  --teleop_device pico_udcap \
  --render_mode steamvr_desktop \
  --num_demos 30 \
  --output ./data/gr1t2_kitchen_sorting_v1.hdf5
```

목표: 30 데모 × 20 초 = 10 분 녹화 = BC-RNN phase-1 기준 데이터셋.

### 9.2 Phase 2: HG-DAGGER 교정 개입

**변경점 1건**: `scripts/run_hg_dagger.py` 의 `InterventionManager` 는 내부에 idle_action tensor 를 보관. GR1T2 용 36D idle 로 교체 필요:
```python
# ust_260421_fourier/scripts/run_hg_dagger_gr1t2.py (또는 기존 파일 robot 플래그 추가)
from ust_ws.ust_260421_fourier.kitchen_sorting_gr1t2_env_cfg import KitchenSortingGR1T2EnvCfg
idle = KitchenSortingGR1T2EnvCfg().idle_action
```

개입 트리거 (양 grip 버튼) 로직은 `PICOInterventionInterface` (부모 클래스) 재사용 — 로봇 무관.

**개입 품질 검증**: GR1T2 의 더 큰 도달 엔벨로프에서 "사용자가 빨리 개입 → 로봇이 즉시 재배치" 레이턴시 < 150 ms (G1 기준 동일 목표).

### 9.3 Phase 3: Conformal Prediction + VLM 실패 감지

**변경점 없음**: `conformal_predictor.py` 는 정책 출력 로짓의 95% 예측 집합을 계산 — action space 차원 독립. `vlm_analyzer.py` 는 카메라 이미지 기반 — 로봇 기하와 무관.

**재보정 필요**: `conformal_threshold` 는 데이터셋별. GR1T2 데이터셋으로 `calibrate_conformal.py` 재실행.

### 9.4 HDF5 스키마 호환성

`utils/hdf5_recorder.py` 스키마:
```
/episodes/{i}/
  actions        (T, 36)   ← GR1T2, 기존 G1 은 (T, 38)
  observations/  (dict, 관측 키별)
  rewards        (T,)
  intervention   (T,) bool
  failure_label  (T,) int8
  metadata: {robot_id: "gr1t2", action_dim: 36, ...}
```

**하위 호환**: GR1T2 모델은 기존 G1 데이터 사용 불가 (action_dim 불일치). HDF5 파일 이름과 metadata 로 명확히 분리:
- `./data/g1_kitchen_sorting_v*.hdf5` (기존, 38D)
- `./data/gr1t2_kitchen_sorting_v*.hdf5` (신규, 36D)

### 9.5 VLM 기반 실패 분류 재사용

`corrective/phase3/vlm_analyzer.py` 는 Isaac Sim 카메라 프레임 + GPT-4V/Claude-3.5 Sonnet 프롬프트:
> "Is the robot's grasp of the {object} successful at step {t}? Answer with SUCCESS/FAILURE/UNCERTAIN."

GR1T2 로봇 모양이 프롬프트에 들어가지 않으므로 재사용 가능. 단, 카메라 위치/각도는 Scene 이 바뀌었으므로 재조정 (§6.4 참조).

## 15. 결론

**한 줄 요약**: 현재 `ust_260418_win` + `ust_260220` 의 **~80% 코드 (SteamVR 입력, 좌표 변환, MDP, 교정 티칭 파이프라인) 는 로봇 무관** 이므로 그대로 재사용한다. **교체가 필요한 것은 리타게터(38D→36D, Inspire→Fourier), env_cfg (G1→GR1T2, pelvis→base_link, wrist_yaw→palm frame), idle pose 3 곳에 집중** 된다. Isaac Lab 2.3 이 GR1T2 + 6-DoF Fourier hand + WaistEnabled + DexPilot YAML 을 `main` 에 전부 내장하고 있으므로, **마이그레이션은 "참조 내장 cfg 를 ust_ws 로 복제 + UDCAP 어댑터 한 층"** 이상이 아니다. 예상 공수 4주, 치명적 리스크 3건 (씬 재튜닝, UDCAP→MANO 인덱스 매핑, 허리 신호원), 1순위 대응 전부 계획에 반영. G1 경로는 `_legacy_g1/` 로 아카이브 하지 않고 회귀 테스트 기준선으로 유지.
