### 3.4 VR 조작 방법

| 제스처/입력 | 기능 |
|------------|------|
| **오른손 이동** | 암 End-Effector 위치 제어 |
| **오른손 회전** | 암 End-Effector 방향 제어 |
| **오른손 핀치** | 그리퍼 열림/닫힘 |
| **왼손 썸스틱** | 모바일 베이스 이동 |

### 3.5 키보드 조작 방법 (폴백)

| 키 | 기능 |
|----|------|
| W/S | 전진/후진 |
| A/D | 좌/우 이동 |
| Q/E | 상/하 이동 |
| ↑/↓ | 피치 회전 |
| ←/→ | 요 회전 |
| G | 그리퍼 토글 |
| R | 환경 리셋 |
| ESC | 종료 |

## 4. 데이터 수집

### 4.1 기본 데이터 수집 (20개 데모)

```bash
cd /workspace/isaaclab

./isaaclab.sh -p ust_ws/260207_ust/scripts/record_demos.py \
    --num_demos 20 \
    --task pick_and_place
```

### 4.2 이미지 포함 수집

```bash
./isaaclab.sh -p ust_ws/260207_ust/scripts/record_demos.py \
    --num_demos 50 \
    --task manipulation \
    --include_images \
    --dataset_path ./ust_ws/260207_ust/datasets
```

### 4.3 수집 파라미터

| 파라미터 | 기본값 | 설명 |
|---------|-------|------|
| `--num_demos` | 20 | 수집할 데모 수 |
| `--task` | manipulation | 태스크 이름 |
| `--include_images` | False | RGB-D 이미지 저장 |
| `--max_episode_length` | 500 | 최대 에피소드 길이 |
| `--min_episode_length` | 10 | 최소 에피소드 길이 |
| `--dataset_path` | ./datasets | 저장 경로 |

### 4.4 수집 중 조작

- **손바닥 아래로 / R**: 에피소드 성공으로 저장 및 다음 시작
- **주먹 제스처 / ESC**: 에피소드 폐기 및 다시 시작
- **Ctrl+C**: 수집 중단 및 현재까지 저장

### 4.5 데이터셋 확인

## 5. 정책 학습

### 5.1 Robomimic BC-RNN 학습

```bash
cd /workspace/isaaclab

# BC-RNN 정책 학습
./isaaclab.sh -p scripts/robomimic/train.py \
    --task Isaac-UST-MobileManip-v0 \
    --algo bc_rnn \
    --dataset ./ust_ws/260207_ust/datasets/ust_demos.hdf5 \
    --experiment ust_bc_rnn_v1
```

### 5.2 Isaac Lab Mimic 데이터 증강

```bash
# 10개 데모 → 1000개 데모 증강
./isaaclab.sh -p scripts/imitation_learning/isaaclab_mimic/generate_dataset.py \
    --input_file ./ust_ws/260207_ust/datasets/ust_demos.hdf5 \
    --output_file ./ust_ws/260207_ust/datasets/ust_mimic_1k.hdf5 \
    --num_envs 100 \
    --num_demos 1000
```

### 5.3 LeRobot 학습

```bash
# 데이터셋 변환
python ust_ws/260207_ust/utils/lerobot_converter.py \
    --input ./ust_ws/260207_ust/datasets/ust_demos.hdf5 \
    --output ~/.cache/huggingface/lerobot/ust_mobile_manip

# ACT 정책 학습
python lerobot/scripts/train.py \
    policy=act \
    env=ust_mobile_manip \
    dataset_repo_id=ust_mobile_manip

# Diffusion Policy 학습
python lerobot/scripts/train.py \
    policy=diffusion \
    env=ust_mobile_manip \
    dataset_repo_id=ust_mobile_manip
```

### 5.4 학습 모니터링

```bash

```

### 5.5 정책 평가



- `/joint_states` (sensor_msgs/JointState)
- `/ee_pose` (geometry_msgs/PoseStamped)


**서브스크라이브 토픽:**
- `/cmd_vel` (geometry_msgs/Twist)
- `/arm_controller/command` (std_msgs/Float64MultiArray)

### 6.4 양방향 브릿지

```bash
./isaaclab.sh -p ust_ws/260207_ust/scripts/run_ros2_bridge.py --mode bidirectional
```

## 7. 문제 해결

### 7.1 USD 파일 로딩 실패

**증상**: `File not found` 또는 `USD load error`

**해결**:
```bash
# USD 파일 경로 확인
ls -la /workspace/isaaclab/ust_ws/isaac_file/ust_project1.usd

# 설정 파일에서 경로 수정
nano config/ust_mobile_manipulator_cfg.py
```

### 7.2 CloudXR 연결 실패

**증상**: VR 헤드셋 연결 안됨

**해결**:
```bash
# CloudXR 서버 상태 확인
ps aux | grep cloudxr

# 환경 변수 확인
echo $XR_RUNTIME_JSON

# 네트워크 확인 (Quest 3S와 같은 네트워크)
ping <quest_ip>
```

### 7.3 GPU 메모리 부족

**증상**: CUDA out of memory

**해결**:
```bash
# GPU 메모리 사용량 확인
nvidia-smi

# 병렬 환경 수 줄이기
./isaaclab.sh -p scripts/run_teleop.py --num_envs 1

# 이미지 수집 비활성화
./isaaclab.sh -p scripts/record_demos.py --no-include_images
```

### 7.4 IK 수렴 실패

**증상**: 암이 목표 위치에 도달하지 못함

**해결**:
- `ust_actions_cfg.py`에서 IK 파라미터 조정
- `lambda_val` 증가 (0.05 → 0.1)
- `scale` 감소 (0.5 → 0.3)

### 7.5 ROS2 토픽 미수신

**증상**: 토픽이 퍼블리시되지 않음

**해결**:
```bash
# 토픽 리스트 확인
ros2 topic list

# 토픽 에코
ros2 topic echo /joint_states

# 노드 상태 확인
ros2 node list
```
