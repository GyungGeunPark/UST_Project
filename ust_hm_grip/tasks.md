입력 :
- .md 파일

진행방식 :
- 시작 시 tasks.md 전체를 출력하여 현재 상태 표시
- Task 하나 완료할 때마다 tasks.md 업데이트 + 변경된 부분 출력
- 입력받은 .md 파일의 설계 및 구현가이드 대로 구현한다.
- 실행환경구축 + 시스템 설계 + 구현 (코드 생성, 수정, 디버깅) + 코드리뷰(결과 리포트 리뷰) + 최종 결과 리포트
- 지적 사항 나오면 다시 Claude 에서 구현 (코드 생성, 수정, 디버깅) 진행
- 실제 시스템 동작을 이미지스크린샷, 레코딩, 로그 확인하여 확인하면서 진행
- 모든 Task 완료 후 최종 결과 리포트
- 히스토리는 memory.md 에 기록

에이전트 주 역할 분담 :
- claude : 코딩, 설계, 디버깅
- codex : 코드 리뷰, 결과 리포트 리뷰 (리뷰,비평,보조 구현)
- gemini : 이미지, 동영상 등 자료 확인 및 리서치 (멀티모달, 긴문서 확인 및 리서치)

완료 조건 (모두 충족):
1. tasks.md 에 미완료 [x] 항목이 0개
2. 코드 실행에 에러 0개
3. 실제 시스템 동작 및 시각화 를 확인하여 이상없을 시 종료.

제약 :
- 토큰 최대 사용 시 중단하고 남은 작업 보고
