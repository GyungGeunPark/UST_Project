## 1. 서론 (Introduction)

### 1.1 연구 배경

```
현대 사회의 도전:
│
├── 인구 구조 변화
│   ├── 노인 인구의 급격한 증가
│   ├── 고령화 사회의 심각한 사회적 문제화
│   └── 돌봄 인력 부족
│
├── 팬데믹의 영향 (COVID-19)
│   ├── 대면 활동 감소
│   ├── 노인의 사회적 고립 심화
│   └── 우울증과 외로움 증가
│
└── 기술적 해결책의 필요성
    └── 휴먼케어 로봇 서비스 개발
```

### 1.2 연구 목표

본 연구에서는 노인을 위한 **인지적, 정서적 지원**을 고려한 휴먼케어 로봇 서비스 통합 시스템을 개발하고, **실제 환경에서 안정성과 유용성을 검증**했습니다.

### 1.3 연구 질문

| # | 연구 질문 |
|---|----------|
| RQ1 | 휴먼케어 로봇 서비스가 안정적으로 작동하는가? |
| RQ2 | 노인들이 로봇 서비스를 유용하게 느끼는가? |
| RQ3 | 로봇 서비스가 노인의 삶의 질에 영향을 미치는가? |

## 3. 연구 방법론 (Methodology)

### 3.1 연구 설계

**준실험 연구 설계(Quasi-Experimental Research Design)**를 사용했습니다.

```
준실험 설계의 특징:
│
├── 정의
│   └── 무작위 배정 없이 인과관계 추정
│
├── 장점
│   ├── 윤리적/실용적 제약 극복
│   ├── 실제 환경에서의 연구 가능
│   └── 내적 타당성 확보 노력
│
└── 본 연구의 적용
    ├── 단일집단 시계열 설계
    └── 단일집단 사전-사후 설계
```

### 3.2 두 가지 실험 설계

#### 3.2.1 단일집단 시계열 설계 (One-group Time Series Design)

| 항목 | 내용 |
|-----|------|
| **적용** | 가정 환경 실험 |
| **특징** | 통제 집단 없이 동일 집단의 결과를 시간에 따라 측정 |
| **장점** | 시간에 따른 변화 추적 가능 |

```
시계열 설계:
O₁ → O₂ → O₃ → X → O₄ → O₅ → O₆ → O₇ → ...
                 ↑
           로봇 서비스 도입
```

#### 3.2.2 단일집단 사전-사후 설계 (One-group Pretest-Posttest Design)

| 항목 | 내용 |
|-----|------|
| **적용** | 테스트베드 실험 |
| **특징** | 로봇 사용 전후의 단일 집단 결과 비교 |
| **장점** | 개입 효과 직접 측정 |

```
사전-사후 설계:
O₁ (사전 측정) → X (로봇 서비스) → O₂ (사후 측정)
```

### 3.3 참가자

| 실험 환경 | 참가자 수 | 특성 |
|----------|----------|------|
| **테스트베드 (아파트)** | 40명 노인 | 다양한 건강 상태 |
| **가정 환경** | 2명 노인 | 장기간 독거 |

### 3.4 실험 절차

```
실험 진행 과정:
│
├── 1단계: 사전 평가
│   ├── 기초 설문 조사
│   ├── 심리 측정 도구 적용
│   └── 기준선 데이터 수집
│
├── 2단계: 로봇 서비스 도입
│   ├── 로봇 설치 및 설정
│   ├── 사용법 교육
│   └── 초기 적응 기간
│
├── 3단계: 서비스 이용 기간
│   ├── 일일 3-4시간 사용
│   ├── 16-20일 동안 지속
│   └── 중간 점검 및 지원
│
└── 4단계: 사후 평가
    ├── 종료 설문 조사
    ├── 심리 측정 재실시
    └── 인터뷰
```

### 3.5 실험 기간

| 항목 | 세부 내용 |
|-----|----------|
| **일일 사용 시간** | 3-4시간 |
| **총 실험 기간** | 16-20일 |
| **추적 조사** | 케어 서비스 사용성 변화 측정 |

## 4. 평가 방법 (Evaluation Methods)

### 4.1 정량적 평가 (안정성)

#### 4.1.1 평가 기준

| 평가 기준 | 정의 | 측정 방법 |
|----------|------|----------|
| **성공률** | 서비스가 기능을 얼마나 잘 수행하는지 | 시도 대비 성공 비율 |
| **사용 빈도** | 사용자가 서비스를 얼마나 자주 이용하는지 | 일일/주간 사용 횟수 |

#### 4.1.2 성공률 계산

```
성공률 = (성공한 서비스 실행 횟수 / 전체 서비스 시도 횟수) × 100%
```

### 4.2 정성적 평가 (유용성)

#### 4.2.1 평가 요소

| 평가 요소 | 측정 내용 |
|----------|----------|
| **삶의 만족도 변화** | 서비스 사용 전후 만족도 비교 |
| **로봇에 대한 인식** | 로봇에 대한 태도 및 수용성 |
| **신뢰성** | 로봇 서비스에 대한 신뢰 정도 |

#### 4.2.2 삶의 질 관련 지표

```
삶의 질 평가 지표:
│
├── 심리적 지표
│   ├── 외로움 (Loneliness)
│   └── 우울증 (Depression)
│
├── 사회적 지표
│   └── 사회적 관계 (Social relationships)
│
├── 신체적 지표
│   └── 건강 상태 (Health status)
│
└── 종합 지표
    └── 삶의 만족도 (Life satisfaction)
```

### 4.3 평가 도구

| 도구 유형 | 구체적 도구 | 측정 내용 |
|----------|------------|----------|
| **설문 조사** | Likert 척도 설문 | 만족도, 수용성 |
| **표준화된 척도** | UCLA 외로움 척도 | 외로움 수준 |
| **인터뷰** | 반구조화 인터뷰 | 심층적 의견 |
| **관찰** | 사용 로그 분석 | 실제 사용 패턴 |

## 5. 연구 결과 (Results)

### 5.1 정량적 결과

#### 5.1.1 서비스별 성공률

```
서비스 성공률 분포:
│
├── 높은 성공률 서비스
│   ├── 날씨 정보 제공: ~95%
│   ├── 음악 재생: ~93%
│   ├── 알림 서비스: ~90%
│   └── 기본 대화: ~88%
│
├── 중간 성공률 서비스
│   ├── 건강 관리 알림: ~80%
│   └── 게임/퀴즈: ~75%
│
└── 개선 필요 서비스
    ├── 활동 감지 기반 사전 서비스: ~60%
    └── 환경음 인식: ~55%
```

#### 5.1.2 사용 빈도 분석

| 서비스 유형 | 평균 일일 사용 횟수 | 선호도 |

| 정서 지원 (대화, 음악) | 높음 | 높음 |
| 정보 서비스 (날씨, 뉴스) | 중간 | 높음 |
| 인지 게임 | 중간 | 중간 |
| 건강 알림 | 낮음 | 중간 |

### 5.2 정성적 결과

#### 5.2.1 긍정적 피드백

## 6. 논의 (Discussion)

### 6.1 주요 발견

1. **대부분의 로봇 서비스가 높은 성공률 달성**
   - 기본 서비스의 안정적 운영 확인
   - 사용자 만족도 긍정적

2. **사전 서비스의 개선 필요성**
   - 활동 감지 기반 서비스 정확도 향상 필요
   - 환경음 인식 성능 개선 필요

3. **실제 가정 환경에서의 높은 수용성**
   - 독거 노인의 높은 만족도
   - 정서적 지원 효과 확인

### 6.2 실행 가능성 및 효과성

**결론: 휴먼케어 로봇 서비스는 노인 케어에 실행 가능하고 효과적입니다.**

```
효과성 평가:
│
├── 인지적 측면
│   ├── 인지 자극 제공
│   └── 일정 관리 지원
│
├── 정서적 측면
│   ├── 외로움 완화
│   ├── 우울감 감소
│   └── 사회적 연결감 제공
│
└── 실용적 측면
    ├── 건강 관리 지원
    ├── 안전 모니터링
    └── 일상생활 편의 제공
```

### 6.3 기술적 도전

| 도전 | 현재 상태 | 개선 방향 |
|-----|----------|----------|
| **음성 인식** | 노인 음성 특성에 민감 | 노인 음성 특화 모델 |
| **활동 인식** | 조명에 민감 | 다중 센서 융합 |
| **개인화** | 기본 수준 | 강화학습 기반 적응 |

### 7.2 기술적 한계

```
기술적 한계:
│
├── 인식 모듈
│   ├── 음성 인식 정확도
│   ├── 활동 인식 정확도

├── 하드웨어
│   ├── 배터리 수명
│   └── 이동성 제한
│
└── 소프트웨어
    ├── 대화 자연스러움
    └── 개인화 수준
```

### 7.3 윤리적/사회적 고려사항

| 고려사항 | 설명 |
|---------|------|
| **프라이버시** | 지속적 모니터링에 대한 우려 |
| **의존성** | 로봇에 대한 과도한 의존 가능성 |
| **인간 접촉 대체** | 인간 상호작용 감소 우려 |
| **기술 격차** | 기술 친숙하지 않은 노인의 어려움 |

## 8. 결론 및 시사점 (Conclusion and Implications)

### 8.1 연구 결론

**요약: 휴먼케어 로봇 서비스는 노인 케어에 실행 가능하고 효과적입니다.**

본 연구는 노인을 위한 휴먼케어 로봇 서비스의 **실제 적용 가능성을 검증**하고, **향후 개선 방향을 제시**했습니다.

### 8.2 학문적 기여

1. **준실험 설계 적용**: 실제 환경에서의 로봇 서비스 평가 방법론 제시
2. **다차원 평가**: 안정성과 유용성의 통합적 평가
3. **실증적 증거**: 휴먼케어 로봇의 효과성에 대한 실증적 데이터

### 8.3 실무적 시사점

```
실무적 시사점:
│
├── 개발자를 위한 시사점
│   ├── 음성/활동 인식 정확도 우선 개선
│   ├── 노인 특성 고려한 인터페이스 설계
│   └── 실제 환경 테스트 중요성
│
├── 정책 입안자를 위한 시사점

│   ├── 윤리 가이드라인 수립 필요
```
