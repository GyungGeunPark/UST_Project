## 1. 서론 (Introduction)

### 1.1 연구 배경

가상 아바타와 소셜 로봇을 포함한 인간과 유사한 에이전트의 경우, 말하면서 적절한 제스처를 취하는 것이 인간-에이전트 상호작용에서 매우 중요합니다. **공동 음성 제스처(co-speech gesture)**는 상호작용 경험을 향상시키고 에이전트가 살아있는 것처럼 보이게 만듭니다.

### 1.2 문제 정의

그러나 사람들이 어떻게 제스처를 취하는지에 대한 이해 부족으로 인해 인간과 유사한 제스처를 생성하는 것은 어렵습니다. 데이터 기반 접근법은 인간 시연에서 제스처 기술을 학습하려고 시도하지만, **제스처의 모호하고 개인적인 특성**이 학습을 방해합니다.

### 1.3 연구 목표

본 논문에서는 음성 텍스트, 오디오, 화자 정체성의 **다중 모달 컨텍스트**를 사용하여 신뢰성 있게 제스처를 생성하는 자동 제스처 생성 모델을 제시합니다.

---

## 2. 관련 연구 (Related Work)

### 2.1 제스처 유형

인간의 공동 음성 제스처는 다음과 같이 분류됩니다:

| 제스처 유형 | 설명 | 예시 |
|-----------|------|-----|
| **아이코닉(Iconic)** | 구체적인 개념을 시각화 | 크기나 모양을 손으로 표현 |
| **메타포릭(Metaphoric)** | 추상적 개념을 시각화 | 아이디어의 "성장"을 표현 |
| **데익틱(Deictic)** | 공간적 위치 지시 | 방향 가리키기 |
| **비트(Beat)** | 음성의 리듬과 동기화 | 강조를 위한 손 움직임 |

### 2.2 기존 연구의 한계

- **규칙 기반 방법**: 제스처 규칙을 수동으로 정의, 확장성 부족
- **데이터 기반 방법**: 오디오만 사용, 의미적 정보 손실
- **기존 딥러닝 모델**: 단일 모달만 사용, 화자별 스타일 미반영

## 3. 방법론 (Methodology)

### 3.1 네트워크 아키텍처 개요

```
┌─────────────────────────────────────────────────────────────┐
│                    제스처 생성 시스템                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   ┌─────────┐   ┌─────────┐   ┌─────────┐                  │
│   │  텍스트  │   │  오디오  │   │ 화자 ID │                  │
│   │ 인코더   │   │ 인코더   │   │ 임베딩  │                  │
│   └────┬────┘   └────┬────┘   └────┬────┘                  │
│        │            │            │                         │
│        └────────────┼────────────┘                         │
│                     ▼                                       │
│              ┌────────────┐                                 │
│              │  컨텍스트   │                                 │
│              │   융합층    │                                 │
│              └─────┬──────┘                                 │
│                    ▼                                        │
│              ┌────────────┐                                 │
│              │  제스처    │                                 │
│              │  디코더    │                                 │
│              └─────┬──────┘                                 │
│                    ▼                                        │
│              ┌────────────┐                                 │
│              │ 판별자(D)  │ ← 적대적 훈련                    │
│              └────────────┘                                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 삼중 모달 입력

#### 3.2.1 텍스트 인코더
- **목적**: 음성의 의미적 내용 추출
- **방법**: FastText 사전훈련 임베딩 (crawl-300d-2M-subword)
- **역할**: 아이코닉/메타포릭/데익틱 제스처에 필요한 의미 정보 제공

#### 3.2.2 오디오 인코더
- **목적**: 음성의 리듬과 운율 추출
- **특징**: MFCC, 피치, 에너지 등 음향 특징
- **역할**: 비트 제스처 및 타이밍 동기화에 필요한 리듬 정보 제공

#### 3.2.3 화자 정체성 임베딩
- **목적**: 개인별 제스처 스타일 반영
- **방법**: 화자 ID를 스타일 임베딩 공간으로 매핑
- **역할**: 내성적/외향적 등 다양한 스타일의 제스처 생성 가능

### 3.3 시간적 동기화 아키텍처

음성과 제스처 간의 **시간적 동기화(temporal synchrony)** 특성을 활용:

- 명시적으로 정렬된 음성과 제스처 사용
- 네트워크가 음성-제스처 변환에 집중 가능
- Gentle 라이브러리를 사용한 오디오-텍스트 정렬

### 3.4 생성기 구조

- **구조**: 4층 GRU(Gated Recurrent Unit)
- **입력**: 컨텍스트 특징 벡터 시퀀스
- **출력**: 인간 자세 시퀀스

### 3.5 적대적 훈련 (Adversarial Training)

**GAN(Generative Adversarial Network)** 아키텍처 채택:

| 구성요소 | 역할 |
|---------|------|
| **생성기(G)** | 입력 컨텍스트로부터 제스처 시퀀스 생성 |
| **판별자(D)** | 생성된 제스처와 실제 제스처 구분 |

적대적 훈련을 통해 인간과 유사한 자연스러운 제스처 생성 보장.

## 5. 평가 지표 (Evaluation Metrics)

### 5.1 FGD (Fréchet Gesture Distance)

본 논문에서 **새롭게 제안한 정량적 평가 지표**:

```
FGD 계산 과정:
1. 제스처 오토인코더 훈련 (Human3.6M)
2. 생성/실제 제스처를 특징 공간으로 인코딩
3. 두 분포 간 Fréchet 거리 계산
```

**FGD 공식**:
$$FGD = ||μ_r - μ_g||^2 + Tr(Σ_r + Σ_g - 2(Σ_rΣ_g)^{1/2})$$

여기서:
- $μ_r, μ_g$: 실제/생성 제스처의 평균
- $Σ_r, Σ_g$: 실제/생성 제스처의 공분산

### 5.2 주관적 평가

인간 평가자를 통한 주관적 평가:
- **자연스러움**: 제스처가 얼마나 인간적인가
- **적절성**: 음성 내용과 얼마나 일치하는가
- **동기화**: 음성 리듬과 타이밍이 맞는가

## 6. 실험 (Experiments)

### 6.1 실험 환경

| 항목 | 사양 |
|-----|------|
| **프레임워크** | PyTorch 1.3+ |
| **운영체제** | Ubuntu 18.04 |
| **Python** | 3.6+ |
| **GPU** | RTX 2080 Ti |
| **훈련 시간** | 약 8시간 |

### 6.2 비교 모델

1. **Audio-only 모델**: 오디오만 사용
2. **Text-only 모델**: 텍스트만 사용
3. **기존 Seq2Seq 모델**: GAN 없음
4. **제안 모델**: 삼중 모달 + GAN

### 6.3 실험 결과

#### 6.3.1 정량적 결과 (FGD)

| 모델 | FGD 점수 (낮을수록 좋음) |
|-----|------------------------|
| Audio-only | 높음 |
| Text-only | 중간 |
| 기존 Seq2Seq | 중간 |
| **제안 모델** | **가장 낮음 (최고)** |

#### 6.3.2 주관적 평가 결과

- 제안 모델이 모든 평가 항목에서 **기존 엔드투엔드 모델보다 우수**
- 특히 의미적 적절성과 자연스러움에서 큰 차이

### 6.4 스타일 변환 실험

동일한 음성에 대해 **다른 화자 ID**를 지정하여 다양한 스타일 생성:

```
같은 문장 "Hello, how are you?"

화자 A (내성적) → 작고 절제된 제스처
화자 B (외향적) → 크고 표현적인 제스처
```

### 6.5 합성 오디오 테스트

- **Google Cloud TTS** 사용하여 텍스트에서 음성 합성
- 합성 오디오에서도 적절한 제스처 생성 확인
- **실제 응용 시나리오**에서의 활용 가능성 입증

## 7. 결과 및 논의 (Results and Discussion)

### 7.1 주요 발견

1. **삼중 모달의 효과**: 각 모달리티가 다른 유형의 제스처에 기여
   - 텍스트 → 의미적 제스처 (아이코닉, 메타포릭)
   - 오디오 → 리듬 제스처 (비트)
   - 화자 ID → 스타일 변화

2. **GAN의 효과**: 더 자연스럽고 인간적인 제스처 생성

3. **스타일 임베딩**: 개인화된 제스처 스타일 생성 가능

### 7.2 한계점

- 손가락 움직임 미포함 (상체 제스처만)
- 특정 문화/언어에 편향될 가능성
- 실시간 처리에 대한 검증 부족

### 7.3 향후 연구 방향

- 손가락 제스처 포함 확장
- 다국어/다문화 데이터셋 구축
- 실시간 시스템 최적화

---

## 8. 결론 (Conclusion)

본 논문은 음성 텍스트, 오디오, 화자 정체성의 **삼중 모달 컨텍스트**를 활용하여 자연스러운 공동 음성 제스처를 생성하는 모델을 제안했습니다.

### 핵심 기여

1. **삼중 모달 입력 프레임워크**: 의미, 리듬, 스타일 정보 통합
2. **FGD 평가 지표**: 제스처 생성 모델을 위한 새로운 정량적 지표
3. **스타일 임베딩**: 동일 음성에 대한 다양한 스타일 제스처 생성
4. **공개 코드/데이터**: 재현성과 후속 연구 촉진

### 응용 가능성

- 가상 아바타 (메타버스, 게임)
- 소셜 로봇 (서비스 로봇, 교육 로봇)
- 디지털 휴먼 (방송, 광고)
- 수화 번역 시스템
