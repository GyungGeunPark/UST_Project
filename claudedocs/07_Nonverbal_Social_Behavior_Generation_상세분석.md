## 1. 서론 (Introduction)

### 1.1 연구 동기

효과적이고 즐거운 인간-로봇 상호작용을 제공하기 위해, 소셜 로봇이 **악수나 포옹과 같은 비언어적 행동**을 보이는 것이 중요합니다.

### 1.2 기존 접근법의 한계

```
전통적 접근법의 문제:
│
├── 미리 코딩된 동작 재현
│   ├── 사용자가 반응 예측 가능
│   ├── 로봇이 기계처럼 느껴짐
│   └── 자연스러움 부족
│
├── 제한된 행동 레퍼토리
│   ├── 새로운 상황 대응 불가
│   ├── 개인화 어려움
│   └── 확장성 부족
│
└── 컨텍스트 무시
    ├── 상황에 부적절한 반응
    └── 사회적 규범 위반 가능
```

### 1.3 연구 목표

**인간-인간 상호작용에서 사회적 행동을 엔드투엔드 방식으로 학습**하는 신경망 아키텍처를 제안합니다.

---

## 2. 관련 연구 (Related Work)

### 2.1 로봇의 비언어적 행동 생성

| 접근법 | 특징 | 한계 |
|--------|------|------|
| **키프레임 기반** | 애니메이터가 직접 동작 설계 | 확장성 부족, 노동 집약적 |
| **동작 캡처** | 인간 동작 기록 및 재현 | 고정된 동작, 적응성 부족 |
| **규칙 기반** | IF-THEN 규칙으로 행동 선택 | 복잡한 규칙 작성 필요 |
| **학습 기반** | 데이터에서 행동 패턴 학습 | 대량 데이터 필요 |

### 2.2 Seq2Seq 모델

```
Seq2Seq 모델 개요:
│
├── 인코더 (Encoder)
│   ├── 입력 시퀀스 처리
│   └── 컨텍스트 벡터 생성
│
├── 디코더 (Decoder)
│   ├── 컨텍스트에서 출력 생성
│   └── 시퀀스 단계별 출력
│
└── 응용
    ├── 기계 번역
    ├── 텍스트 요약
    └── 행동 시퀀스 생성 (본 연구)
```

### 2.3 생성적 적대 신경망 (GAN)

| 구성 요소 | 역할 |
|----------|------|
| **생성기(G)** | 가짜 데이터 생성 |
| **판별기(D)** | 진짜/가짜 구분 |
| **훈련** | 적대적 게임으로 품질 향상 |

## 3. 방법론 (Methodology)

### 3.1 전체 아키텍처

```
┌─────────────────────────────────────────────────────────────┐
│              비언어적 행동 생성 시스템                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   ┌─────────────────────────────────────────────────────┐   │
│   │                    입력                              │   │
│   │    상대방(E)의 자세 시퀀스: {x₁, x₂, ..., xₜ}        │   │
│   └────────────────────┬────────────────────────────────┘   │
│                        ▼                                    │
│   ┌─────────────────────────────────────────────────────┐   │
│   │                  인코더 (Encoder)                    │   │
│   │    • 양방향 LSTM/GRU                                │   │
│   │    • 입력 시퀀스 → 컨텍스트 벡터                    │   │
│   └────────────────────┬────────────────────────────────┘   │
│                        ▼                                    │
│   ┌─────────────────────────────────────────────────────┐   │
│   │                  디코더 (Decoder)                    │   │
│   │    • LSTM/GRU                                       │   │
│   │    • 컨텍스트 → 반응 자세 시퀀스                    │   │
│   └────────────────────┬────────────────────────────────┘   │
│                        ▼                                    │
│   ┌─────────────────────────────────────────────────────┐   │
│   │                판별기 (Discriminator)                │   │
│   │    • 생성된 시퀀스의 현실성 평가                    │   │
│   │    • 적대적 훈련을 통한 품질 향상                   │   │
│   └────────────────────┬────────────────────────────────┘   │
│                        ▼                                    │
│   ┌─────────────────────────────────────────────────────┐   │
│   │                    출력                              │   │
│   │    로봇(R)의 반응 자세 시퀀스: {y₁, y₂, ..., yₜ}    │   │
│   └─────────────────────────────────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 인코더 구조

| 구성 요소 | 설명 |
|----------|------|
| **입력** | 상대방의 자세 시퀀스 (관절 좌표) |
| **레이어** | 양방향 LSTM 또는 GRU |
| **출력** | 고정 크기 컨텍스트 벡터 |

### 3.3 디코더 구조

| 구성 요소 | 설명 |
|----------|------|
| **입력** | 컨텍스트 벡터 + 이전 출력 |
| **레이어** | LSTM 또는 GRU |
| **출력** | 각 시간 단계의 자세 |

### 3.4 판별기 구조

```
판별기 네트워크:
│
├── 입력
│   └── 자세 시퀀스 (진짜 또는 생성된)
│
├── 처리
│   ├── 시간적 특징 추출 (LSTM)
│   └── 전역 특징 추출 (FC layers)
│
└── 출력
    └── 진짜/가짜 확률 (0~1)
```

### 3.5 손실 함수

```
총 손실 = L_reconstruction + λ × L_adversarial

L_reconstruction: 재구성 손실
- 생성된 자세와 실제 자세 간의 차이
- MSE (Mean Squared Error) 사용

L_adversarial: 적대적 손실
- 판별기를 속이기 위한 손실
- GAN 학습 동역학 제공

λ: 균형 하이퍼파라미터
```

### 3.6 GAN의 역할

장기 행동 생성 시 **유효하지 않은 자세 시퀀스가 발생하는 것을 방지**:

| 문제 | GAN 없이 | GAN 사용 시 |
|-----|----------|------------|
| **누적 오류** | 시간이 지남에 따라 증가 | 억제됨 |
| **비현실적 자세** | 발생 가능 | 판별기가 감지/제거 |
| **일관성** | 저하 가능 | 유지됨 |

## 4. 데이터셋: AIR-Act2Act

### 4.1 데이터셋 개요

| 항목 | 내용 |
|-----|------|
| **이름** | AIR-Act2Act |
| **규모** | 5,000개의 인간-인간 상호작용 |
| **시나리오** | 10가지 다른 시나리오 |
| **목적** | 로봇에게 비언어적 사회적 행동 교육 |

### 4.2 상호작용 시나리오

```
AIR-Act2Act 시나리오:
│
├── 인사 관련 (8가지)
│   ├── 인사 (Bowing)
│   ├── 악수 (Handshake)
│   ├── 포옹 (Hug)
│   ├── 손 흔들기 (Waving)
│   └── ... (기타 인사 행동)
│
└── 기타 (2가지)
    ├── 하이파이브 (High-five)
    └── 때리기 (Hit) - 방어 행동 학습용
```

### 4.3 데이터 구조

| 역할 | 설명 |
|-----|------|
| **노인(E)** | 시작 행동 수행 (Initiating behavior) |
| **파트너(R)** | 반응 행동 수행 (Responsive behavior) |

반응 행동은 서비스 로봇이 수행할 때 사람들에게 **자연스럽고 겸손한 반응**으로 수용될 수 있도록 설계되었습니다.

### 4.4 데이터 캡처

```
데이터 캡처 시스템:
│
├── 센서
│   ├── RGB 카메라
│   ├── 깊이 카메라
│   └── 모션 캡처 (선택적)
│
├── 처리
│   ├── 자세 추정 (OpenPose 등)
│   ├── 3D 재구성
│   └── 시간 동기화
│
└── 출력
    ├── 관절 좌표 시퀀스
    ├── 행동 레이블
    └── 타이밍 정보
```

## 5. 학습된 비언어적 행동 (Learned Nonverbal Behaviors)

### 5.1 5가지 핵심 행동

| # | 행동 | 한국어 | 설명 | 응용 |
|---|------|--------|------|------|
| 1 | **Bowing** | 인사하기 | 정중한 인사 동작 | 첫 만남, 인사 |
| 2 | **Staring** | 응시하기 | 주의 집중 표현 | 관심 표시 |
| 3 | **Shaking hands** | 악수하기 | 사회적 인사 | 비즈니스, 소개 |
| 4 | **Hugging** | 포옹하기 | 친밀감 표현 | 환영, 위로 |
| 5 | **Blocking face** | 얼굴 가리기 | 방어적 반응 | 위협 상황 |

### 5.2 행동별 학습 포인트

```
각 행동의 학습 요소:
│
├── 인사하기 (Bowing)
│   ├── 적절한 굽히는 각도
│   ├── 타이밍 (언제 시작, 언제 끝)
│   └── 속도 조절
│
├── 악수하기 (Handshake)
│   ├── 손 위치 조정
│   ├── 그립 세기 (간접적)
│   └── 흔드는 패턴
│
├── 포옹하기 (Hugging)
│   ├── 접근 거리
│   ├── 팔 위치
│   └── 지속 시간
│
├── 응시하기 (Staring)
│   ├── 시선 방향
│   └── 자세 유지
│
└── 얼굴 가리기 (Blocking)
    ├── 빠른 반응
    └── 적절한 가림 자세
```

## 6. 실험 (Experiments)

### 6.1 실험 환경

| 항목 | 세부 내용 |
|-----|----------|
| **로봇 플랫폼** | Pepper 휴머노이드 로봇 |
| **환경** | 시뮬레이션 환경 |
| **목적** | 제안 방법의 검증 |

### 6.2 실험 설계

```
실험 구성:
│
├── 실험 1: 단일 행동 학습
│   ├── 각 행동을 개별적으로 학습
│   └── 행동별 성능 평가
│
├── 실험 2: 다중 행동 동시 학습
│   ├── 모든 행동을 동시에 학습
│   └── 행동 간 간섭 분석
│
└── 실험 3: 비교 연구
    ├── 전통적 방법과 비교
    └── 다른 학습 방법과 비교
```

### 6.3 평가 지표

#### 6.3.1 제안된 새로운 평가 지표

사회적 행동의 성공 평가는 **주관적**이므로, 생성된 행동과 실제 행동 간의 차이를 계산하는 **새로운 평가 지표**를 제안:

```
평가 지표:
│
├── 자세 정확도 (Pose Accuracy)
│   └── 관절 위치의 평균 오차
│
├── 시간적 일관성 (Temporal Consistency)
│   └── 연속 프레임 간 부드러움
│
├── 행동 완성도 (Behavior Completeness)
│   └── 행동의 시작-중간-끝 적절성
│
└── 현실성 (Realism)
    └── 인간 평가 또는 판별기 점수
```

### 6.4 실험 결과

| 비교 항목 | 전통적 방법 | 제안 방법 (GAN 없음) | 제안 방법 (GAN 포함) |
|----------|------------|---------------------|---------------------|
| 자세 정확도 | 낮음 | 중간 | **높음** |
| 시간적 일관성 | 중간 | 낮음 (누적 오류) | **높음** |
| 행동 완성도 | 중간 | 중간 | **높음** |
| 현실성 | 낮음 | 중간 | **높음** |

## 8. 논의 및 한계 (Discussion and Limitations)

### 8.1 주요 기여

1. **엔드투엔드 학습**: 규칙 없이 데이터에서 직접 학습
2. **GAN 통합**: 장기 시퀀스의 현실성 보장
3. **새로운 평가 지표**: 사회적 행동 평가를 위한 객관적 지표
4. **다양한 행동 학습**: 5가지 핵심 비언어적 행동

### 8.2 한계점

| 한계 | 설명 | 향후 방향 |
|-----|------|----------|
| **시뮬레이션** | 실제 로봇 검증 부족 | 실제 환경 테스트 |
| **행동 수** | 5가지로 제한 | 더 많은 행동 추가 |
| **개인화** | 모든 사용자에게 동일 | 사용자별 적응 |
| **문화** | 단일 문화 데이터 | 다문화 데이터셋 |

## 9. 결론 (Conclusion)

### 9.1 연구 요약

본 논문은 **Seq2Seq 모델**과 **GAN**을 결합하여 소셜 로봇의 비언어적 사회적 행동을 **엔드투엔드로 학습**하는 방법을 제안했습니다.

### 9.2 핵심 성과

- **자연스러움 향상**: 예측 불가능하고 인간적인 반응 생성
- **확장성**: 다양한 사회적 행동 학습 가능
- **일반화**: 새로운 상황에 대한 적응력
- **실용성**: 실제 로봇 플랫폼 적용 가능

### 9.3 향후 전망

이 연구는 소셜 로봇이 인간과 더 자연스럽고 풍부한 비언어적 상호작용을 할 수 있는 기반을 제공합니다.
