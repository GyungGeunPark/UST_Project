## 2. 연구 토픽 배경 (Research Topic Background)

### 2.1 사회적 맥락

```
현대 사회의 변화와 로봇 기술의 필요성:
│
├── 인구 구조 변화
│   ├── 고령화 사회의 급속한 진행
│   ├── 분산 가정(맞벌이 가정) 증가
│   └── 한부모 가정 증가
│
├── 케어 수요 증가
│   ├── 노인 케어 인력 부족
│   ├── 돌봄 서비스 비용 증가
│   └── 케어 품질에 대한 기대 상승
│
└── 기술적 해결책
    └── 사회적 지능을 갖춘 서비스 로봇 개발
```

**핵심 인용**: "노인과 케어 제공자들은 사회적으로 지능적인 서비스 로봇의 잠재적 이점을 인정하고 있습니다."

### 2.2 서비스 로봇의 진화

#### 전통적 서비스 로봇
- **특징**: 비상호작용적, 물리적 서비스 중심
- **예시**: 청소 로봇, 감시 로봇, 배달 로봇, 물류 로봇
- **한계**: 인간과의 사회적 상호작용 부재

#### 현대 서비스 로봇
- **특징**: 사회적으로 지능적이고 상호작용적인 서비스
- **예시**: 안내 로봇, 감정적 동반자 로봇, 의료 중재 로봇, 교육 로봇
- **요구사항**: 사회적 인간-로봇 상호작용(sHRI) 필수

## 3. 수록 논문 분석 (Featured Articles Analysis)

이 연구 토픽은 HRI 설계, 사회적 지능, 의사결정, 사회심리학, 로봇 사회적 기술 분야에서 제출물을 받았으며, **4개의 논문**이 출판을 위해 수락되었습니다.

### 3.1 논문 1: 자폐 아동을 위한 댄싱 로봇

#### 연구 개요
| 항목 | 내용 |
|-----|------|
| **저자** | Javed and Park |
| **대상** | 자폐 스펙트럼 장애(ASD) 아동 |
| **방법** | 댄싱 로봇을 통한 참여 유도 |

#### 기술적 접근

```
댄싱 로봇 시스템 아키텍처:
│
├── 컴퓨터 비전 (Computer Vision)
│   ├── 아동의 움직임 감지
│   ├── 자세 추정
│   └── 참여도 분석
│
├── 강화학습 (Reinforcement Learning)
│   ├── 리더/팔로워 역할 전환
│   ├── 아동 반응에 따른 적응
│   └── 최적 상호작용 전략 학습
│
└── 댄스 생성
    ├── 음악과 동기화된 움직임
    ├── 아동 움직임 모방
    └── 새로운 움직임 제안
```

#### 상호작용 모드

| 모드 | 설명 | 목적 |
|-----|------|------|
| **리더 모드** | 로봇이 새로운 동작 제안 | 모방 능력 향상 |
| **팔로워 모드** | 로봇이 아동 동작 모방 | 자기 효능감 향상 |
| **전환 모드** | 역할 동적 전환 | 유연한 상호작용 |

### 3.2 논문 2: SocialDQN 프레임워크

#### 연구 개요
| 항목 | 내용 |
|-----|------|
| **저자** | Belo et al. |
| **방법** | 심층 강화학습 프레임워크 |
| **목적** | 감정 상태에 대한 로봇 반응 훈련 |

#### 기술적 접근

```
SocialDQN 아키텍처:
│
├── 입력 처리
│   ├── 얼굴 특징 추출
│   └── 감정 상태 인식
│
├── 심층 Q-네트워크 (DQN)
│   ├── 상태 표현 학습
│   ├── 행동 가치 추정
│   └── 최적 정책 도출
│
├── 시뮬레이션 환경
│   ├── 다양한 감정 시나리오
│   ├── 반복적 훈련
│   └── 안전한 실험 환경
│
└── 출력
    └── 감정에 적합한 로봇 반응
```

#### 강화학습 구성 요소

| 구성 요소 | 설명 |
|----------|------|
| **상태(State)** | 사용자의 감정 상태 (행복, 슬픔, 분노 등) |
| **행동(Action)** | 로봇의 반응 (표정, 제스처, 발화 등) |
| **보상(Reward)** | 사용자 반응의 긍정도 |
| **정책(Policy)** | 감정→반응 매핑 |

### 3.3 논문 3: CTAMP 계층적 제어 아키텍처

#### 연구 개요
| 항목 | 내용 |
|-----|------|
| **저자** | Jeon et al. |
| **방법** | Combined Task and Motion Planning (CTAMP) |
| **목적** | 사회적으로 지능적인 물리적 조작 |

#### 기술적 접근

```
CTAMP 계층 구조:
│
├── 작업 계획층 (Task Planning)
│   ├── 고수준 목표 분해
│   ├── 사회적 제약 고려
│   └── 실행 순서 결정
│
├── 동작 계획층 (Motion Planning)
│   ├── 궤적 생성
│   ├── 충돌 회피
│   └── 자연스러운 동작
│
└── 불확실성 처리 (Uncertainty Handling)
    ├── 확률적 추론
    ├── 적응적 재계획
    └── 견고한 실행
```

#### 사회적 지능의 통합

| 요소 | 설명 |
|-----|------|
| **물체 전달** | 사용자에게 편안한 방향으로 전달 |
| **안전 거리** | 조작 중 적절한 거리 유지 |
| **타이밍** | 사용자 준비 상태 확인 후 행동 |
| **투명성** | 의도를 명확히 표현 |

### 3.4 논문 4: 사용자 선호도 연구

#### 연구 개요
| 항목 | 내용 |
|-----|------|
| **저자** | Velentza et al. |
| **방법** | 비디오 기반 사용자 연구 |
| **목적** | 로봇 성격과 상호작용 스타일 선호도 조사 |

#### 연구 변수

```
연구 변수:
│
├── 독립 변수
│   ├── 로봇 성격 (Personality)
│   │   ├── 외향적 (Extroverted)
│   │   └── 내향적 (Introverted)
│   │
│   ├── 상호작용 스타일 (Interaction Style)
│   │   ├── 사회적 (Social)
│   │   └── 기능적 (Functional)
│   │
│   └── 친숙도 수준 (Familiarity)
│       ├── 높음
│       └── 낮음
│
└── 종속 변수
    ├── 선호도
    ├── 신뢰도
    ├── 편안함
    └── 사용 의향
```

#### 주요 발견

| 발견 | 내용 |
|-----|------|
| **성격 영향** | 성격 유형이 선호도에 영향 |
| **스타일 영향** | 상호작용 스타일이 신뢰에 영향 |
| **친숙도 영향** | 친숙도가 편안함에 영향 |

```
미래 인간-로봇 공생을 향한 로드맵:
│
├── 단기 (1-3년)
│   ├── 개별 기술 고도화
│   ├── 실제 환경 검증
│   └── 사용자 수용성 향상
│
├── 중기 (3-5년)
│   ├── 기술 통합
```
