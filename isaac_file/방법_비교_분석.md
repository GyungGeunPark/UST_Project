# Open Manipulator X - Isaac Sim 설정 방법 비교 분석

## 현재 상황

### 문제점
현재 `ust_project1.usd` 파일은 **페이로드(Payload) 참조 시스템**을 사용하여 로봇을 불러왔기 때문에:
- 계층 구조 수정이 불가능 (worldBody를 link1로 변경 실패)
- `Sdf.CopySpec`도 실패 (페이로드 spec은 복사 불가)
- 스크립트를 통한 자동 수정이 매우 어려움

### 에러 메시지 분석
```
Error in 'pxrInternal_v0_24__pxrReserved__::SdfCopySpec' at line 606:
'Cannot copy unknown spec at </World/Robot/open_manipulator_x1/worldBody>'
```
→ 페이로드로 로드된 프림은 복사가 불가능

## 방법 비교

### 방법 1: 기존 USD 파일 수정 (현재 시도 중)

#### 장점
- 이미 모델이 로드되어 있음
- 메쉬와 비주얼이 이미 설정됨
- URDF에서 변환된 상태

#### 단점
- ❌ **페이로드 시스템 때문에 수정 불가능**
- ❌ 계층 구조 변경 실패
- ❌ 복잡한 USD 내부 구조
- ❌ 스크립트 접근 방법이 제한적
- ⏱️ 예상 소요 시간: **불가능하거나 매우 오래 걸림 (수일)**

#### 가능한 해결책 (매우 복잡)
1. 페이로드를 플래튼(Flatten)하여 전체 USD로 변환
2. 플래튼된 파일에서 계층 구조 수정
3. 물리 속성 재설정
→ 이 과정도 복잡하고 에러 가능성이 높음

---

### 방법 2: URDF에서 다시 임포트 ✅ **추천**

#### 필요한 것
- Open Manipulator X의 URDF 파일
- 메쉬 파일들 (.stl, .dae)

#### 장점
- ✅ **Isaac Sim의 URDF Importer는 자동으로 올바른 계층 생성**
- ✅ Joint, Articulation이 자동으로 설정됨
- ✅ 물리 속성이 URDF에서 자동 변환됨
- ✅ 깨끗하고 간단한 구조
- ✅ Lula가 즉시 인식 가능
- ⏱️ **예상 소요 시간: 30분 ~ 1시간**

#### 단점
- URDF 파일이 필요함 (하지만 Open Manipulator X는 공개 패키지)
- 처음부터 다시 임포트 필요

#### 작업 절차
```
1. URDF 파일 준비 (10분)
   - ROS 패키지에서 URDF 가져오기
   - 또는 GitHub에서 다운로드

2. Isaac Sim에서 임포트 (10분)
   - File > Import > URDF
   - Import 설정 조정

3. Articulation 설정 확인 (5분)
   - 자동으로 올바른 계층 구조 생성됨
   - link1이 root, link2~5가 자식으로 설정됨

4. Lula 설정 (10-20분)
   - Robot Prim 선택
   - Joints 설정
   - Collision Spheres 추가

5. 저장 및 테스트 (5분)
```

---

### 방법 3: 새로운 모델링 파일에서 시작

#### 필요한 것
- Open Manipulator X의 CAD 파일 (.step, .stl 등)

#### 장점
- 깨끗한 시작

#### 단점
- ❌ **Joint를 수동으로 모두 생성해야 함**
- ❌ Articulation을 수동으로 설정
- ❌ 물리 속성을 수동으로 입력
- ❌ Joint 위치, 회전축을 정확히 측정해야 함
- ⏱️ **예상 소요 시간: 3-5시간 이상**

#### 작업 절차
```
1. 메쉬 파일 임포트 (30분)
2. 각 링크를 Rigid Body로 설정 (30분)
3. Joint 5개 수동 생성 및 설정 (2-3시간)
   - 각 Joint의 위치 정확히 설정
   - 회전축 방향 설정
   - Joint limit 설정
4. Articulation Root 설정 (10분)
5. Mass, Inertia 수동 입력 (1시간)
6. Lula 설정 (10-20분)
```

## 권장 사항

### 🏆 **방법 2: URDF 재임포트 강력 추천**

#### 이유:
1. **가장 빠름**: 30분 ~ 1시간이면 완료
2. **가장 정확함**: URDF에 이미 정확한 Joint 정보 포함
3. **가장 안전함**: Isaac Sim이 검증된 방법으로 변환
4. **Lula 호환성 최고**: 자동으로 올바른 구조 생성

#### 다음 단계:

1. **URDF 파일 찾기**
   ```bash
   # Open Manipulator X는 ROBOTIS의 공식 ROS 패키지
   # GitHub: https://github.com/ROBOTIS-GIT/open_manipulator
   ```

2. **Isaac Sim에서 임포트**
   - File > Import > URDF
   - URDF 파일 선택
   - Import Configuration:
     - Fix Base Link: ✅ (체크)
     - Self Collision: ✅ (체크)
     - Import Inertia Tensor: ✅ (체크)

3. **결과 확인**
   - Stage에서 계층 구조 확인
   - base_link → link1 → link2 → ... 로 정상 생성됨
   - Articulation Root가 base_link에 자동 설정됨

4. **Lula 설정**
   - Robot Prim으로 base_link 선택
   - 모든 Joint가 자동으로 표시됨
